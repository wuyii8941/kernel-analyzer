# Formation interventions

The Phi MM map has one exploratory residual-row permutation intervention. It
preserves the local residual norm/multiset and includes a matched sham, but its
analytic transport reconstruction is not closed, so the artifact is retained
as `MEASURED_NO_TRANSPORT_SUPPORT` rather than a P2 claim. Intervention
artifacts must name the formation stage that triggered them, preserve the
declared marginals/support/semantics, include a matched sham, and remain
separate from formation labels.
