## 1. 家族规格 f

| 家族 | f |
|---|---|
| G1 | mean = mean_d(x[r,:])；var = mean_d((x − mean)²)；rstd = (var + eps)^(−1/2)；y[r,d] = (x[r,d] − mean)·rstd·gamma[d] + beta[d] + res[r,d] |
| G2 | r = max(a, 0)；y = r²·b，逐元素 |
| G3 | t_i = 1 + h_i/(1 + \|h_i\|)；y_i = t_i / Σ_j t_j，按行 |
| G4 | v′ = mu·v + g；y = theta − lr·(v′ + wd·theta)，逐元素 |
| G5 | byte_j = packed[r,j]；q_{2j} = (byte_j & 15) − 8；q_{2j+1} = ((byte_j >> 4) & 15) − 8；y[r] = Σ_k q_k·sc[r, ⌊k/G⌋]·a[k]，a（fp16）按精确值转换 |
| G6 | y[r] = ⟨a_r, b_r⟩ / (√⟨a_r, a_r⟩ · √⟨b_r, b_r⟩) |
| G7 | s_j = max(⟨q, k_j⟩·scale, 0)，j ≤ pos；否则 s_j = 0；y = Σ_j s_j·v_j / (Σ_j s_j + 1) |
| G8 | y[r,d] = (Σ_{i≤d} x[r,i]) / D |

所有运行时标量（eps = 2⁻²⁰，lr = 2⁻¹⁰，mu = 7/8，wd = 2⁻⁸，scale = 1/8）都是 float32 精确可表示的值，发布值等于 kernel 接收值，阶段 2 只有一种标量口径，接口项应为零。

## 4. 勘误（在打开阶段 1 结果之前，复核答案文件时发现）

1. **一个预先登记的阳性在设计上无法检出。** 它的注入作用约为 10⁻¹³ 的相对量，而单程序检验的噪声来自末步最近舍入，约为 3×10⁻⁸。推算如下：每元素信号 ≈ lr·wd·4×10⁻⁸·|θ| ≈ 1.5×10⁻¹³|θ|，在 R3 方向上的投影 ≈ 1.5×10⁻¹³·‖θ‖ ≈ 7.7×10⁻¹¹；每个 seed 的投影噪声 ≈ 3×10⁻⁸；64 个确认 seed 下，信号约为标准误的 0.02 倍。输出层与参数更新层都一样。处理：改为灵敏度探针，不计入检出率分母；若被判检出，按待核实的发现处理。程序编号在答案文件里，揭盲时公布。
2. **一个语义变体的预期量级写偏了。** 答案写的是 K_R − f 的相对量约为 eps；正确值约为 1.5·eps（var ≈ 1 时为 1.43×10⁻⁶）。推导：K_R 的 rstd = var^(−1/2) + eps，f 的 rstd = (var + eps)^(−1/2) ≈ var^(−1/2)·(1 − eps/(2var))，两者之差 = eps·(1 + 1/(2var^(3/2)))。符号与规则不变。

其余阳性按答案预测的量级与相应噪声逐个复核过，信噪比都在两位数以上。
