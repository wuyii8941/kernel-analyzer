## 第一组：保证修复，优先于大规模新增运行

1. 整数：修复 `_cmpi` 的uint64重新转int64；修复CAS比较/返回值经过float64；对divui/remui/ceildivui、logical shift、unsigned min/max和最终整数输出比较做同类检查。
2. scaled dot：保留上下界，传播scale的状态/conditional；正例不仅是加载点值，还要是来自前面子区域的区间与条件值。共同解码路径要配独立解码检查，不能只TTIR与TTGIR相交。
3. CAS两序：两序一致仅作诊断；基于程序证书、真实声明顺序或覆盖全部允许交错的集合返回。为未证明前提单列保证状态，不混入认证complete。
4. 来源：删除“位模式属于输入”及“全零”作为复制证明的作用；无生产者证据保留kernel级。补跨seed来源变化检查，不能只用首seed的来源覆盖整个总体。
5. Gluon：`measure.run`用与核心求值器一致的IR选择，不再先硬读`asm['ttir']`。真实sm86 Gluon kernel从统一声明到最终报告走通，不能仅官方插件能跑。

每个修复：最小反例、普通对照、生产入口或完整解释器回归；更新受影响记录清单，先定位影响再决定重算范围。
