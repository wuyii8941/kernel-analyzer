# Case 001

This directory is an opaque historical-case package for blind localization.
The package contains only the input artifact, declared reference output, and
environment/contract metadata. It must not contain a fixed revision, patch,
issue discussion, or root-cause note.

The package is generated by `build_blind_case_package_v0_1.py` in the target GPU
environment. The locator may use `case_manifest.json`, `input.pt`, and
`reference.pt`; the external evaluator owns any hidden historical answer.
