## 1. 家族规格 f

| 家族 | f |
|---|---|
| F1 | y[r,d] = x[r,d] · (mean_d(x[r,:]²) + eps)^(−1/2) · (1 + s[r,d]) + b[r,d] |
| F2 | g(a) = 0.5·(1 + a/(1+\|a\|))；y = (a·g(a))·b，逐元素 |
| F2S | g(a) = 0.5·(1 + a/(1+\|a\|))；y = ((a·g(a))·b)·t，逐元素，t 为运行时标量 |
| F3 | out[r,0] = mean_d(x[r,:])；var = mean_d((x − mean)²)；out[r,1] = (var + eps)^(−1/2) |
| F4 | P = D/4，x1 = x[:, 0:P]，x2 = x[:, P:2P]，xp = x[:, 2P:D]；y1 = t·(x1·cos − x2·sin)；y2 = t·(x1·sin + x2·cos)；y = [y1, y2, xp] |
| F5 | y[r] = Σ_k (q[r,k] · sc[r, ⌊k/G⌋]) · a[k]，q（int8）与 a（fp16）按精确值转换 |
| F6 | g = 0.5·(1 + h/(1+\|h\|))；w = m·g；y[r,d] = Σ_l w[r,l]·x[r,l,d] / Σ_l w[r,l] |
| F7 | y[r] = Σ_v softmax(p[r])_v · (log softmax(p[r])_v − log softmax(q[r])_v) |
| F8 | d = pred − target；g = d 若 \|d\| ≤ delta，否则 delta·sign(d)；y = g·m / nvalid |

同一家族的所有程序使用同一份 f。f 的求值必须独立于候选程序的 TTIR：把上面的公式作为输入，用参照求值器的内部运算或独立的精确有理数代码算出来，不能把候选自身再求值一次当作 f。

## 2. f 的求值

| 运算 | 方法 | 宽度 |
|---|---|---|
| 加、减、乘、除、取绝对值、按整数位置选取 | 精确有理数 | 0 |
| (·)^(−1/2) | 正确舍入的 sqrt 向上、向下各算一次 | 高精度下约 1 ulp |
| F7 的 exp、log | 正确舍入向上、向下各算一次，softmax 用 max 平移 | 同上 |
| F8 的 sign | 精确；d = 0 时 sign(0) = +1（与程序中 `d >= 0` 的写法一致） | 0 |

## 3. 阶段 2 的量

阶段 1 的 e = K − K_R 原样保留。阶段 2 新增

e_sem = K_R − f

两侧都是区间时按区间相减：K_R − f ∈ [L_R − U_f, U_R − L_f]。对 e_sem 用与阶段 1 相同的五条规则、相同的 seed 集、相同的端点保守检验与 Holm 校正，每程序一行报告 μ 区间与判定。F3 的两列分开报。

## 4. 对修订 v1.1 的三处更正

1. **R4 归入固定方向规则。** R4 是事前固定的向量（前 64 维 −1、第 65–128 维 +1、其余 0），不依赖输入或 K_R，与 R1、R5 同组；只有 R2、R3 的方向依赖参照输出。v1.1 把 R4 写进对齐组是错的。只改分类，不改任何判定。
2. **R5 的复现写法。** 第二轮在新 seed 上重新学习方向，复现的是同一检测程序的表现，不是同一个数值方向上的同一个 μ。报告写「程序级复现」，不写「原方向已跨输入确认」。
3. **prog_07 的定位写法。** 写「4 个输入中 2 个可模拟，这 2 个首位节点一致」，归入条件性定位。

另加一条表格说明：μ 区间一列是未做多重校正的单格区间，最终判定以 Holm 结果为准；区间不含零而判定为未确认的格子，原因就在这里，数值不改。

## 5. 对阶段 1 复现结果的定性

36/38 个初次检出的格子在不相交 seed 上同号复现，是可重复性证据，不是准确率或召回率：两轮共用同一参照求值器与统计方法，共享的系统错误不会被复现发现。prog_16 的 R2、R3 记为「初次检出、复现未确认」，R4 稳定复现，两者不矛盾。8 对逐位相同的程序判定一致，证明的是等价写法得到一致处理。

现在能说的是：在这批陌生组合、声明的输入分布和当前参照与统计条件下，工具找到了多项能在新输入上重复出现的平均作用。漏检率、误报率、以及这些作用是否违反任务规格，要等独立核实与阶段 2。
