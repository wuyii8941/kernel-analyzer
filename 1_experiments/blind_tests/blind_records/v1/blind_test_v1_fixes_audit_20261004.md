# 修复包审阅（blind_test_v1_audit_20261004，提交 3490425）

## 1. 端点保守 p 值的更正

被测方自查出的问题成立：旧式 p = max(两端点的双侧 p) 在跨零的盒上偏小，Holm 把这类检验当作拒绝，放宽了其余检验的阈值。更正后的 p = 2·min(p(E[l] > 0), p(E[h] < 0)) 与区间判定一致。

出题方独立核实：
- 源码 `analysis.py` 的 `_summarize` 实现与更正式一致，区间判定用 E[l] 的置信下界与 E[h] 的置信上界。
- 用回归记录中每个确认 seed 的投影上下界，出题方自行重算 170 个实现量检验的 p 值、区间与 Holm 判定：p 值与区间逐项相同，Holm 后判定 0 处不同，检出 38 个。
- 用冻结的阶段 2 报告重跑 Holm：发布标量口径 160 个检验中 90 个跨零检验曾被算作拒绝，float32 口径 156 个中 111 个；按更正式重算，最终检出 29 → 29、19 → 19，无增减。阶段 1 两轮没有受影响的检验。

结论：冻结结果与最终计分不受影响；更正正确。
