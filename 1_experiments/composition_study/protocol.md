# 组合研究：Triton 操作组合中 bias 的成因（协议）

日期：2026-10-13。对象：Triton 3.6.0（`ka_main`），sm_86（RTX A6000）。输入：用户提供的 three_plans_v3 包
（`inputs/three_plans_v3_20261013.tar.gz`，sha256 `4e703057…48a0fa`）。

## 0. 要回答的问题与可以成立的说法

中心问题：一个陌生的 Triton kernel 进来，能不能拆成「原语 × 组合规则」，并说明它偏离声明计算的部分从哪来、改了会怎样？
在什么意义上可以说「Triton 里 bias 的成因测全了」？

程序有无穷多个，「测全」不能指测全所有程序。可以测全的是生成所有程序的有限部件：

1. **原语表（L）**：每个原语实例在设备上实际怎么算。原语 = F1 的操作实例（包里的 705 个）加上前端实际产生的
   libdevice 调用（每个函数 × 类型签名）和常量字面量。
2. **组合规则（C）**：每一种组合形式（F2）在设备上怎么由原语拼出来。包括 TTIR 本身不规定、由下降决定的部分：
   归约与扫描的次序、乘加收缩、近似指令与加法的合并、张量核内部的累加、原子更新的次序。
3. **偏差机制（M）**：位点上的局部残差怎样变成输出的系统性偏差。把输出偏差按位点逐个替换分解（telescoping），
   每一项的期望只有四种来源：位点残差的均值（B1）、残差与下游系数的协方差（B2）、二阶项（曲率 × 方差，B3）、
   离散判定的翻转（B4）。加上声明计算与任务规格之间的差（B5，语义层），这是一个恒等式，不是经验分类。

可以成立的说法是结构归纳加单程序证书：若 L 中每个原语、C 中每条组合规则都经过设备核验，则任一由它们构成的程序，
其设备结果由「原语行为 + 组合规则」逐位确定，偏差可以逐位点分解；对单个程序，这一点由逐位仿真与设备输出的比较
直接核验（工具的 `emulate.verify`）。仿真不能逐位复现的部分就是缺口，必须报告，不能默认。

本研究的产出因此是三张表（原语表、组合单元表、机制表）与一张缺口清单；库里的算子只是检验组合规律与统计流行度的样本。

## 1. 与 three_plans_v3 的关系

- F1 用包的展开规则从工具的 Triton 3.6.0 操作注册表重新生成（`space.py`，与包的 705 个实例逐项相同）。
- 包的答案机在生成器里同时充当「设备」：`K_elem = round(G)` 由 oracle 算出，不运行设备，所以它测不到下降带来的任何
  偏离（近似除法、ex2.approx、收缩、归约次序、TF32）。本研究的每一个单元都在设备上运行；答案机（`exact.py`、
  `refs.py`）只算声明值，不导入工具代码。
- 包缺的因子在这里补上：编译选项（`enable_fp_fusion`、`enable_reflect_ftz`、`num_warps`、`default_dot_input_precision`
  及 bf16x3 / bf16x6）、布局参数（BLOCK、归约轴长度）、生产者-消费者相邻关系（收缩、近似指令合并只发生在相邻的两个
  原语之间）、libdevice 函数。

## 2. RQ1 原语表（描述性，没有假设）

每个原语实例：编译状态（编译器的拒绝本身是结果）、PTX 指令、在 7 种分布（包的 6 种去掉「构造残差符号」，加上覆盖
全指数范围的 wide）与特殊值组合上的设备结果对声明值。浮点结果报告：等于正确舍入值的比例、最大与平均有符号误差（以
结果格式在精确值处的间距为单位）、冲零、特殊值类别不一致；整数、谓词、位转换报告逐值相等，声明未定义的结果单独计数。

## 3. RQ2 组合单元（预先写定的判据）

单元 = 一个原语 × 一种组合形式 × 一组编译选项。单元在设备上运行，捕获后用工具的仿真器（全部下降选择冻结，不按输出
拟合）逐元素比较。单元结果：逐位相同 / 不一致 / 未建立（仿真器声明不可仿真）/ 不适用 / 编译器拒绝。

- **H2.1**：默认选项下，所有可编译原语 × 23 种形式中，仿真器能仿真的单元全部逐位相同。不一致的单元逐个找原因
  （仿真器错误 / 未建模的下降），不改判据。
- **H2.2**：仿真器声明不可仿真的形式（扫描、原子、张量核 dot）只有这三类；其余形式没有「未建立」。
- **H2.3**：设备结果在同一输入上逐位可重复，原子浮点折叠除外。
- 选项扫描（关闭收缩、`num_warps` 1/8、关闭 reflect_ftz）按选项值 × 形式 × 原语类别的两两覆盖执行，判据同 H2.1。

## 4. RQ3 新组合规则（为仿真器不覆盖的形式建立，先定预测再测）

- 张量核 dot（tf32、bf16、f16）：用构造输入分别测输入转换的舍入方式与 mma 内部的累加方式（乘积是否精确、对齐与舍入），
  把测得的规则写成模型；判据：模型在留出的随机输入上逐位复现设备输出。
- 扫描：从小规模构造输入识别组合次序，判据同上。
- 原子：浮点折叠的结果必须落在所有串行次序的结果之中（可枚举的规模上逐一枚举）；整数折叠与次序无关。

## 5. RQ4 偏差机制（预测在运行之前写定）

- B1 位点残差均值：从原语表的平均有符号误差预测单个位点的偏差；判据：符号一致，大小比在 [0.8, 1.25]（包的判据）或
  预测落在 95% 区间内。
- B2 协方差：包的 D1 / D2 构造（残差与系数同号 / 异号）；预测：偏差符号随构造翻转。
- B3 曲率 × 方差：平方、倒数、开方对舍入后的值；预测 E[偏差] ≈ ½ f″ · Var(ρ)。
- B4 离散翻转：比较、取整、max 对舍入后的值；预测翻转率 ≈ 判定边界处的密度 × |ρ| 的均值。
- 每类至少在一种组合形式里以设备结果检验；结果按成立 / 不成立 / 无法判断写。

## 6. RQ5 陌生 kernel 的归因与流行度

- 第二轮 C 组的 Triton TF32 收缩（每次矩阵乘约 −3.5e-4）：由 RQ3 的 dot 模型预测收缩的大小与来源（输入截断 / 内部累加），
  与第二轮的测量比较。
- 库与官方测试中的 kernel：拆成原语与形式，统计每个原语、形式、下降模式、机制出现的频率；报告落在已测单元之外的部分
  （包的 K1 / K2 失败码）。
