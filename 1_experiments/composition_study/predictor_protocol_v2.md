# 组合测试能否预测 bias：冻结协议 v2

日期：2026-10-13。v1（[predictor_protocol.md](predictor_protocol.md)，冻结于提交 bd84c02）照原样报告。v1 的留出结果揭出
预测器的一个错误：噪声遍不携带半径通道，下游舍入点把每个操作数都当作精确的，用舍入关系的舍入点（含软件 e5m2 转换）因此
不注入方差——噪声水平平均低估一半以上（留出集上预测 / 实测的中位数 0.43，55 个输出中 18 个低于 0.1）。受影响的是
§7 的二阶项 2·r² 与 §4 第 3 条失效条件（相对误差过大），均值预测本身不受影响。v2 改两处，其余——契约表、生成器、判定规则、样本数——与 v1 相同：
1. `_site` 在两遍中都累加半径（回归测试 `test_noise_pass_carries_operand_exactness`）；
2. §7 的 r（以及 §4 第 3 条）取预测的**总**误差（每个元素的预测均值 δ 加一次噪声抽样）的 RMS 相对值；v1 只取噪声抽样。
   精确数据的确定性转换（例如 bf16 值到 e5m2）误差全在 δ 里、随元素变化，不是噪声，v1 因此把它漏在 r 之外。v2 用新的
留出种子（§8），留出程序与 v1 和开发集都不同。

## 1. 问题

给一个没有在开发中出现过的 Triton 程序和它的输入分布，**不在设备上运行它**，只用组合研究得到的局部关系和组合规则，能否事先
说出它的输出 bias，并在设备上被证实？

## 2. 预测什么

对一次启动的每个浮点输出：对齐量 α = ⟨K − G, G⟩ / ⟨G, G⟩，K 为设备输出，G 为同一程序的精确值（参照求值器
`KernelReferenceEvaluator`，数值差模式）。负值为收缩（偏向零），正值为放大。同时给出状态：`predicted` 或 `无法判断`
（失效条件成立，见 §4）。

## 3. 预测器（冻结对象）

- 代码：`2_tool/src/kernel_analyzer/reference_eval/bias_predict.py`；
- 契约表：`2_tool/src/kernel_analyzer/reference_eval/data/bias_contracts.json.gz`（由 `contracts.py` 生成）；
- 冻结时的 SHA-256 记在 §8，入库提交即冻结点。

做法：把启动按精确值求一遍，在每个舍入点把该点**契约**（给定精确操作数的粗特征时，残差的条件均值、半宽、方差）注入切向
通道；切向沿求值器的前向规则传播到输出，得到每个元素的预测均值误差 δ 与一阶最坏半径 R。第二遍以随机符号注入
±√方差，得到噪声水平（测量 α 应有的标准误）；每个元素的预测总误差为 δ 加一次噪声抽样，其 RMS 相对值记为 r。

契约来源（都来自组合研究的结论）：

| 舍入点 | 局部关系 | 来源 |
|---|---|---|
| IEEE RN 运算、转换、整数转浮点 | 位置规则时均值 0；结果可表示或输入有效位不多于目标格式时为精确 | 原语表：正确舍入 |
| 由操作数网格决定的 RN 结果 | 丢弃位不超过 12 位（短操作数的积与和、平局），或加减中较小操作数不足结果一 ulp（吸收、进位、跨入更粗的 binade）：在设备值估计（精确值加已预测的均值误差，落到各自格式的网格）上求残差 | 原语表 + C1/C3/C4/C8 单元的下降规则 |
| 截断 / 向下 / 向上 / 最近远离 | −sign·u/2·(1−2^−q) 等 | 原语表 |
| 近似原语（div.full、ex2.approx、非正确舍入的 libdevice） | 每个（符号, binade）格、每个操作数有效位类别（一元：均匀 / 11 位网格 / 8 位网格；二元：每个操作数为 2 的幂 / 短 / 长）的平均有符号误差（输出 ulp），半宽为最大误差 | `contracts.py` 在设备上单测原语 |
| 张量核 dot | tf32 操作数截到 11 位；每组 4/8 个乘积与累加器按最大指数和对齐、低于 2^(E−24) 的位截断、组和截到 24 位；被丢弃位在截断位与各项粒度之间取均值（乘积为最低置位；累加器的粒度沿链跟踪） | `tensor_core.py`（逐位验证的规则） |
| fp32 ieee dot | fma 链，逐步吸收规则 | C15 单元 |
| 求和归约 / 扫描 | 设备组合顺序（`layouts.py`、`scan_order.py`），逐次吸收规则 | C3 / C4 单元 |
| 软件 e5m2 转换 | 先截到 f16，再最近远离 | 组合研究 D 系列 |

组合时保留的信息：精确值；切向区间 [δ − R, δ + R]；每个操作数在设备上可能携带的有效位数（由其生产者决定：load 保留数据自身
的位数，转换与舍入点为目标精度，布局操作透传）；加法吸收时操作数的设备值估计（精确值加已预测的均值误差）。

## 4. 失效条件（任一成立则该程序的预测为「无法判断」）

1. 某个运算没有契约：未编入目录的下降、契约表无条目、没有切向规则；程序中止；
2. 不连续阈值可能翻转：比较的边距在 R 之内且所选分支相差大于 R 的 select；R 之内的浮点转整数、floor / ceil / round；
   条件依赖于这种比较的分支；
3. 一阶模型超出范围：某输出超过 1% 的元素的预测总误差（δ 加噪声抽样）的相对值大于 2^−4；
4. 舍入点上次正规或非有限值超过该点 0.1% 的通道；
5. 浮点原子累加（折叠顺序不建模）；
6. 近似原语超过 1% 的通道落在未刻画的格外，或在至少 1024 个通道上只取不到 64 个不同的操作数值（少数固定工作点，格均值
   不代表它们）；
7. 有写出的元素没有精确值（参照中止、未定义）。

## 5. 留出集 A：随机程序

- 生成器：`programs.py` 的 `generate(seed, 60)`，形式与比例见源码（逐元素 2/7、归约、扫描、循环累加各 1/7、dot 2/7），
  输入分布 normal / uniform01 / wide / bf16valued；
- 种子：`heldout2-` + SHA-256(`bias_predict.py` ‖ `bias_contracts.json.gz` ‖ `programs.py`) 的前 16 个十六进制字符（v2 的
  `bias_predict.py`）——冻结前无法预知，冻结后不能挑选；
- 预测样本：输入种子 0..5，`TritonLaunchRecorder(execute=False)` 捕获（核不运行），预测写入
  `results/predictor_heldout2_predictions.jsonl`，记录 SHA-256 并在测量之前入库；
- 测量样本：输入种子 1000..1005（与预测样本不同），设备运行，参照求值器给 G。

## 6. 留出集 B：真实修改（TF32）

不在 v2 中重做：v1 的 TF32 预测在 v1 冻结之后、测量之前入库并检验，结论按 v1 报告。噪声错误只影响二阶项 2·r²，dot 的

## 7. 判定规则（每个程序 / 每个 (变体, 层×矩阵)）

记 α̂ 为预测样本的平均预测、α 为测量样本的平均测量，SE_pred、SE_meas 为各自样本间的标准误（测量取样本间标准误与逐元素
独立估计的较大者），r 为预测总误差（δ 加噪声抽样）的 RMS 相对值。

- 预测状态为「无法判断」→ **无法判断**（单独计数，并报告这些程序的实测 α，供检查放弃是否有理由）；
- |α − α̂| ≤ 3·√(SE_pred² + SE_meas²) + 0.1·|α̂| + 2·r² → **成立**；否则 **不成立**。

第一项为抽样，第二项为一阶契约本身的相对精度，第三项为一阶模型忽略的二阶项（与相对误差平方同阶）。

对照：零预测（α̂ = 0，即「RN 无偏」）按同一规则（无第二项）判定，报告它在多少程序上被否定——这些程序上预测器给出的非零
预测才是组合测试带来的信息。

结果只按三种状态报告，不合成单一分数。
