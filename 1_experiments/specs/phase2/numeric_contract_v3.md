# 数值契约 v3（2026-10-08）— 可执行版

## 1 三个问题分开
| 问题 | 由谁回答 | 输出 |
| --- | --- | --- |
| 误差多大 | 参照包围 | 区间宽度、|e| 的分布 |
| 平均作用是否非零 | 冻结的统计层 | 均值区间、Holm 后判定；前提不成立 → 「无法判断」 |
| 是否违反任务要求 | 任务契约（文档明文、声明解释、契约允许的数值行为） | 三栏之一 |
任何一栏不得用另一栏代替。「在误差界内」「条件数大」「eager 也一样」只能出现在「误差多大」的描述里。

## 2 黑箱模式下语义与数值的分类：精度不变性
适用：候选支持 dtype 参数化且两种精度走同一算法。不适用（写死 dtype 的 kernel、bf16 专用路径）→ 用 K_R 模式；K_R 也没有 → 「未判定」。
对每个条件、每个输出元素 j：
```
d32_j = |K32_j − f_j|,  d64_j = |K64_j − f_j|      # f_j 取规格区间中点；|f_j| 的尺度另记
若 d32_j == 0 且 d64_j == 0: 一致
若 d32_j == 0 且 d64_j != 0: 异常（float32 恰好正确、float64 偏离）→ 单列复核
r_j = d64_j / d32_j
r_j < 2^-16  → 数值（随精度缩小）
r_j > 2^-4   → 语义（不随精度变化）
其间          → 未判定
```
条件级结论：取该条件内「语义」元素的个数与比例；只要有一个元素为语义且 |d64_j| 超过 float64 的求值噪声（2^-40·(1+|f_j|)），该条件记为「存在语义偏离的元素」。阈值在运行前写定，不按结果调整。
非有限结果（NaN/Inf）：不进入上面的比值，单列第四栏「数值失败」，并记录是否只在某一精度出现。

## 3 「无法判断」的触发（统计前提）
在运行前从现有校准数据定下三条，填入下表后不再改：
| 前提 | 检查 | 触发时 |
| --- | --- | --- |
| 样本方差为零 | 全部 a_i 的区间端点相同 | 「无法判断（退化）」，不返回 p = 0 |
| 分布前提 | 样本偏度绝对值 > S₀ 且 n ≤ N₀（S₀、N₀ 取校准中覆盖率跌破 0.93 的边界） | 用 bootstrap-t；若 bootstrap-t 在该偏度下的校准错误率仍 > 0.07，记「无法判断（分布前提）」 |
| 样本不足 | n < n_min（事先登记） | 「无法判断（样本）」 |
S₀、N₀、n_min 由执行方从 2a 的校准表读出并写在这里；审阅方核对。
