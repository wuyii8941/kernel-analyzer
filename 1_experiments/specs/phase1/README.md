## v0.1 → v0.2 的修改（来自审计）
1. 类别置换性质同步变换落在类别范围内的 ignore_index，并支持概率目标。
2. IDX-A2 的 (self+Σ)/k 不再列为读法，改为带标签的错误变体。
3. max pool 的空采样窗口返回 −∞ 与空集合；全为 NaN 且 R_ignore 时同样；接受 ±∞ 输入；avg pool 的非有限输入显式拒绝。
4. 全部忽略的 'mean'：loss 无定义，grad_defined=False；梯度性质跳过该情形。
5. 交叉熵改为严格区间算术；审计给出的 logits = [−1e100, 0] 反例现在被区间包含。
6. 测试失败时进程非零退出。
7. 协议改为四组对照，B016 改为编译缺陷的召回例子，HF 案例改为累加窗口归一化，裁决口径改为「未排除相等」等六条。

## v0.2 → v0.3 的修改（来自第二轮审计）
1. 区间算术改在固定上下文上运行并陷阱异常；次正规反例（梯度约 1.9×10⁻¹⁰⁰⁰⁰⁵⁸）现在被 [0, 1×10⁻⁹⁹⁹⁹⁹⁹] 包围；[1e100, 1e100] 用稳定形式得到 ln 2，不再溢出；其余越界情形返回 established=False。
2. 非法输入一律拒绝：类别下标越界、label_smoothing 越界、索引越界、不支持的维度、形状不匹配、padding 超过核的一半。
3. 顺序不变性对 dim=1 置换列；梯度总量守恒排除空窗口并单独报告；伴随检查先核对形状。
4. 删除一项恒真占位测试，新增 13 项回归。
5. 协议：F 与 FR 对「候选是否违反任务」用同一 K − f 契约裁决，FR 的分解单独计分；τ₆₄ 只作筛查门槛；只有精确可表示的小规模例子才要求严格相等；规格未建立与非法输入单列。

## v0.3.1：独立交叉核对的结果
`python3 independent_check.py 1000`（随机种子固定）：
- 交叉熵：1000 个随机条件，覆盖三种读法、三种 reduction、类别下标与概率目标、含零权重、label_smoothing 的发布值与接收值，以及尺度从 1e−300 到 1e100 的混合、相等 logits、−2302718 与 ±1e100 这类极端值。9,965 个损失与梯度标量全部落在规格区间内，0 个在外，0 个「未建立」，0 个异常泄漏；44 个无定义情形与独立计算一致。
- 池化：3000 个随机配置，1,815 个合法配置与蛮力实现逐项相等，0 处不一致；非法配置两边同时拒绝，没有一边拒绝另一边接受的情形。
- index/scatter：3000 个随机配置，960 个合法配置逐项相等，0 处不一致；越界索引全部被拒绝。
这是抽样证据，不是全域证明。

## v0.4：按审阅决定所做的修改
1. 主读法：CE 为 R_A + D2 分母（代码默认不变，R_C 降为诊断标签）；avg pool 的默认除数读法改为 R2，R1 保留对照。
2. NaN：R_prop 为诊断 profile，只传播实际参与的 NaN；R_ignore 过滤后无值时，max pool 与 index/scatter 都返回「未建立」（SpecNotEstablished），不再返回 −∞ 或抛 ValueError；几何空窗口仍为 −∞。
3. 并列：新增 `check_max_indices`（前向下标须在并列集合内）、`check_max_subgradient`（非重叠窗口的集合式反向检查）、`check_extremum_subgradient`（index/scatter 的集合式反向检查）；(1,0) 与 (1/2,1/2) 都通过，(2,−1) 被拒。
4. CE-A3 的措辞改为「分母为零、有限实数目标无定义」，并加入分子为正的例子。
5. 协议：结果分三栏（文档明确条款的违反、声明解释下的差异、未定义情形的实现约定）；主比较用实际接收的标量；严格导数评分限唯一极值。
6. 测试 105 项全部通过；独立核对重跑结果不变（CE 9,965 个标量全部在区间内，池化 1,815 与 index 960 个合法配置逐项相等，0 处不一致、0 处异常泄漏）。
