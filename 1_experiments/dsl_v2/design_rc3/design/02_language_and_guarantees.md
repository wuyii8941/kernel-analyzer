# 02 新版 DSL：带类型、效应与分析契约的参照 IR（rc3，官方范围优先）

本文是从已有 Program/Op 扩展出的设计，不是对当前生产代码已实现能力的陈述。目标范围以00的官方入口为准，不受旧TTIR表限制；实现优先级可以有限，目标语言不能按当前实现删减。
数学中的“完整”指没有用实际中间值或实际路径替代应当求出的参照值，不意味着区间自动很窄。

## 1. 目标先固定

一次任务包含：源程序及编译产物 P、形状/启动/硬件配置 C、接口与存储绑定 B、输入域 D、分析策略 π、观察映射 O。
Gπ(P,x) 是声明的参照输出，K(P,x,ω) 是实际执行输出。ω只用于已声明、执行有效的随机或调度因素。

模式A：e_num = K − Gπ。
模式B：另有独立任务规格 f，e_sem = Gπ − f，e_total = K − f。
这两个模式不需要使用不同的数值内核。没有 f 不阻塞模式A。模式 B 的 f 来自版本化的独立规格库及其输入契约：每个条件先归入合法有定义、文档未规定（列出全部有依据的读法，候选须在全部输入上符合同一读法）、实数目标无定义（只记录约定）、不合法（规格拒绝）、规格未建立五类之一，再比较。
K − Gπ 中可能包含近似指令和下降错误的影响，不能先验命名成“只舍入”。

### 1.1 接口项

Gπ 与 f 都在**实际接收的输入** x 上定义。若任务发布的理想输入是 x⋆（例如发布常数 0.1，kernel 收到的是 float32(0.1)），逐项相加得到

    K − f(x⋆) = (K − Gπ(x)) + (Gπ(x) − f(x)) + (f(x) − f(x⋆))
              =  e_num       +  e_sem         +  e_interface.

三项分别报告。发布值、机器常数与运行时接收值不能在一次比较中悄悄切换；编译期常数以其存储值进入 Gπ，因此常数表示差异落在 e_sem，并须标明来源是「重算核实」还是「仅按机制推断」。

### 1.2 观察映射与下游映射

观察映射 O 选出被测输出。测量点由下游映射 D_m 给出，测量差为 d = D_m(K) − D_m(Gπ)：

| 测量点 | D_m |
|---|---|
| 算子输出 | 恒等 |
| 参数梯度 | 同一状态下的反向重放 |
| 公式更新 | 同一旧状态上的理想 optimizer 响应 |
| 实际写入 | 设备上的真实 Step，注明 CPU/GPU、foreach/fused、参数与状态的 dtype |
| 状态序列 | 冷启动、正常步、零梯度与 grad=None（语义不同）、跳步、保存恢复的短序列 |
| 影子状态 | 候选沿参照参数轨迹推进、保留自己的 moment 历史 |

训练后果（独立配对训练的 loss 差）不属于 DSL 的保证；只有声称训练改善或损害时，才需要单独的配对训练证据。

要求：D_m 在给定状态下确定，并有满足包含性的区间扩展；它本身是一段被接纳的程序（调用级区域），用同一套规则求值，不在 DSL 之外另写。实际写入在参照值靠近舍入边界时，包围可能覆盖多个可写值：保留其可靠集合并报告精度尚不足；只有参照本身或执行来源未建立时才记未建立，不能混淆，也不能任取一个值。

π逐节点说明：普通算术提升为实数；哪些配方中的量化保留；哪些位级区域保持格式语义；归约顺序是已证明无关还是明确绑定。
不能为使某程序通过，事后在其中插入隐含舍入或改变π。

## 2. 类型与结果

```text
Type ::= Real | Bool | BV(width, signedness)
       | Format(format_id)
       | Tensor(shape, Type) | Tuple(Type*)
       | Address(storage_id, address_space, byte_range)
       | Token(effect_scope, epoch) | Layout(mapping) | Descriptor(kind, metadata)
       | Event(event_id, scope) | OpaqueExternal(contract_id)
```

Real表示精确实数目标，不表示当前工作精度。数值后端可用有理数、代数数或带包围的表达式实现。
Format表示有确定格式语义的值，Bits/BV表示固定宽度位模式；二者不与Real隐式互换。

```text
Outcome ::= Finite(value_or_enclosure)
          | Special(NaN, +Inf, -Inf, signed_zero_metadata)
          | DomainUndefined(reason) | Poison(reason)
```

特殊值不是自动的错误，也不能自动转零。每个原语明确特殊值、mask和未选分支的传播规则。
数值平均查询要求观察映射得到有限实向量；DSL本身还表达整数、位模式、集合、状态、特殊值与无返回值的写入操作，不因它们不是浮点返回值而缩小语言。指针和任意bit-pattern默认不作算术bias；用户须选择有解释的观察量。不要求每个中间值都有限。
例如合法的masked attention可能使用−Inf，并通过exp(−Inf)=0得到有限输出。
`select`只选择数值结果；不能用它抹去另一个已执行区域中的非法内存访问。

## 3. 计算语法

保留SSA操作和嵌套区域，核心构造如下。名字是建议的内部语法，不要求用户手写。

```text
Region ::= let values = primitive(values; attrs)
         | map(region, tensors)
         | fold_ordered(region, initial, values; order_id)
         | reduce(region, values; law_certificate)
         | scan(region, values; associative_certificate, direction)
         | if(condition, then_region, else_region)
         | for(bounded_integer_range, carried_state, body)
         | while(condition, state, body; termination_certificate)
         | load(address, mask, other; memory_token)
         | store(address, value, mask; memory_token)
         | atomic(address, contribution; effect_certificate)
         | atomic_cas(address, expected, desired; order, scope)
         | atomic_load_store_poll(...; order, scope, progress_contract)
         | async_transfer(...)->token | wait(token) | barrier(scope, address_spaces)
         | parallel_regions(partitions; communication) | cluster_event(...)
         | asm_region(body, constraints, pack, layout; target_contract)
         | rng(seed, counter, conversion_policy) | environment_read(contract_id)
         | call(region, args) | launch_sequence(regions, memory)
         | yield(values)
```

普通元素运算、矩阵乘和dot_scaled等可以保留高层快捷操作，但须给出到上述核心的语义定义或等价证书。
任意combine表示“区域体可以任意组合已支持语义”，不是“所有combine都满足结合律”。
`if`只执行所选区域，`select`的两个SSA输入可能已经被计算；两者不可随意互换。

高层descriptor访问、block pointer、布局转换、NVIDIA/AMD矩阵指令、打包算术及各种元信息可保留为原语，但必须有到核心关系/效果的定义。不能把“当前没有展开”当成它不属于DSL。

## 4. 接纳判断：支持名字不是通过分析契约

建议判断形式：

    Γ ; Φ ; Π ⊢π P : Tensor[d,Real] ! E ▷ (termination, enclosure, refinement)

Γ：值、形状与类型；Φ：输入域与局部定义域不变量；Π：存储所有权、别名和顺序证据；E：真实的执行效应。
证据来自规则推导和明确的证书，不来自“这个程序跑成功过”。

每条RuleContract至少声明：
- 源操作+类型+属性+子区域签名；来源版本与定义。
- 参照语义、输入与异常条件、内存/控制/异步效应。
- 原语的包围实现及包含性依据。
- 有限求值的条件；获得目标精度的有效方法或模量。
- 规则替换/合并后所需的不变量与证明。
- 真正触发该签名的正例、边界和违反前提测试。

首版证书只采用小型、可检查的构造：已审阅基础引理的实例化；带分母非零条件的有理函数恒等式；
有向区间推出的范围不等式；精确整数地址映射与不相交证明；有限循环展开；所有权/token推导；
由这些子证明组成的区域证明。不能以一个CAS的“simplify成功”、一个未核查的SMT结果或字符串proof_path直接代替证书。
有理函数恒等式可以交叉相乘后比较多项式系数，但必须保留每个分母在实际使用域上非零的证据。
对更复杂解析恒等式可以扩充已审阅引理库；没有证据就不偷偷猜测。

每条接纳义务都要标明证据类型：

| 类型 | 含义 | 能支撑什么 |
|---|---|---|
| static | 对整个声明输入域 D 成立的证书 | 全域主张 |
| per_sample | 对该输入实际执行的相关事件检查，并对参照实际可能访问的路径、地址和定义域另作检查 | 只支持已覆盖事件和参照义务的该样本结论；实际单一路径不足以证明其他参照路径 |
| declared | 用户声明但未核验的域/环境前提 | 作为条件性结论的前提，不伪装已证明；解释器、证书检查器及绑定机制的可信基础另外公开 |

首个产品承诺可以是**逐样本**的，但前提必须涵盖该样本的参照求值，不是只涵盖K的实际轨迹。若实数参照的分支或地址改变，要继续解释并验证参照一侧；不得沿原捕获地址读取实际值。需要域级总性或域级均值界时，义务也必须覆盖域，不由单次动态检查外推。接纳检查不得假设K=G，否则会把要发现的实现偏离排除。

证书检查器应对有限证据终止。自动证据生成可能失败或超时，不能将“证明没找到”报告为“发现竞争”。
声明前提、静态证明和逐样本运行时检查分开。仅检查一次轨迹不能证明整个输入域满足前提。

## 5. 语言保持宽，保证按任务分开

### 5.1 精确核心 L_Q

有限形状、有界循环/无递归调用；有限有理接口值；精确整数/位操作；四则运算与已定义比较；
显式且可正确计算的格式转换；有确定顺序的fold或带有效法律证书的reduce/scan；
访存与执行效应满足已核验的不变量。除数非零、索引有效及输出有限由前提与规则保证。

对这个核心，逐步用精确有理数与位语义即可得到单点G。算得慢不能被隐藏；有限不等于预算内快。
核心里的“有理数”包含1/3等非二进有限数；只有输入机器值必为二进有理数。

### 5.2 可收紧扩展 L_C

允许exp/log/sqrt等有可靠包围的原语。包围必须来自严格方法（MPFR 加误差界、Arb 一类球算术、定向舍入的区间实现）；高精度点值加一个声明余量只能作交叉核验，不能当包围用（erf 等函数在现有工具链中尤其要注意）。每个原语在相关域上具有可有效计算的包围和连续性控制。
除法远离零、log位于正域等条件在传播前检查；sqrt在0处可用相应连续性模量，不必一律排除零。
离散使用点（比较控制、地址、取整/bitcast桥）必须满足一种条件：
1. 精确可判定，包括表达式恒等证书；
2. 有可检查的正间隔，能最终分开判定边界；
3. 虽然条件不能分开，但两分支在所需输出与状态上具有能收敛到同一点的证明。

没有这些证据时，保守并分支仍可输出可靠集合，但不能承诺任意精度的点参照。
这些任务进入“集合包围”片段 L_E，不从官方语言或现实分母删除。L_E可能仍足以确认稳健符号或等价范围，只是不保证可收紧到唯一点。舍入核验模式下只有误差契约的近似指令也属于此类，见§6.5。

L_point = L_Q ∪ L_C；L_set = L_E。它们是保证片段，不是整个DSL的语法边界。官方合法的CAS、动态控制、低层区域仍在L中，可能需要补证明/求值器，也可能只能提供集合或环境参数化目标。每个片段的数学前提预先定义，不能因某个测试失败临时改动。

### 5.3 集合和环境参数化目标

令 G_set(P,x) 包含官方契约及策略π允许的参照观察。某个具体选择g∈G_set与实现输出K比较；未知选择时不捏造唯一e_num。若G_set有限且可包围，可先形成所有允许残差的区间。若环境变量ω有声明的配对/抽样机制，也可定义G(P,x,ω)并测其指定均值。

集合结果不是数据竞争的免责：只有官方定义的有效执行才进入G_set。确认的未定义竞争单列为执行错误；没有证明并非已确认竞争。可交换且返回值不影响观察的原子路径可缩成单值，是优化特例，不是CAS等进入语言的唯一方式。

## 6. 边界构造的明确规则

### 6.1 Real与位模式

`decode_F : Format(F) -> Real/特殊值`；`encode_F,r : Real -> Format(F)`使用显式舍入、饱和与次正规约定。
Real的1/3不能直接bitcast。encode遇到无法判定的舍入边界时，需上述离散判定证据，或只返回集合。
保留格式的区域会改变G，因此报告必须列出它们；把整段改成设备格式重放不能冒称测完全部舍入bias。

### 6.2 归约和扫描

有可信order_id时，对该树/次序作精确或区间fold，输出为顺序特定目标。
没有顺序时，需要结合性与定义域闭合；只有在许可重排叶子时另要求交换性。
scan即使结合，也必须保存前缀元素顺序。
结合律证书应验证区域表达式和不变量，不能只检查名字，也不能把未证明当不成立。

Welford的可复用证书：对非空摘要a=(n,m,s)，n>0，令

    Φ(a) = (n, n*m, s+n*m*m).

标准merge中的n=n_a+n_b、δ=m_b−m_a、m=m_a+δ*n_b/n、

    s=s_a+s_b+δ²*n_a*n_b/n

满足 Φ(merge(a,b))=Φ(a)+Φ(b)。在n>0上Φ可逆，因此merge继承加法的结合性与交换性。
空摘要使用(n,m,s)=(0,0,0)和真正有定义的空分支，不能把未经保护的0/0简化掉。
这是验证表达式等价的证书模板，不是按Welford的kernel名称接受所有写法。

### 6.3 内存与并发

使用storage_id、生命周期、地址范围与元素映射建立同一参照存储。观察值相同不证明是复制。
对并发冲突访问，需要相应线程/作用域的happens-before关系或互斥/所有权证据；同一program编号不等于同一线程。
异步发起、完成、缓冲复用必须通过token连接。descriptor/TMA不能只保留地址计算而丢弃异步效果。

原子最终折叠需要：已知初始值、封闭贡献集合、贡献与调度无关、无交错的非原子访问、返回旧值不影响观察或贡献，
以及所需代数律。否则需显式顺序与事件结构证明，或返回调度相关集合；不能从“atomic_add可结合”推出整个程序唯一。

这些规则证明参照的模型内效果。实际设备执行无越界/无竞争还需低层分析、正确性假设或执行检查的支持，
不能把高层类型证书当成编译器和硬件全部正确的证明。检测到不一致先诊断，不自动转成可平均的随机性。

### 6.4 参照循环

声明上限必须是源程序本身的上限，或可验证的参照终止界。
例如实数t=1、while t>0: t=t/2不终止；实际浮点执行下溢后终止，不能用其次数冒充参照次数。
截断模式可以另定义G_T，但必须明确改变了目标。

### 6.5 近似指令、外部数学库、融合与矩阵乘精度属性

**近似指令与外部数学库。** 数值差异模式下，将有文档目标函数的近似操作提升为该函数；普通与显式舍入指令使用同一个π规则，不能只因函数名带后缀就临时改变语义。未知extern的语义通过插件补充，不根据符号后缀猜测。[S06,S13,S15]

舍入核验使用实际ISA/库契约：记录 `metric={ulp, absolute, relative, piecewise}`、误差锚点、输入域、格式、FTZ、特殊值、ISA与GPU条件。不能统一写成g(x)·(1±ε)：cos类误差可能是绝对界，div类可能是ulp界，而且某些输入域只承诺best effort。纯数值模式可比较精确数学函数，不必知道近似微码；规范一致性模式缺少有效误差界时必须标为证据缺口。[S15]

**融合与矩阵路径。** 实数目标下(a·b)+c与fma相同，但浮点核验需要绑定实际下降产物或保留合法选择集合。`inputPrecision`的全部官方取值按版本收集，包括该版本定义的tf32、tf32x3、ieee、bf16x3、bf16x6；不要限定为旧三个枚举。maxNumImpreciseAcc、scale布局和合法类型均属于签名。[S06]

不能把“所有TF32都是截断”“所有arith.divf总降低成同一近似指令”写成跨后端定律。这些是版本、选项和下降路径的事实；应由编译产物核对，按具体ISA转换规则建模。未知硬件累加树不阻塞精确点积目标，但阻塞逐位模拟或特定节点归因时需明确说明。

**格式与块缩放。** FP4/FP8等打包、MX scale原始payload、轴、tile、饱和、非有限编码和各后端转换均纳入。有限有理解码可精确计算，整个异步dot_scaled/MFMA程序仍需处理布局、内存与事件，并非“解码精确所以全程序完整”。[S09,S11,S12]

### 6.6 需要属性守卫的结构操作

- tt.reshape/对应API的 allow_reorder、cat的 can_reorder：保持官方许可的元素关系。若观察对允许重排不变可得到单值；否则绑定可信的具体映射或报告允许集合。不能因缺单值证书就从DSL删除此构造，也不能把任意归约都认作置换不变。[S14]
- arith.maximumf/minimumf 传播 NaN，maxnumf/minnumf 忽略 NaN；clampf 的 propagate_nan 属性同理。名字相近的操作不能共用规则。
- tt.join、split、trans、broadcast、expand_dims、splat，以及不允许重排的cat：精确元素映射。分布式布局还需register/lane/warp/CTA/cluster映射和重复副本一致性。[S03,S07]
- tt.gather 与数据相关的索引：逐样本检查索引有效（per_sample）。
- argmax/argmin（值与下标二元组）：按源契约处理tie-break；规定最小下标/稳定性时是确定值，未规定时才用集合。浮点NaN/有符号零另遵守具体操作。

### 6.7 随机数

Philox等位生成部分在给定seed、counter、offset与轮数时有精确BV语义；rand/randn还包含位到浮点及正态变换，不能整体都叫整数计算。参考是否保留这些转换由π预先决定。若r与p都是确定Format值，dropout的r<p可精确判断；若π使r为实数区间，仍需离散判定证据。随机舍入需将随机位和概率/比较方式纳入目标与抽样契约，不把经验均值当精确参照。所有这些API均留在DSL目标范围。[S02,S20]

### 6.8 排序、top-k 与直方图

tl.sort 由比较加选择的排序网络组成：比较是离散使用点，需要 §5.2 的判定证据，否则两支取凸包。键相等时先查源契约是否要求稳定或有tie-break；有则必须满足，无才使用集合。payload与索引都属于观察，不能只比较排序后的数值。histogram的整数计数仍需检查有效输入域、bin边界和计数位宽。


### 6.9 官方低层模块与效果组合

经典Triton和Gluon分别导入。Gluon提供显式布局、共享存储与warp specialization，NVIDIA/AMD操作不是“本轮看不到所以不支持”。采用统一的分布式Tensor/Descriptor与事件核心，target专有部分由插件定义。[S03–S12]

高层`descriptor_load`返回可使用的tensor值时，其语义不是让调用者额外提交未出现的wait；低层TMA/TDM/async_copy必须解释实际发起、group/phase、完成和proxy可见性。两层以效果保持的展开连接。[S06–S10]

mbarrier不能只保存一个epoch：根据具体操作记录arrival、transaction bytes、phase、参与者与scope。warp specialization区域并发开始、结束汇合；不能串行执行所有partition后宣称已验证实际访存安全。cluster、CLC和grid dependency必须进入事件/任务分配模型。[S07,S10,S11]

原子CAS、exchange、load/store/poll都有正式目标关系，不能整体列语言外。有限合法交错可穷举或通过偏序归约/协议摘要处理；无限poll/无进展要说明终止或公平性条件，没有则报告证明缺口或观察到的超时。非交换不等于数据竞争。[S06,S15]

### 6.10 内联汇编与官方工具操作

必须区分逐元素`inline_asm_elementwise`与逐线程`ttg.inline_asm`；处理constraints、pack、寄存器映射、谓词、多个输出、共享/全局存储及副作用。逐指令的ISA组合解析是目标，不以少数单行正则构成语言上限。未知片段保留未实现项；无语义来源不能猜测。[S07,S13]

`tti`、Proton及日志/时钟读取也登记在官方目标面。只有证明对当前观察无数据/控制/存储影响时才能擦除；插桩改变调度分布的可能性须与原始测量分开。FpSan载荷一致不能作为纯舍入证书。[S16–S18]

## 7. 正确性论证

以下是建议实现应满足的条件命题及证明结构，不宣称生产代码已有形式化证书。

### 命题A：精确核心的求值总性

给定有效接纳推导，P∈L_Q、x∈D，在理想无资源上限计算模型中，求值有限结束，返回精确G。
证明：循环和调用界给出有限展开；每个节点的运算及分支都可精确决定；已验证访存读到其唯一合法前驱值。
按展开长度归纳得到每一步存在唯一结果，并保持定义域与存储不变量。原子由合法fold替换证书处理。

### 命题B：组合包含性

设每条抽象原语F#都满足F(γ(A))⊆γ(F#(A))，并保持域与存储不变量。
则对有限展开程序，输入与初始存储被包含⇒最终观察G被包含。
证明：基本算术按原语规则；顺序按两次包含关系的传递；循环有限归纳；分支合并覆盖真实分支，
且返回值与存储状态同时合并；map/fold按元素/节点归纳；load/store依赖已证明的地址映射和前驱写入。
不能只在数值DAG上归纳而跳过内存、控制或编译导入。
这是抽象解释的标准构造，不是新的通用完备性定理。[P1]

### 命题C：可达分辨率

对L_C中的程序，连续节点有有效误差传递模量，离散节点具有上述证据，循环有限；
因此对任意η>0可以计算足够的工作精度/局部误差分配，使width∞(R)≤η。
证明：在确定的有限计算/状态展开上逐节点分配精度；连续模量使局部误差传到输出的预算可控；
离散证据给出有限的判定阶段或等值分支证明；有限个要求取联合足够精度。
实际实现若把区间固定为float64端点，或使用不可消除的近似契约集合，则不满足任意η保证。

### 命题D：导入忠实性

对声明的源片段S_v，TTIR→内部IR的转换必须保持π选定的源声明语义、类型和效应：

    Gπ(P,x)=Gπ(Import(P),x).

证明义务逐源操作给出，其组合仍依赖区域作用域和控制/存储映射；不是证明实际K与G相等。
这项连接不能由“内部解释器算得对”代替。未知源属性不能静默忽略。

### 资源与输出失败

上述总性是数学计算模型的总性。预算内产品保证另声明尺寸、步数、目标η和成本约束。
超预算仍是覆盖/服务失败，应计入；不能改成已建立并返回捕获值。
参照有限也不保证K有限。实际NaN/Inf或崩溃单独报告，不能删掉后仍声称估计原总体。

## 8. 与统计连接：可测不等于必检出

### 8.1 先固定查询

一次均值结论由五项确定：比较对象（模式 A 的 K − Gπ，或模式 B 的各项）、测量点 D_m、输入或状态的分布、方向规则、独立抽样单位。

方向规则分两类，分开报告：
- 固定方向：w 在确认数据之前固定，检验的是均值向量的一个分量；
- 对齐：w = r/‖r‖ 随参照输出变化，检验的是对齐作用。两者不能互相改写。

独立单位要写明：固定状态下的不同 batch、不同训练历史、独立 run 是不同的单位；同一历史上的多个 checkpoint 不是独立单位，跨历史推断时先在每条历史内汇总。默认输入来源是真实训练中捕获的状态，按步数分层抽样；合成输入另行声明其总体。样本量若依据结果追加，必须用事先声明的有效序贯方案，不能反复看普通 p 值再停止。

方向、分组与归一化在开发数据上选定，确认数据上冻结。检验族在运行前登记；无法计算的格在族中保留，按事先规定的保守方式处理，不能事后缩小族。

### 8.2 端点包围与幅度界

令 a_i = ⟨K_i − G_i, w_i⟩。数值求值给出 a_i ∈ [l_i, h_i]。

若声明总体上已证明 |a_i| ≤ M，可先截断端点：

    l'_i = max(l_i, −M),  h'_i = min(h_i, M).

截断后仍有 l'_i ≤ a_i ≤ h'_i，而且 l'_i、h'_i 都落在 [−M, M] 内。如果在端点随机变量上直接应用界，截断保证其取值范围成立；也可以直接对有界真实a应用Hoeffding，再用逐样本包围夹住样本均值，此证明不要求未截断端点自身有界。若截断交集为空，说明数值证据或M冲突，必须报错，不能产生区间。

M 必须覆盖整个声明域，不能取样本最大值。它的一个来源是逐输入的误差预算：例如顺序求和满足 |Ŝ − S| ≤ γ_{n−1} Σ|x_i|，所以 M 存在的前提是声明域上 Σ|x_i| 有上界。输入分布无界不自动推出误差无界：若输出被饱和或观测有界，仍可能有M。若所需目标确无已知统一界，则可采用明确条件的近似路线，或另声明已知方差/尾部假设的有效方案；不能由这批样本预算推出总体界。

### 8.3 有界路线（Hoeffding）

逐步推导：
1. 样本独立同分布，l'_i ∈ [−M, M]，取值范围长 2M。
2. Hoeffding 单侧不等式：P(mean(l') − E[l'] ≥ t) ≤ exp(−2n t² / (2M)²) = exp(−n t² / (2M²))。
3. 令右边等于 α/2，解得 t = r_n = M·√(2 ln(2/α) / n)。
4. 于是以至少 1 − α/2 的概率 E[l'] ≥ mean(l') − r_n；对 h' 的上侧同理。
5. 由 l'_i ≤ a_i ≤ h'_i 得 E[l'] ≤ μ ≤ E[h']，再用并集界：

       Pr{ μ ∈ [mean(l') − r_n, mean(h') + r_n] } ≥ 1 − α.

经验 Bernstein 界在方差小时更窄，可以作为后续选项；首版先接通 Hoeffding。

### 8.4 近似路线

没有 M 时，可用端点 t 区间：以 ℓ 的单侧下界与 h 的单侧上界组成区间。它要求独立单位、有限方差，以及 Student 化近似在该分布上适用；「有限方差加 n ≥ 2」本身不给出保证，偏斜与稀有大值下的失效范围要随结果一起报告。

### 8.5 两个判定轴与灵敏度

- 非零轴：有效区间整体在零的一侧。
- 等价轴：区间落在 (−δ, δ) 内，或通过对应的两个单侧检验。δ 必须事先声明并写明来源（任务精度预算、可接受做法的尺子、剂量反应标定之一），不同测量点的 δ 不能沿用同一个数。

两个轴可以同时成立（非零但足够小）。未确认时附最小可检出效应：它是按冻结设计算出的灵敏度，不是已经排除的效应；要排除效应只能靠等价轴。多重比较用 Holm 控制族错误率，确认轮与复现轮分开报告；族内Holm不表示各族统计独立，也不自动控制全研究的错误率。跨族/跨轮主张使用预登记的全局或层级规则，不能事后重新挑族。

### 8.6 整向量的保守路线

若 e_i ∈ R^d，坐标 j 有总体界 M_j，各坐标截断后分配 α/d：

    μ_j ∈ [mean(l'_j) − r_j, mean(h'_j) + r_j],  r_j = M_j·√(2 ln(2d/α) / n),

同时以至少 1 − α 的概率成立，不需要坐标之间独立。原点被这个盒子排除，即确认均值向量非零；盒子的最大范数小于 δ，即确认在该范数尺度下足够小。高维时它很保守；学习方向与分组可以提高功效，但有限几个投影未检出，不能写成整向量为零。

### 8.7 执行随机性、退化与过滤

- 每个输入至少重复启动两次并逐位比较。结果不同且程序已接纳（例如可交换的原子更新），就在每个输入内对 r 次执行的投影区间取平均，再以输入为独立单位推断（原子程序默认 r = 8）；不能把执行次数或输出坐标当作独立样本。
- 竞争不是随机性：已证实的非原子冲突且缺少合法顺序/同步保证，使对应执行不能进入均值统计。合法原子交错按其顺序/集合契约处理。证据不够时记执行有效性未建立，不自动宣称竞争。
- 没有有效观测或统计计算失败时返回未建立。样本方差为零只意味着普通t统计量可能退化，不应禁止有界Hoeffding：该界在s=0时仍有正宽度，可能合法检出强作用。不得由s=0自动返回p=0。
- 实际输出非有限单独报告为数值失败。过滤掉任何样本都改变了总体，必须声明；不能删掉困难样本后仍声称估计原总体。

## 9. 给用户的稳定接口

```text
import(source, artifact, boundary, policy) -> Program
admit(Program, domain, certificate) -> Accepted(profile, obligations, identity)
                                      | NotAdmitted(reasons)
evaluate(Accepted, input, target_width, budget) -> ReferenceResult
measure(ReferenceResult, actual_output, query, sampling_contract) -> Report
```

程序是否接纳、参照是否完整、精度是否达到、统计是否有效、是否非零是独立字段。环境参数化结果还须列出绑定/抽样的环境契约；未指定环境分布不产生唯一均值。报告至少包含：

| 字段 | 内容 |
|---|---|
| 接纳 | L_Q / L_C / L_E / 环境参数化 / 尚未接纳（附全部阻塞原因）；每条义务的证据类型 |
| 参照范围 | kernel 级 / 调用级；边界输入的来源证明（存储身份与生产者，不是数值相等） |
| 服务路径 | 1 调用级完整自动参照；2 kernel/明确边界的自动参照；3 外部规格或实现对照；4 当前未建立均值比较。历史κ不直接等价于路径：complete也可能只是kernel级。外部f若有严格包围，也不是未认证参照。 |
| 精度 | 目标宽度、达到宽度、能否继续收紧 |
| 执行 | 重复启动是否逐位一致；竞争检查结果；非有限输出 |
| 统计 | 查询五项；路线（有界 / 近似）及其前提；两个轴的判定；最小可检出效应 |
| 模式 B | e_sem、e_total、e_interface；四栏：文档明确条款的违反、声明解释下的差异、未定义情形的约定、数值失败 |
| 常数 | 常数与接口差异，以及归因是「重算核实」还是「机制推断」 |
| 黑箱诊断 | 第3路径可附精度响应诊断；它只能提示机制，不能恢复缺失的G，也不能证明语义差异为零。 |
| 成本 | 编译、捕获、参照、统计四段耗时；接入的人工 |

不改变现有历史 K_R 字段；新输出附 target_id 和符号映射（K_R → Gπ 与其包围 ℛ），避免历史结果失去可复现性。


## 10. 集合参照也可提供有限但有效的bias信息

设有效参照结果集合G_set(x)的每个允许投影都落在区间中，对实际输出K构造残差上下界l(x),h(x)。则每个兼容的参照选择g(x)都满足l(x)≤〈K−g(x),w(x)〉≤h(x)。
若采样端点由独立输入按冻结规则生成、端点经已证明的公共M截断，则§8.3的同一事件给出：

    对全部兼容且可测的选择g，E〈K−g,w〉 ∈ [mean(l)−r_n, mean(h)+r_n]。

这是对所有允许目标的稳健包围，不是在未声明的调度分布上凭空定义一个唯一均值。只有数值求值宽度能随精度减小；规范固有的多值宽度可能保留。一次固定seed或一次观察到的交错，不证明其它交错也相同。

## 11. 推进覆盖但不改变目标的三条约束

1. 不为绕过硬构造而自动将整段切回Format重放；否则可能人为使K−G趋零。
2. 不把实际执行的分支/地址/原子顺序当成参照在所有可能路径上的值；条件化模式另命名。
3. 不把尚未编码的Gluon/AMD/CAS/描述符操作排出目标语言。保留语言定义、实现欠账和设备未测三列。

## 12. 编译假设和合法域

`assume`、multiple_of/contiguity等声明不单是可随意擦除的速度提示。保存其源条款，按具体API区分可证明事实、调用前提和纯性能选择。合法输入不能靠看到候选错误再排除。整数overflow flags、poison、未选select操作数与副作用的区别必须按源IR处理。[D1,S02,S06]
动态shape、autotune、num_warps/num_ctas、运行时标量和实际后端构成编译实例身份。一个实例的观察不证明整个配置空间。缓存、守卫复用及版本迁移另有证据，不能把当前源码当成所有版本的共同语义。
