# 00 官方范围优先：目标语言不由当前实现倒推

版本：v2-rc3，2026-10-09。本文定义下一版设计目标，不宣称已有相应实现或机器证明。
输入依据是上传的 rc2；外部依据是本次读取的 Triton 官方文档及官方主线提交 `e50b186e8bd2d16ae3f564311ef868aa3bd45a2d`。
旧仓库 `5b9ac32` 与 Triton 3.6.0 是迁移基线，不是新语言的上限。[S01–S05]

## 1. 三个范围，不混成一个“支持”

**官方目标面 U**：选定官方提交及其 LLVM 依赖中，经典 Triton、Gluon、NVIDIA/AMD 路径可使用或生成的操作、类型、属性、区域、效果、外部函数与运行参数。条件由官方版本、目标硬件和API契约决定，不由当前求值器决定。

**参照语言 L**：能够表达这些构造的组合数学语义与执行关系。一个构造可能有唯一结果、允许结果集合，或显式外部环境参数。未知外部函数保留契约接口，而不是猜测函数；有语义但未实现是工具欠账。L 的语法可表达，不等于其每个程序已经取得了可测证书。

**已认证分析 A**：导入、求值与查询实现已经兑现的范围。需要明确前提、资源和证据。A 内失败是实现缺陷或明确资源失败，不能临时从分母移除；U 内但 A 外是尚未完成的覆盖工作，不能反过来删除 U。

目标是使 A 尽可能扩展到 U 中有定义、可分析的实例。不能把“都分类了”计成“都测得出来”。

## 2. 官方入口必须全部留在目标清单

| 入口／层 | 新版处理 |
|---|---|
| `triton.language`、tensor/descriptor 方法、JIT和编译期配置 | 主目标，包含隐含类型规则与编译假设 |
| Gluon及显式分布式布局、共享存储、子区域 | 主目标，不再标语言范围外 |
| NVIDIA：官方导出的 Ampere/Hopper/Blackwell/Rubin 子模块 | 独立target profile，实施与硬件验证进度另列 |
| AMD：官方导出的 CDNA/RDNA/gfx 子模块 | 独立target profile，不能用暂无AMD设备缩小DSL |
| `tt/ttg/ttng/amdg/gluon/nvg/nvws`及相关MLIR层 | 依语义或已验证展开接入；低层路径不自动由TTIR覆盖 |
| `tti/proton/proton_gpu`等验证与测量操作 | 记录数据、控制、日志及同步效应；可证明不影响所选观察时才擦除 |
| libdevice、OCML、inline asm与外部设备调用 | 符号/ISA插件；未知实现标缺证据，不编造实际函数 |

这些命名空间来自官方导出和方言索引。并非各后端对所有类型与参数都可执行；目标限制必须附版本和架构条件。[S01–S05,S07–S18]

非Triton的CPU任意程序、整套Python动态语义、整个LLVM生态，不因上述目标而自动纳入。若被实际导入路径使用，其具体调用/下层构造仍须出现在依赖清单，不可静默忽略。

## 3. 不同语义保证，而不是把难题删出语言

- **单值精确**：有理数、位模式以及已核验的有限离散结构。
- **单值可收紧**：初等函数及具有有效精度控制、离散判定证据的组合。
- **集合包围**：官方允许多个结果、次序未绑定、近似指令只给误差集合。需要如实返回不可消除的语义宽度。
- **环境参数化**：调度、时钟或随机源作为显式参数；固定、观测或抽样的作用域不同。
- **尚未建立**：语义插件、来源或证明缺失，或资源不足。这是覆盖缺口，不是成功路径。

集合包围也可能足以支持均值符号。例如所有允许参照都给出正差时，无需先选唯一参照。反之，集合跨零时不能任意选一个结果签发非零结论。集合宽度与求值宽度分开。[本稿推导]

## 4. 每个官方构造都应有一个实施回答

回答至少包含：来源版本、合法签名、目标语义、唯一/集合/环境参数、所需证明、通用求值模块、实现状态、触发测试和设备验证状态。

TMA不是因为当前无token实现就出语言；CAS不是因为不可交换就出语言；Gluon不是因为当前没有导入器就出语言。可以排实施先后，不能把延期伪装成理论不适用。

实现优先级可按现实普查排序，但定义分母必须先于普查结果和工具支持观察。官方新增项即成为新版本差集；不得先等用户kernel触发才承认该项存在。

## 5. 这次核验完成到哪里

本包完成：rc2逐段审阅；官方入口/方言/关键属性文档对照；148项经典语言`__all__`的固定源码转录；61项官方能力族的需求矩阵；所有125项旧检查点的保留或更正去向。

没有完成：官方源码TableGen全实例化、安装后的本地注册表导出、全部libdevice/OCML符号枚举、所有Gluon子模块的方法枚举、构建与GPU验证。不可报告“官方全量签名已核对”或新实现支持率。

`coverage/official_surface_matrix.json` 是需求族账本，不是指令全集。`coverage/official_public_exports_snapshot.json` 是一个模块的公共导出记录，不是全语言操作计数。`tools/reconcile_official_inventory.py` 用于取得真实的三方清单后检查差集，不会因清单缺失返回“通过”。
