# 研究出发点与贡献边界

## 从 FlashAttention 论文出发

[Qiu 与 Yao](https://arxiv.org/abs/2510.04212) 已经把具体舍入偏差、backward
传播、训练失稳和针对性修改联系起来。我们的起点不是“以前无人关注方向”，而是
沿用其**具体数学成因 → 参数更新 → 训练后果 → 修改验证**的逻辑，并将它扩展为
对未知具体实现也可复用的数值偏差分析与有界判断。

不把该论文的特定 attention 机制推广为所有失稳的必要条件，也不要求我们的
每个案例最终崩溃。loss 分叉可以出现而不持续恶化。

## 本项目要形成的贡献

1. 用相同的三阶段方法分析不同 Triton、常规和混合训练实现，分开总差异、平均方向、
   相对缩放和剩余结构。
2. 区分固定集合与随机状态总体，在声明参数、状态和工程范围内给出等价、超范围、
   证据不足或无法判断的结果。
3. 对代表案例写出具体数值差异进入 gradient/update 的条件，并用局部修改检验预测。
4. 对选定修改做配对训练，分别报告轨迹非同一、质量、成本和稳定性。

Triton 是重点对象，但不能把常规实现默认成真值；混合路径也可成为正式案例。
推导、预测、测量、干预、loss 后果分别列明证据，不由一个完成状态互相替代。

## 不作的首创或价值主张

不声称首次研究有符号数值偏差、首次测 gradient/optimizer、首次区分均值与波动、
首次做训练差分测试或首次用随机舍入减轻 bias。不能把其他方法概括成“只能发现
崩溃”或“只做 allclose”，也不能仅因 bias 很小就宣称它更危险。

跨工作比较须核对具体实验边界，不能只靠关键词拼出“首创”。训练价值不一定要求
灾难性失稳，但 loss 非同一、稳定质量下降和训练效率改善是不同结论。

## 辅助方法的位置

三阶段测量、效应量和等价检查构成统一分析方法；短筛只用于降低确认成本。
求和顺序的平均误差只能预测特定 reduction 成因。FP32 对 FP32 的顺序
实验与 BF16 对 FP32 的累加精度实验分别报告，不能互相充当因果闭环。

当前可争取的是**跨具体实现复用的训练数值分析、结论范围和诊断所指导的修改**；
并不声称已经对任意算子证明训练正确性。
