# 研究出发点、同行对比与贡献边界

核查日期：2026-09-07。本页是公开文献比较与目标定位，不是实验完成报告。
以论文公开版本和作者代码为依据；未独立复现同行的实验。近期预印本不统称为
已经同行评审的成果。主线和完成状态分别见[当前主线](current_mainline.md)与
[验收范围](new_mainline_execution_status.md)。

## 文献核查后的判断

本次核查未找到完整实现以下联系的近邻工作：

> 跨具体 kernel 实现复用同一训练偏差检验，在真实 backward 和 optimizer 中
> 测量系统性更新作用，以有条件的机制推导预测局部修改，再验证修改的训练后果。

因此，这条主线有可辨认的创新空间，适合继续推进。这个判断不等于证明全部公开或
未公开工作均不存在，也不等于当前仓库已经完成贡献。“框架、Triton、理论、强训练
结果”是四个共同目标，不能仅凭关键词组合声称首次。

## 最接近的工作与实际区别

下表比较各工作的主要研究问题，不因正文没出现某个关键词就断言它没有相关能力。

| 工作与核查来源 | 已有工作覆盖的内容 | 我们需要建立的具体区别 |
|---|---|---|
| [Qiu–Yao，FlashAttention failure，v4](https://arxiv.org/html/2510.04212v4) | 具体舍入偏差、梯度传播、训练失稳和针对性修改 | 从特定 failure 的机制研究走向不同实现可复用的统计偏差分析；不能声称首次把 bias 与训练失败相连 |
| [RENDER / When AllClose Fails，ASE 2025](https://qi-zhan.github.io/assets/pdf/ASE2025zq.pdf) | 对包括 Triton 的真实深度学习计算估计舍入误差并诊断问题 | 从误差是否符合舍入界，推进到跨训练状态的系统性 update 作用；Triton 与数值分析的结合不是新概念 |
| [TTrace，v2](https://arxiv.org/html/2506.09280v2) | 训练实现对齐、动态 tolerance、activation/gradient 与 optimizer 前后参数比较 | 不以“首次测 optimizer”区分；应检验方向/缩放结构，而不只估计正常数值误差范围 |
| [OpScanner，作者代码](https://github.com/wzzll123/OpScanner)；[作者出版记录](https://ztw33.github.io/publication/2025-10-21-wen2025study) | 分析算子精度转换，代码包含 BF16/FP32 算子引起的训练权重差异测量 | 内部精度选择与训练权重变化已有先例；我们还须识别系统性偏差及其机制。此次未取得出版社全文，不据代码概括全部论文能力 |
| [noisefloat，v3 预印本](https://arxiv.org/html/2607.25494v3) | 统一随机算术分析工具、有效数字、算子定位与训练过程跟踪 | 它测随机算术下的数值可靠性；我们测具体 candidate/reference 差异在真实训练语义中的可复现平均作用 |
| [Correcting Stochastic Update Bias，v1 预印本](https://arxiv.org/html/2605.20756v1) | 预条件 optimizer 的统计偏差、修正、理论与语言模型训练结果 | 它的偏差来自随机梯度/预条件器的统计关系；我们研究具体数值实现替换所产生的差异 |
| [UFP4，v1 预印本](https://arxiv.org/html/2606.20381v1) | FP4 shrinkage 的机制、对齐/剩余分解与训练方案 | 缩放偏差和分解本身不是我们的贡献；区别在跨实现统一检验和跨训练阶段解释 |
| [Contract-Grade Verifier，v2 预印本](https://arxiv.org/html/2608.12700v2) | GPU kernel 检查器、Triton 实验、数学依据、批量审计及 backward 训练验证 | 已与四目标的表面组合接近；主要检查计算合同，不是跨训练状态的系统性 update 偏差及其统计等价性 |

尤其需要同时对比 TTrace、RENDER、OpScanner 和 noisefloat，不能只与特定低精度
训练论文比较。已有工具会检查静默数值问题，不应概括成“传统方法只能抓到崩溃”。

## 四个共同目标如何形成贡献

1. **框架、机制和工具都有。** 接入不同家族时复用比较状态、三阶段测量、统计计算
   和报告；代表案例说明何种数值选择、何种条件导致不抵消，并据此给出修改预测。
   不以更大覆盖计数替代机制，也不每例重新选择能过线的分数。
2. **真实包含 Triton。** 主要机制实验和修改定位到手写或编译生成的 Triton 计算。
   常规实现可作 candidate，混合路径如实记录；实现语言不决定正确性角色。
3. **统计学理论完备。** 对实际声称的偏差、区间或等价结论给出对象、假设和错误
   控制，生产与校准一致。不要求任意训练分布的无条件定理，也不把增加置信区间
   本身当作新理论；现有总体校准缺口仍是未完成项。
4. **训练后果有实际幅度。** 优先解释可复现的数值性训练崩溃并验证修改有效；没有
   崩溃时，仍争取足够有意义的 loss/perplexity、稳定性或固定质量下的训练成本变化。
   幅度标准在新确认前声明，小差异和无收益仍完整报告，不能事后降低目标来过线。

这样的组织并不奇怪：已有机制论文连接分析、修改和训练结果，已有工具论文建立
可复用测量。我们的贡献需要证明两者在同一偏差对象上真正连接，而不是并排展示。
训练价值也不只来自崩溃：[AISTATS 2025 随机舍入工作](https://proceedings.mlr.press/v258/ozkara25b.html)
联合验证了训练质量、吞吐与显存，支持把质量与成本作为实际结果，但不证明本项目
已经取得同类收益。

## 可争取的论文主张与当前缺口

目标主张是：

> 面向具体 LLM training 实现，我们建立以 Triton 为重点的可复用偏差分析框架，
> 用同一测量与统计方法追踪数值差异怎样形成系统性参数更新，以机制推导指导局部
> 修改，并验证有实际意义的训练后果。

只有对应证据完成后才将目标写成成果。当前生产中的 Q-only 固定集合分析不等于
完整偏差检验或总体统计保证；已有 Liger 小幅 loss 分叉也不等于强训练后果。
仅仅“接入更多 Triton → 计算 update RMS → 添加区间 → 找到微小 loss 不同”，
不足以建立上述完整创新。

不声称首次研究有符号数值偏差、首次测 gradient/optimizer、首次区分均值与波动、
首次做训练差分测试或首次用随机舍入减轻 bias。不承诺自动理解任意 kernel、自动
生成正确参考或证明任意未来训练安全。正式首创比较限定为本次已核查工作；若后续
出现直接重合文献，应更新区别而不是不断堆叠条件保住“首次”。

## 保留原方法，不另造统计主线

Q、M、整体缩放和正负响应分解继续按[方法](method.md)定义，旧实验阈值与标签不改。
原坐标能量是基本约束，方向检验不是全空间上界；统计保证不足的部分继续研究，
不靠改名成描述性工具宣称目标完成。求和顺序的平均误差只服务特定 reduction
预测；它与不同精度实验不能无说明合并为同一次机制验证。
