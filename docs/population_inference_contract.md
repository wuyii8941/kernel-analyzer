# 随机训练状态总体：可证明范围与不能绕过的边界

本框架不再把“小样本 t 区间看起来正常”当作随机训练状态总体保证。总体输出分成
三个不同问题，程序根据协议选择对应入口；不能在看到结果后互换。

| 问题 | 可执行方法 | 保证所需条件 | 条件缺失时 |
|---|---|---|---|
| 固定状态集合的总 update 差异 | 直接计算原坐标 (Q_{\mathcal S}) | 集合、参数范围和实际写入有效 | `INVALID/PARTIAL` |
| 随机状态总体的平均能量 (Q=\mathbb E X/\mathbb E B) | 对 (X-\delta^2B) 的有界 Hoeffding 检验 | 独立单位；观察前可证明的 (X,B) 上界 | 不签平均 (Q) 总体证书 |
| 超过逐状态 RMS 范围的状态比例 | 精确二项单侧界 | 独立同分布单位；正的 repair-energy 下限 | 不签超界比例证书 |
| 预声明方向内积为正的状态比例 | 精确二项单侧界 | 独立同分布单位；方向与零值处理在观察前固定 | 不签方向出现比例证书 |

后两项不是同一个结论。超界比例不控制少数超界状态的幅度；平均能量不直接说明
多少状态超界。

## 为什么无条件的有限样本平均能量证书不存在

令 (B=1)，目标边界为 (\mathbb E X=\delta^2)。对任意有限样本数 (n)，取

\[
X=\begin{cases}
0,&\text{概率 }1-p,\\
\delta^2/p,&\text{概率 }p.
\end{cases}
\]

这个分布位于不等价边界，且所有矩都有限；但 (n) 个观测全为零的概率是
((1-p)^n)。令 (p) 足够小，这个概率可以任意接近 1。因此，任何仅凭有限样本、
又会在全零观测上签发等价的方法，都无法在所有无界非负分布上统一控制错误通过率。

这不是某个 bootstrap 实现的问题，而是缺少总体尾部信息时的识别边界。可接受的
处理只有三种：事前给出可审核的能量上界；改问可由精确二项方法回答的超界比例；
或者明确采用带矩条件的大样本近似而不声称有限样本统一保证。

## 当前完成到哪里

- 固定集合原坐标 (Q)：已进入默认分析，并覆盖所有未被投影看到的方向。
- 有界总体平均 (Q) 与 aligned scaling：生产实现和高维合成路径已通过；普通
  LLM training 尚没有自动可用且有检出能力的能量上界。
- 总体超界比例：精确有限样本实现和高维合成路径已通过；AdamW8bit 已在一个声明的
  固定 checkpoint 经验 token 分布上完成 32 个独立 gradient-history 单位。32/32 超过
  1% 参数写入 RMS，超范围比例的一侧 95% 下界为 91.06%。
- 总体方向出现比例：AdamW8bit 在另一组事前抽取的 32 个独立 gradient history 中，
  candidate-reference 参数写入与 FP32 AdamW 正常写入的内积均为正；出现比例的一侧
  95% 下界为 91.06%。整体 aligned ratio 的描述值约为 0.0756%，所以这个结果只说明
  预声明方向的符号稳定，不是方向幅度、向量均值或实际重要性保证。
- 原 studentized 平均能量方法：保留为失败与大样本研究记录，不签有限样本证书。

因此，**总体统计不再被定义成一张无条件万能证书**。当前已经闭合两条可执行路线：
有观察前能量界时检验平均能量 $Q$；没有可用幅度界时，检验逐状态超界比例。
后一条已有一个真实 AdamW8bit history 总体结论。普通 LLM training 中平均 $Q$ 的
实证应用仍缺少有检出能力的观察前能量界，这是该 estimand 的适用限制，不是可以靠
继续调区间消除的实现缺口。后续每个总体实验必须先声明要回答哪一个问题；条件不满足时
框架返回不作判断。

自动入口：

```bash
python scripts/run_training_numerical_analysis.py population-bounded-mean RAW.json PROTOCOL.json OUTPUT.json
python scripts/run_training_numerical_analysis.py population-exceedance RAW.json PROTOCOL.json OUTPUT.json
```

多案例中“至少一个超范围”的报告仍需按预声明 family 使用 Holm 等校正；单案例
等价判断中，必须通过所有必要条件的组合使用 intersection-union 逻辑，不靠“没有
显著”推断安全。
