# β₂ 扫描的事前预测（运行前提交）

机制：bf16 的半个 ulp 相对大小在 2⁻⁹（尾数接近 2）到 2⁻⁸（尾数接近 1）之间。v·β₂ 的衰减量为 (1 − β₂)·v。

- 1 − β₂ ≥ 2⁻⁸（β₂ ≤ 0.99609）：对所有尾数，衰减都不小于半个 ulp，衰减被保留，**不出现棘轮**；v_bf16 / v_fp32 在 1 附近
  起伏，不随步数单调增长。
- 2⁻⁹ < 1 − β₂ < 2⁻⁸（0.99609 < β₂ < 0.99805）：只有尾数较大的 v 能衰减，**部分棘轮**，增长慢于 0.999。
- 1 − β₂ ≤ 2⁻⁹（β₂ ≥ 0.99805）：衰减对所有尾数都被吃掉，**完全棘轮**，v 只增不减。

预测的取值：β₂ ∈ {0.95, 0.98, 0.99, 0.995} 不出现棘轮；0.997 部分棘轮；0.998、0.999、0.9995 完全棘轮，且 β₂ 越接近 1，
增量门槛（0.001 量级的 (1 − β₂)·g² 要超过半个 ulp）越高，增长越慢但同样不回落。foreach（两次舍入）在每一档上不轻于 fused。
判据：3000 步时 v 比值的中位数，不出现棘轮记为 < 1.02 且第 1000 步到第 3000 步不增长。
