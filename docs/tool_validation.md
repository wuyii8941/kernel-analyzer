这一轮回答两个问题：答案已知时工具的判断靠不靠得住；它找到的交叉熵近似除法是否一路影响到参数更新。

## 0 核对：exp / 除法干预

`results/reference_eval/exp_intervention_audit.json`、`exp_intervention.json`。同一批 logits 上，Liger
交叉熵 kernel 的每个变体相对原 kernel：

| 变体 | TTIR 改动 | PTX 改动（实际执行） | 自己的 K_R 与原 K_R |
|---|---|---|---|
| div_rn | 2 处 `arith.divf` → `tt.precise_divf` | `div.full.f32` 67→3，`div.rn.f32` 0→64 | 逐位相同 |
| div_d_rn（只换 ÷d） | 1 处 | `div.full.f32` 67→35，`div.rn.f32` 0→32 | 逐位相同 |
| div_n_rn（只换 ÷N） | 1 处 | 同上 | 逐位相同 |
| libdevice | 3 处 `math.exp` → `tt.extern_elementwise` | `ex2.approx.f32` → `ex2.approx.ftz.f32`，新增 65 条 `fma.rm.ftz.f32` 等 | 逐位相同 |
| exp2_rn / exp2_up | `math.exp` → `math.exp2(x·c)` | `ex2.approx.f32` → `ex2.approx.ftz.f32`，去掉一批非规格数处理指令 | 不同（声明表达式变了） |

声明语义不变的替换，两侧参照完全相同；源码一处替换会改动多条下降后的指令，记录在案。

**exp 的结论**：exp2_rn 与原 kernel 逐位相同，证实 `math.exp` 下降为 ex2.approx(x·RN₃₂(log₂e))；常数舍入
只解释偏正的一小部分（改常数 0.752→0.635，未翻转；libdevice 0.765）。

**除法的结论**（4.1）：两处被换的除法都写进 dlogits（loss 路径上的除法未动），比例都在 dlogits 上测：

| 变体 | 正比例 | 平均残差 |
|---|---:|---:|
| 原始 | 0.752 | 1.13e-14 |
| 只换 ÷d | 0.739 | 7.94e-15 |
| 只换 ÷N（N=63） | 0.561 | 7.67e-15 |
| 两处都换 | 0.536 | 4.28e-15 |

主要来源是 ÷N。原 kernel 与只换 ÷N 的 dlogits 之比：没有一个元素小于 1，约 70% 大于 1，中位数 1+7e-8，
其余逐位相同。与 RN₃₂(1/63) 比 1/63 大 5.8e-8（相对）一致：`div.full.f32` 除以同一个 63 等于乘以一个略大的
倒数，整批 dlogits 幅值放大约 1 ulp。偏正是非目标位置 dlogits 为正的表象；目标位置为负，被放大后更负。

## 1 统计判定规则的校准

`results/reference_eval/decision_rule_calibration.json`、`figures/decision_rule_power.png`。规则与统一入口
完全相同（向量化实现与 `analysis._summarize` 在 200 次抽查中判定一致）：32 个开发单元学固定方向，64 个
确认单元打分，t 区间，端点保守。单元 u = μ·v + 噪声，v 对规则未知，每坐标噪声单位方差。

**误报率**（μ = 0，每格 4000 次）：

| 噪声 | d=1 | d=64 | d=1024 |
|---|---|---|---|
| 正态 | 4.9% [4.3, 5.6] | 5.1% [4.4, 5.8] | 4.6% [4.0, 5.3] |
| t(3) | 4.9% [4.3, 5.6] | 4.6% [4.0, 5.3] | 5.0% [4.4, 5.7] |
| 稀疏大值 | 2.9% [2.4, 3.5] | 3.8% [3.2, 4.4] | 5.6% [4.9, 6.3] |

每格 4000 次，名义 5% 处的蒙特卡罗标准误 √(0.05·0.95/4000) = 0.34%，95% 半宽 ±0.7%。最高的 5.6% 出在
「稀疏大值、d=1024、w=0」一格，区间 [4.9, 6.3] 含 5%，在蒙特卡罗误差内；同一噪声在 d=1、64 时偏保守
（2.9%、3.8%：每单元只有一个坐标时投影的分布重尾，t 区间偏宽），维度增加后投影趋于正态，回到名义水平。
噪声种类只覆盖对称分布（正态、t(3)、稀疏大值），偏斜噪声未校准。

参照区间宽 w = 0.1 时误报率 0–0.7%（端点保守）；6 个比较 Holm 后族错误率 2.8–4.8%。

**检出概率**（64 个确认单元）：维度决定灵敏度。d=1 时 μ=0.5 检出 97%；d=64 时 μ=0.5 为 31%、μ=1 为 99%；
d=1024 时 μ=1 只有 28%。原因是 32 个开发单元在高维下学到的方向噪声大。这是工具的灵敏度，不是统计方法
要求的幅度上界（本规则不使用事前界 M）。μ>0 时与开发方向反号的检出另报，最高 7%（稀疏噪声、d=1、
μ 很小时）。

**高维灵敏度的推导。** 单元 uᵢ = μv + εᵢ，‖v‖ = 1，εᵢ 每坐标方差 σ²。开发单元的平均 m = μv + ε̄，ε̄ 每坐标方差
σ²/n_dev，所以 ‖m‖² ≈ μ² + dσ²/n_dev。确认单元在 w = m/‖m‖ 上的投影均值约为

  μ·(v·m)/‖m‖ ≈ μ² / √(μ² + dσ²/n_dev)，

噪声方差恰为 σ²（w 与确认单元独立且为单位向量），标准误 σ/√n_conf，于是检出概率约为

  Φ( √n_conf · μ² / (σ√(μ² + dσ²/n_dev)) − 1.96 )。

d=1024、μ=σ、n_dev=32、n_conf=64：投影 1/√33 = 0.174，检出 Φ(1.39 − 1.96) = 0.28。d=1 时方向只剩符号，
投影均值是 μ(2Φ(μ√n_dev/σ) − 1)；μ=0.5σ 时为 0.498，检出 Φ(3.98 − 1.96) = 0.98（直接代入上面的大 d 近似
得 0.96）。把开发方向的噪声（ε̄ 沿 v 的分量与其余 d−1 维的 χ² 长度）积分进去后的预测与模拟一致（正态噪声，
64 个确认单元；`decision_rule_calibration.json` 中各行的 `predicted_positive`）：

| | μ=0.2 | μ=0.3 | μ=0.5 | μ=1 |
|---|---|---|---|---|
| d=1 预测 / 模拟 | 0.30 / 0.28 | 0.63 / 0.63 | 0.975 / 0.972 | 1.00 / 1.00 |
| d=64 | 0.04 / 0.05 | 0.07 / 0.08 | 0.27 / 0.31 | 0.986 / 0.987 |
| d=1024 | 0.03 / 0.04 | 0.03 / 0.04 | 0.05 / 0.04 | 0.278 / 0.279 |

瓶颈在 dσ²/n_dev 一项：方向要从 n_dev 个单元里学，维度一高，学到的方向几乎与真方向正交。

**三种补法**（`decision_rule_calibration.json` 的 `remedies`；d=1024 分成 16 组、每组 64 个坐标，正态噪声；
误报率每格 4000 次，检出每格 1000 次）。统一入口里对应的规则在 `analysis.apply_direction_rules`：

| 规则 | 误报率（正态 / t(3) / 稀疏） | μ=0.3 | μ=0.5 | μ=1 |
|---|---|---|---|---|
| 学到的固定方向（现行，32/64） | 5.2 / 5.0 / 5.0% | 0.03 | 0.07 | 0.29 |
| 机制给定方向，与真方向一致 | 5.4 / 5.1 / 5.0% | 0.66 | 0.97 | 1.00 |
| 机制给定方向，与真方向夹角余弦 0.5 | 5.1 / 5.0 / 4.9% | 0.24 | 0.54 | 0.97 |
| 交叉拟合 K=2，各折投影合并成一个 t 检验 | **16.6 / 16.6 / 16.5%** | 0.11 | 0.17 | 0.53 |
| 交叉拟合 K=2，逐折检验、Bonferroni | 3.5 / 3.3 / 3.2% | 0.03 | 0.05 | 0.27 |
| 交叉拟合 K=4，逐折检验、Bonferroni | 4.9 / 4.3 / 4.6% | 0.04 | 0.05 | 0.29 |
| 交叉拟合 K=2，合并统计量的符号翻转检验 | 5.0 / 5.1 / 4.6% | 0.04 | 0.07 | 0.33 |
| 按声明的组求和后学方向（效应在组内同号） | 4.9 / 5.5 / 4.8% | 0.18 | 0.62 | 1.00 |
| 同上，但效应在组内正负混杂 | — | 0.02 | 0.04 | 0.04 |

- **机制给定方向**（统一入口的 `aligned_reference_update`：方向取每个单元自己的参照更新，对应「整体缩放」
  这类机制）：不学方向，检出 ≈ Φ(√n_conf·μ·cosθ/σ − 1.96)，与维度无关；方向只要大致对（余弦 0.5）就比学到
  的方向强得多。代价是方向必须事前由机制给出，不能看了数据再定。
- **交叉拟合**：把各折投影直接合并做 t 检验，误报率实测 16.6%，不能用。原因是各折的方向由其他折的单元学出，
  不同折的投影通过共享单元正相关；高维下 Cov 约为 σ²/(n(1−1/K))，合并均值的方差约翻倍，名义 5% 变成
  P(|Z| > 1.96/√2) = 16.6%，与实测相符。有效的做法是逐折检验后 Bonferroni（对任意依赖成立）或对合并统计量做
  单元符号翻转的随机化检验（零假设下单元分布关于零对称时精确）；两者误报率都在名义水平，但检出几乎不比
  单次划分高（μ=1 时 0.27–0.33 对 0.29），因为方向噪声只从 dσ²/32 降到 dσ²/48 或 dσ²/72。统一入口实现的是
  逐折 Bonferroni 版本（`cross_fit`，折数 `cross_fit_folds`）。
- **按结构降维**（`grouped_<规则>`，声明 `groups.size`）：先按行或张量把坐标求和，方向在 G 维里学，投影均值变为
  μ²/√(μ² + Gσ²/n_dev)。效应在组内同号时 μ=0.5 的检出从 7% 升到 62%（预测 0.62）；组内正负混杂时信号被求和
  抵消，μ=2 也只有 9%。分组必须事前按机制声明（例如「每行同一缩放」），不能事后挑。
- 三种做法的误报率都在名义水平（稀疏噪声 d=1024 下学到的固定方向本次为 5.0%，上一节同一格 5.6%，两者都在
  蒙特卡罗误差内）。

## 2 真实 kernel 改动实验

`results/reference_eval/mutation_experiment.json`。9 个原参照完整的 kernel（scale、四项和、行和、softmax、
layernorm、matmul、累加、Liger RMSNorm 前向、Liger 交叉熵），34 处单点改动与 12 个阴性对照（8 次原样
重跑、4 个逐位等价改写）。每处改动事先只写局部可确定的结论，平均作用是否为零不作答案。

| 结果 | 数量 |
|---|---|
| 改动后仍在支持范围（无不支持指令、无中止） | 42/42 |
| 改动在数值上被看到（输出变化或 K_R − f 检出） | 33/33 |
| 事先写明「预期无差异」：RMSNorm 的 ÷n_cols 换 div_rn，n_cols=512 是 2 的幂，近似除法与正确舍入除法结果相同 | 1/1（值与参照逐位相同；结构差异 8 个操作，含改动处） |
| 末步且输入精确时向下 / 向上舍入，输出残差符号固定 | 4/4 |
| 漏项：有规格时检出、无规格时不可见（报告写明任务语义未检验） | 4/4 |
| 同一实数的另一种写法（softmax 去掉减最大值、layernorm 的 E[x²]−mean²）参照相交 | 2/2 |
| 阴性对照：值与参照逐位相同、结构差异为 0 | 12/12 |

事先写错的两处已更正：四项和的末步向下舍入，其输入 (a+b)+c 已含上游舍入，输出符号不固定，改记为「仅局部
成立」，不在输出上检验；RMSNorm 的 ÷2^k 按除数可知两种除法逐位相同，原先记为「未看到的改动」不妥，改记为
「预期无差异」并按阴性对照检验（`mutation_kind = approximation_exact_divisor`）。

**定位**（不告诉工具改动在哪）：两份捕获程序的结构差异（按数据流的结构哈希，可交换运算的操作数排序）
把区域缩到 1–31 个操作（kernel 共 16–101 个）；求和次序改动只改结构不改指令种类，结构差异能看出，
指令计数看不出。只用数值证据时，变化的输出元素的依赖锥覆盖 kernel 操作的 80% 以上，等于 kernel 级定位。

## 3 与只看误差大小的方法对比

`results/reference_eval/method_comparison.json`（`scripts/run_method_comparison.py`）。7 个 kernel 的 18 处声明语义
不变的改动与 7 个原样重跑，同一组 96 次输入抽取（32 开发、64 确认），测量点为 kernel 输出。

- **误差大小一侧（表的行）**：用的是 TTrace 式扰动阈值，不是 `allclose`。每次抽取算改动版对原版的 Frobenius
  相对误差，阈值取「原版的每个浮点输入乘以 1 ± 2⁻²⁴（随机符号）后重跑原版」与原版的相对差；半数以上抽取超过
  阈值记为「超出容差」。只实现了 TTrace 判据的这一部分，称为误差大小基线，不称复现 TTrace。`torch.allclose`
  （默认 rtol 1e-5、atol 1e-8）同时逐次记录，单独成表（见下）。
- **平均作用一侧（表的列）**：u = 改动版输出 − 原版输出，两个都是设备上的实际值，这一列不用参照，也就没有区间
  端点；规则是固定方向（32 个开发抽取学方向，64 个确认抽取投影），t 区间，18 处改动做 Holm 校正。判定的
  正负是沿学到的方向，「检出」表示开发方向在确认数据上重现。另报 u = 改动版 − K_R 与 u = 原版 − K_R：
  这两项用参照区间的两个端点，单元的投影取 [Σ min(lᵢwᵢ, hᵢwᵢ), Σ max(lᵢwᵢ, hᵢwᵢ)]，端点保守判定
  （`method_comparison.json` 中的 `average_effect_mutant_vs_reference`、`average_effect_original_vs_reference`）。

| | 平均作用：检出 | 平均作用：未确认 |
|---|---|---|
| 误差超出容差 | — | 降精度 ×5（scale、四项和、行和、softmax、layernorm）、matmul tf32、matmul 降精度、matmul 换次序 |
| 误差在容差内 | scale 向下 / 向上舍入、四项和末步向下舍入、累加向下 / 向上舍入 | 四项和与行和换次序、softmax / layernorm 换近似函数与改写 |

- 定向舍入的误差都在一个 ulp 量级（相对误差 6e-8，阈值 6–7e-8），误差大小判据视为正常，平均作用一侧稳定检出。
- 降精度把误差放大几个数量级，但在 96 次抽取上没有确认一致方向（与第 1 节高维灵敏度一致），不能据此说作用为零。
- 行改用 `allclose`（半数以上抽取不通过记为超出）时，表变为：

  | | 平均作用：检出 | 平均作用：未确认 |
  |---|---|---|
  | `allclose` 不通过 | — | 降精度 ×5、matmul 三处、layernorm 换近似函数（71%）与改写（89%） |
  | `allclose` 通过 | 同上表五处定向舍入 | 四项和与行和换次序（32%、10% 不通过）、softmax 换近似函数与改写 |

  两种误差大小判据在 layernorm 两处结论相反，只看误差大小时结论取决于容差的定法；平均作用一侧的结论不随之
  变化。
- 原样重跑：改动版减原版恒为零（方向规则无从学习，记为无法判定），没有误报；softmax 与 layernorm 的原版本身
  相对 K_R 有检出的平均作用，原样重跑与原版一致。

表中各格按数据填写，未为填满某格调整阈值；「检出 × 超出」一格在这批数据中为空。

## 4 交叉熵的近似除法：一路追到训练

`results/reference_eval/ce_division_propagation.json`（`scripts/run_ce_division_propagation.py`）。Qwen3-1.7B
FP32，主体冻结，lm_head 用 AdamW（lr 1e-4，betas (0.9, 0.95)，eps 1e-8）在 wikitext-103 的 64 token 窗口上训练。
48 条独立历史（各自的数据顺序；16 开发、32 确认），每条训练 40 步后冻结真实状态与第 41 步的批次，四个
kernel 变体（exp ∈ {tl.exp, libdevice} × 除法 ∈ {近似, 正确舍入}）在同一隐藏状态上算 dW，再从同一状态各走
一步 AdamW（真实动量）、零动量 AdamW 与 SGD。同一条历史只取一个点，单元之间独立。下表的相对量是对齐
投影除以参照更新（正确舍入除法、原 exp）的范数，32 条确认历史的中位数：

| 层 | 近似除法的作用（对齐，相对） | 差的总范数（相对） | Holm 后判定 |
|---|---:|---:|---|
| 梯度 dW | +5.9e-8 | 9.4e-8 | 检出（正） |
| SGD 更新 | +5.9e-8 | 9.8e-8 | 检出（正） |
| AdamW 更新（真实动量） | +3.1e-9 | 6.3e-7 | 检出（正） |
| AdamW 更新（零动量，对照） | +1.2e-8 | 1.3e-6 | 检出（正） |

- **梯度层**：dW 沿自身方向放大 5.9e-8，与 RN₃₂(1/63)·63 − 1 = 5.8e-8 一致：÷N 的局部偏差原样进入梯度，相当于
  梯度乘以 (1+ε)。
- **更新层**：SGD 原样保留；AdamW 把这一缩放分量压低约 19 倍但不为零（当前梯度放大而历史动量没有放大），同时
  差的总范数更大（逐坐标归一化放大小梯度坐标上的差异）。
- **exp**：在梯度和 SGD 上未确认，经 Adam 归一化后检出（AdamW 对齐作用正）；exp × 除法的交互在各层都未确认。

**4.4 的 2×2 结果**（exp ∈ {tl.exp, libdevice} × 除法 ∈ {近似, 正确舍入}）。对齐规则：差沿参照更新方向的投影，
32 条确认历史的平均与 95% t 区间，单位与该层相同；判定为 28 项一起 Holm 校正后。「÷N（tl.exp）」= 原版 −
div_rn，「÷N（libdevice）」= libdevice − libdevice_div_rn，「exp」= 原版 − libdevice（近似除法下），交互 = 两个
÷N 作用之差：

| 层 | ÷N（tl.exp） | ÷N（libdevice） | exp（近似除法下） | 交互 |
|---|---|---|---|---|
| 梯度 dW | +7.79e-7 [7.40, 8.18]e-7 检出 | +7.79e-7 [7.44, 8.14]e-7 检出 | −5.3e-9 [−22.5, 11.9]e-9 未确认 | +4.5e-11 [−1.48, 1.49]e-8 未确认 |
| SGD 更新 | +7.81e-11 [7.44, 8.19]e-11 检出 | +7.82e-11 [7.48, 8.16]e-11 检出 | −5.9e-13 [−2.34, 1.16]e-12 未确认 | −6.6e-14 [−1.55, 1.41]e-12 未确认 |

÷N 的作用与 exp 的实现无关（两列几乎相同，交互未确认）；exp 的作用在梯度上未确认，经 AdamW 后出现与 ÷N
同量级的正对齐分量。一种解释是 AdamW 的逐坐标归一化对零均值扰动有二阶响应，这一点未单独检验（需要同幅度的
随机扰动作对照），所以不把它记为 exp 本身的偏差。同样 12 项用声明的
256 行固定方向时 Holm 后全部未确认（原始 p 最小的是梯度层 libdevice 下的 ÷N，0.015）。

**÷N 在 N 的总体上的平均**（`results/reference_eval/division_bias_over_n.json`，`scripts/division_bias_over_n.py`）。
本实验每个窗口 64 token、最后一个标签忽略，所有历史 N=63，N 的分布是 63 处的点质量。按审阅意见算
δ_RN(N) = (RN₃₂(1/N) − 1/N)·N = RN₃₂(1/N)·N − 1，N = 1…131072 逐个用有理数精确算；同时在 GPU 上对每个 N 用
1024 个分子实测 x/N（`div.full.f32`）相对 `div_rn` 的平均相对偏差，并读出硬件倒数 rcp.approx.ftz.f32(N)：

| N 的分布 | E_N[δ_RN] | E_N[δ_rcp]，δ_rcp = rcp(N)·N − 1 | 实测平均 | δ_RN > 0 的比例 |
|---|---:|---:|---:|---:|
| 63（本实验） | +5.77e-8 | +5.77e-8 | +5.58e-8 | — |
| 均匀 1…64 | +1.25e-8 | +1.23e-8 | +1.27e-8 | 70% |
| 均匀 1…512 | +3.7e-9 | +1.00e-8 | +1.01e-8 | 54% |
| 均匀 1…4096 | +1.8e-9 | +6.6e-9 | +6.6e-9 | 52% |
| 均匀 1…131072 | +8.0e-11 | +5.85e-9 | +5.86e-9 | 50% |
| 2048 ± 64 | +2.3e-9 | +4.1e-9 | +4.0e-9 | 49% |
| 8192 ± 256 | +1.5e-9 | +3.0e-9 | +3.0e-9 | 51% |
| 32768 ± 1024 | −1.2e-10 | +1.2e-9 | +1.2e-9 | 49% |

- 按 RN₃₂(1/N) 模型，单个 N 的 |δ| 平均 2.2e-8，正负各半，宽的 N 分布上平均几乎抵消（均匀 1…131072 只剩 8e-11）。
- 但 `div.full.f32` 实际乘的是硬件倒数 rcp.approx，它在 13.5% 的 N 上不等于 RN₃₂(1/N)（9.9% 偏大、3.6% 偏小）。
  实测偏差与 δ_rcp 的相关 0.999（与 δ_RN 只有 0.33）；同一个 N 下 1024 个分子的偏差符号全部一致或为零；2 的幂
  上两者都精确为零。所以真实偏差在 N 的总体上不抵消：上表各分布平均为 +1e-9 到 +1e-8，约为单个 N 幅度的
  1/20 到 1/2。
- 训练中的作用要按实际的 N 分布（每批非忽略 token 数）声明后再算；N=63 处 rcp 与 RN₃₂ 相同，本实验的 5.9e-8
  与两种模型都一致。
- **固定方向规则**（声明的 256 行，16 个开发历史）在各层都未确认，与第 1 节的校准一致：高维下灵敏度低。
- **训练层（4.5）不做**：作用能重复出现、含义清楚（等价于把学习率乘以 1+5.8e-8，经 AdamW 后约 3e-9），但幅度
  比换种子的 loss 波动小几个数量级，不值得配对训练。链条停在更新层。作用的符号由硬件倒数相对 1/N 的方向决定，
  这里 N=63；真实训练中 N 随批次变化，见上表。

## 5 核内定位：逐位模拟设备上的 FP32 执行

`results/reference_eval/inkernel_localization.json`（`scripts/run_inkernel_localization.py`，模拟器
`src/kernel_analyzer/reference_eval/emulate.py`）。kernel 内部的中间值在设备上看不到，只用数值证据只能定位到
kernel。这里换一条路：按锁定版本（Triton 3.6.0、sm_86）的下降规则在主机上逐位重演设备的执行，先核对模拟
输出与设备输出逐位相同，再一次只把一个节点改成精确值，输出的变化就是这个节点的贡献
c_j = K_模拟 − K_(节点 j 精确)。

**模拟规则**（在舍入核验模式上增加；每条都由逐位比较逼出，并在 PTX 或 SASS 中核对过）：

| 规则 | 依据 |
|---|---|
| IEEE 运算（加减乘、fma、precise sqrt/div、转换、带舍入后缀的 libdevice）每次按声明模式舍入 | 舍入核验模式 |
| 同一基本块里乘法结果进入加减时合成一次 fma（LLVM 在 NVPTX 上的积极合成；中间隔着 splat/broadcast 也算；两边都是乘积时合成使用次数少的） | PTX 中的 `fma.rn.f32` |
| 乘积进入归约时，第一次见到原始乘积的合并是 fma（线程内首两项、或第一次 shuffle） | layernorm：`fma.rn.f32 %r45, %r42, %r42, %r44` |
| 归约次序取 TTGIR 布局：线程内按寄存器次序顺序累加，线程束内按轴向 lane 蝶形交换，再跨 warp 蝶形；`tt.reshape allow_reorder` 后按源布局的寄存器次序 | Liger 交叉熵的两次求和 |
| fp32 `tt.dot`（ieee）为沿 k 的顺序 fma 链 | matmul 原版 16384/16384 逐位相同 |
| 近似指令（`arith.divf` = div.full、`math.exp/log/sqrt/rsqrt/...`、libdevice、inline asm）在设备上对模拟出的操作数执行同一条 TTIR 运算（硬件预言机；指令确定，操作数相同结果就相同） | — |
| 近似运算紧接着同一基本块里的普通加减时，两者一起在设备上执行：ptxas 会把 div.full 展开末尾的乘法与后面的加减合成 FFMA | SASS：`MUFU.RCP` 后 `FFMA R7, R11, -R7, R4` |
| 张量核点积（tf32、tf32x3、bf16/f16 输入）、扫描、atomic：不可模拟，定位在那里停止 | — |

有两类选择 TTIR 本身不能决定：div.full 末尾的乘法是否被合成进后面的加减（ptxas 的调度决定，只在 SASS 中
可见），以及两边都是乘积时 LLVM 合成哪一个（取决于选择 DAG 里的使用计数）。这两类先取默认，只有翻转后
逐位相同的元素增多才翻转，并报告翻转了几处；翻转后全部元素必须逐位相同才算复现。

**覆盖**（100 个捕获包：36 个求值 kernel 的捕获、Liger 交叉熵 64 次启动等）：

| 来源 | 捕获包 | 不同 kernel | 写出元素 | 可模拟 | 逐位相同 | 由输出决定的选择 | 不可模拟的部分 |
|---|---:|---:|---:|---:|---:|---:|---|
| 练习 kernel | 24 | 20 | 90,972 | 84,600 | 84,600 | 0 | 张量核点积 3 个（tf32、tf32x3、bf16 输入，6144 个元素）、扫描 1 个（200）、无 other 的掩码加载的未定义 lane（28）；atomic 2 个整个 program 停止 |
| Inductor | 7 | 5 | 383,619 | 383,619 | 383,619 | 0 | — |
| Liger（交叉熵 64 次启动、RMSNorm 前向 / 反向） | 66 | 3 | 2,085,983 | 2,085,983 | 2,085,983 | 0 | — |
| torchao AdamW8bit（3 步） | 3 | 1 | 792,576 | 792,576 | 792,576 | 5 | — |
| 合计 | 100 | 29 | 3,353,150 | 3,346,778 | 3,346,778 | 5 | |

可模拟的元素全部逐位相同，没有一个例外；不可模拟的只有事先列出的那几类。由输出决定的 5 处选择都在 torchao：
3 次启动各有 1 处 div.full 末尾乘法未被合成进后面的减法，第 2、3 步另有 1 处两边都是乘积的减法合成了使用
次数多的一边（第 1 步状态为零，两种选择结果相同）。其余 97 个捕获包完全由事先固定的规则复现。

**定位验证：变异 kernel**（每个变体 8 次输入抽取为单元；对每个节点按三种统计量（加性：贡献的平均；
乘性：c/K 的平均；沿输出方向：Σ c·K/‖K‖）在单元之间做 t 检验，同一变体内全部「节点 × 统计量」做 Holm）。
事先知道位置与符号的只有定向舍入的 5 处：

| 变体 | 排在第一的节点 | 统计量 | 平均贡献 | t | 定位 |
|---|---|---|---:|---:|---|
| scale 向下舍入 | `__nv_fmul_rd` | 加性 | −3.43e-9 | −122 | 正确（位置与符号） |
| scale 向上舍入 | `__nv_fmul_ru` | 加性 | +3.41e-9 | +163 | 正确 |
| 四项和末步向下舍入 | `__nv_fadd_rd` | 加性 | −3.42e-6 | −84 | 正确 |
| 累加向下舍入 | `__nv_fadd_rd` | 加性 | −3.39e-6 | −221 | 正确 |
| 累加向上舍入 | `__nv_fadd_ru` | 加性 | +3.37e-6 | +114 | 正确 |

其余 21 个变体（原版、换次序、降精度、换近似函数、改写）事先不知道有没有偏差，检出的节点如下，其余变体没有
节点通过 Holm：

| 变体 | 检出的节点 | 统计量 | 值 | t |
|---|---|---|---:|---:|
| scale 原版、scale 降精度 | 乘以 0.1 的 `arith.mulf` | 乘性 | +2.30e-9、+2.57e-9 | 9.7、11.7 |
| softmax 原版 / 除法改为正确舍入 / 去掉减最大值 | `math.exp` | 乘性 | +6.9e-8 / +7.0e-8 / +4.3e-8 | 16.5 / 23.2 / 6.3 |
| layernorm 改写为 E[x²]−mean² | `var + eps` 的 `arith.addf` | 沿输出方向 | −2.9e-7 | −17.0 |
| 累加原版 | `arith.addf` | 沿输出方向 | +2.5e-6 | 4.2 |
| matmul 反转 K 次序 | `tt.dot`（fma 链） | 加性 | +1.4e-8 | 3.9 |

- 乘以 0.1 的偏差是真的，不是假阳性：0.1f 的尾数 0xCCCCCD ≈ 0.8·2²⁴ + 0.2，乘积被舍掉的那部分只落在
  k/5 + 0.2·Mₓ/2²⁴ 附近而不是均匀分布，就近舍入只在余数均匀时无偏。逐个尾数枚举，舍入误差平均 +0.022 ulp
  （随 Mₓ 在区间内的位置从 −0.025 到 +0.063 ulp）；10⁷ 个正态输入上相对平均 +2.29e-9（标准误 8e-12），与
  定位结果一致。
- softmax 原版的偏差定位在 `exp` 节点（近似指令 ex2.approx），与第 3 节「softmax 原版相对 K_R 检出平均作用」
  一致：那一节只能说 kernel 有偏差，这里说出是哪一个节点。
- 累加原版与 matmul 反转次序两处 t 只有 4 左右（8 个单元），没有机制解释，按单次检验记录，不作结论；
  这 21 个变体合起来约有 1 个族内假阳性的期望。
- matmul 换 tf32 的变体 0/16384 个元素可模拟：张量核点积处停止，不给定位。

**Liger 交叉熵**（12 次启动，每次 32000 个 dlogits，n_non_ignore = 63，全部逐位复现）：

| 节点 | c/K 的平均 | t | Σ c·K/‖K‖ | t |
|---|---:|---:|---:|---:|
| `X_block / n_non_ignore`（÷N，div.full） | +5.781e-8 | 1436 | +1.07e-9 | 6.5 |
| 第二遍的 `math.exp` | −1.71e-8 | −21 | −1.7e-14 | −36 |
| 其余 20 余个节点 | — | Holm 后均未检出 | — | — |

÷N 节点的相对贡献在每次启动、每个元素上都等于 RN₃₂(1/63)·63 − 1 = 5.774e-8 加上零均值的舍入噪声，
沿输出方向的分量比 exp 节点大五个数量级。这与第 0、4 节的干预结论（主要来源是 ÷N）一致，但这里没有改任何
代码，只用一次捕获和模拟就把偏差落到了具体节点。÷N 的加性平均反而不显著（t = −0.9）：目标位置的一个大负值
与 32000 个小正值相互抵消——乘性机制要用乘性或沿输出方向的统计量，这与第 1 节「机制给定方向」是同一个道理。

**局限**：模拟只在锁定版本与 sm_86 上建立；两类下降选择由输出决定时要报告；硬件预言机假定近似指令在单独
编译时与在原 kernel 中下降相同（每次都由最终的逐位比较检验）；节点精确时下游近似运算保持自身误差
（hw(RN(x)) + f(x) − f(RN(x))），与 ptxas 合成在一起的加减改为「近似结果 + 精确加法」，是一阶近似；
张量核、扫描与 atomic 所在的区域不能定位。

## 并行：第二个 Triton 版本

`results/reference_eval/version_migration/`。相邻版本 3.5.1（torch 2.9.1，同一 GPU，同一输入）。在 3.5.1
二进制上重新枚举注册表：它是 3.6.0 的真子集（少 `math.clampf`、`gpu.subgroup_broadcast`），映射表覆盖完整。
19 个练习 kernel 在两个版本下：两版各自的参照都正确（舍入核验模式下 IEEE kernel 两版都逐位复现，近似指令
kernel 两版都不复现）；两版参照全部相同（声明计算未变）；设备值除两个 atomic（并发次序）外全部逐位相同。

**同一份 TTIR 用两个版本编译**（`results/reference_eval/version_migration/same_ttir_351_vs_360.json`，
`scripts/cross_version_ttir.py`）。把 36 个实际求值 kernel 的捕获包与 65 份静态语料中的 TTIR 去重后共 61 份
（另加下面的 1 份激活用 kernel），每份用 3.5.1 与 3.6.0 各编译一次（选项取原始编译的 num_warps、num_stages、
enable_fp_fusion，语料中没有捕获的取 4/3），比较 PTX，并把由捕获 TTIR 编出的两版二进制都在捕获的输入上运行：

| 结果 | 数量 |
|---|---|
| 两版都能编译 | 61/61 |
| PTX 去掉注释、版本头与调试段后逐字相同 | 6/61 |
| 浮点指令的种类与条数相同（差别只在整数、控制流、寄存器分配与调度） | 53/61 |
| 浮点指令不同 | 8/61：`elementary` ×2、Inductor AdamW ×4、torchao AdamW8bit ×2 |
| 捕获输入上两版输出逐字节相同 | 98/100（不同的 2 个是 atomic kernel，各版自身重跑也不确定） |
| 3.6.0 由 TTIR 重编的二进制与原始捕获二进制的输出相同 | 98/100（同上 2 个 atomic） |

浮点指令的差别只有两类，都与非规格数（subnormal）有关：

- `tt.precise_sqrt`、`tt.precise_divf`（`tl.sqrt_rn`、`tl.div_rn` 与 Inductor 的 sqrt）：3.5.1 下降为
  `sqrt.rn.ftz.f32`、`div.rn.ftz.f32`（输入与结果的非规格数清零），3.6.0 下降为不清零的 `sqrt.rn.f32`、
  `div.rn.f32`；
- libdevice `__nv_powf`：3.5.1 走清零分支，多 2 条 `mul.rn.ftz.f32` 与 2 条 `add.f32`。

捕获的输入里没有非规格数，所以两版输出逐字节相同。为了让差异出现，加两组会经过这些指令的输入
（`captures_activated/`）：

| | 3.5.1 与 3.6.0 不同的元素 | 3.5.1 ≠ RN(K_R) | 3.6.0 ≠ RN(K_R) |
|---|---|---|---|
| `ftz_lowering`：sqrt_rn(\|x\|)，一半元素为 ±2^−120…2^−149 | 1568/4096 | 1568（全部输出 0） | 0 |
| `ftz_lowering`：div_rn(x, 3) | 1619/4096 | 1619（应为非规格数的结果输出 0） | 0 |
| `ftz_lowering`：libdevice pow(\|x\|, 0.75) | 0 | 2451 | 2451（近似函数，两版相同） |
| Inductor AdamW，grad 与 exp_avg 乘 2⁻⁷⁰、exp_avg_sq 乘 2⁻¹⁴⁰ | 0/24576 | 0 | 0 |

- 两版编译的是同一份 TTIR，自动参照 K_R 相同，所以 E[K₂ − G] − E[K₁ − G] = E[K₂ − K₁] 全部来自下降。舍入核验
  模式把差异定位到具体规则：3.6.0 的 sqrt_rn / div_rn 在全部元素上逐位等于 RN(K_R)，3.5.1 只在非规格数处
  不等，偏差方向是朝零（sqrt 平均 +1.1e-20 由 3.5.1 的 0 变为 3.6.0 的正确值）。
- AdamW 中 exp_avg_sq 有 2708 个元素确实是非规格数，3.5.1 的 sqrt 输出 0、3.6.0 输出约 1e-20，但随后加上
  eps = 1e-8，差别在 FP32 中被吞掉：下降差异被触发但对参数更新没有作用，两版在 3 个输出上都逐位等于 RN(K_R)。
- 结论：在相邻版本之间，同一份 TTIR 的下降差异只出现在非规格数处理上；在捕获的真实输入上不起作用；
  构造非规格数输入后差异出现，参照相同，工具把差异归到具体指令与具体元素。没有覆盖的是：次序或近似指令
  本身随版本改变的情形（这两个版本之间没有出现）。

## 并行：提速

只做不改变严格性的部分：点输入的初等函数每元素一次 MPFR 调用并读 inexact 标志（交叉熵单次启动 0.99→
0.50 s，包围与两次定向调用相同，精确结果保持零宽）。剖析显示其余时间主要在逐元素 MPFR 调用的 Python

## 写作

README 与方法文档已改为工具阶段。手工参照对自动参照：统一入口的同一套统计分别配手工 FP64 参照（区间取手工值 ± γ₆₄·Σ|G_c|）与自动 K_R，在 Liger FP32 dW 累加上
各跑一次（`results/reference_eval/liger_fp32_order_manual_reference.json`）：6 项统计结果完全相同。自动参照多带来
的是：区间更紧（手工参照有 324 个元素舍回 FP32 时两端不同，自动参照为 0）、不需要为该位置写公式、逐元素的
三类判定与覆盖报告。
