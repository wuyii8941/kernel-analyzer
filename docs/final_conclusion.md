# Final conclusion and remaining scope

## What is established

The project now has a complete, auditable chain:

```text
implementation difference
  → local numerical variation
  → F+B/optimizer transport
  → formation or cancellation
  → SEUP persistence and trajectory drift
```

The strongest predictive result is conditional, not universal. A
`TRANSPORTED_CONDITIONAL_MEAN_PERSISTENCE` predictor was frozen before
consequence measurement and correctly identified the same `lm_head dX`
mathematical family on two new operand distributions (Llama 3.2 and
Ministral 3). The strict corrected orbit measurements retain the signal, while
the five-seed repeated-orbit null shows that a one-shot random perturbation is
not enough to explain the observed drift.

This is evidence for cross-model/operand generalization of one exact reduction
and VJP family. It is **not** evidence for a universal all-operator oracle:
the current new-implementation positive count is zero.

## What the controls show

Several newly measured semantic regions have real, backward-visible residuals
but remain centered or canceling after gradient/update transport. They are
valuable controls because they show that a nonzero endpoint difference is not a
training-bias verdict. Mamba and Phi-4 normalization remain abstentions because
compiler or graph closure failed before a valid formation measurement; they are
not negative results.

Gemma 4 supplies a separate feedback-sustained case. Its local source is near
the diffusive boundary, while Adam state sustains the later drift. It must not
be relabeled as a Flash-style source carrier. Likewise, the historical eight
trajectory observations are an audit denominator, not eight copies of one
mechanism.

## The correct property statement

> For an exact finite semantic orbit with a closed forward/backward boundary,
> a nonzero transported conditional orbit mean can predict persistent drift in
> the measured reduction/VJP family. Outside that scope—feedback-dominated,
> discrete-routing, missing-orbit, or unresolved-compiler regimes—the predictor
> abstains rather than emitting SAFE.

This wording is deliberately conditional. The data do not justify saying that
all operators share one source property, nor that an unresolved endpoint is
harmless.

## Remaining steps if a broader claim is required

The post-checkpoint extension added five complete, residual-nonzero,
backward-visible centered controls and no new implementation-class positive.
The next step is therefore not another unconstrained case search.  It is to
test a small set of predeclared structural properties on the existing positive
and centered populations:

1. source asymmetry or a nonzero conditional orbit mean;
2. source--transport correlation under the exact VJP;
3. concentration of transported error into a low-dimensional parameter
   carrier;
4. stability of that carrier across adjacent reference-trajectory states.

These measurements should feed a short-horizon, candidate-aware screening
oracle using shared reference checkpoints and fixed random update sketches.
Only predicted risks and a random sample of predicted negatives should receive
the expensive exact-repair trajectory.  Thresholds and input features must be
frozen before any new implementation-class outcome is revealed.  A separate
feedback predictor remains necessary before making claims about
feedback-sustained cases.
