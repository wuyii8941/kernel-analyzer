- **写进优化器状态或累积缓冲的作用确实不经过 Adam 的抑制**：超过尺子的五个全部属于这一类（低精度状态、低精度 EMA），作用量是
  每步更新的 20–50%；不保存状态的 C8、C10 都比 δ 小两个数量级以上。
- **两个 8 位实现差别很大**：torchao AdamW8bit 每步更新缩小约 20% 且有固定方向分量（超过尺子），bitsandbytes AdamW8bit 的作用只有
  +2%（在尺子之内）。60 步的冒烟里两者几乎相同，差别是随训练在状态中积累出来的——这正是影子状态测量要抓的东西。torchao 自己的
  基准（Llama2-7B 微调）里 ao 8-bit 的准确率也低于 bnb 8-bit（41.50 对 42.75）。
- **bf16 随机舍入（C6）**：作用量的均值为零（随机舍入的设计目的），但 u 的相对 RMS 约为 1——每一步的噪声和更新一样大，只是没有
  方向。这是「平均作用」与「幅度」两轴给出不同信息的又一个例子。
- 「在尺子之内」的四个报告上界：bnb 8-bit 为 δ 的 0.56 倍，其余不到 δ 的 1%。

## 2. 深案例一：torchao AdamW4bit（C4，按保守量排第一）

- 机制（源码，torchao 0.16 与当前 main 相同）：二阶矩 v 用不含 0 的 16 级线性码表（1/16, …, 1），按 128 个元素一块以块内最大值归一；
  每步 v = lerp(dequant(v_prev), g², 1 − β₂) 后重新量化存回，块内小于约 1/32 最大值的 v 每步被抬到 max/16。torchao 的 README 注明
  没有实现论文中二阶矩的 rank-1 归一化。
- 归因（影子状态，种子 0，预注册预测）：只量化 v（C4a）γ̂ = −0.40，为 C4 的 81%（预测 ≥ 70%，**成立**）；只量化 m（C4b）γ̂ = −0.16，
  为 32%（预测 < 30%，**不成立**，m 的贡献比预期大，两者不可加）。
- 干预（块大小 128 → 32，C4c）：γ̂ = −0.47，|γ̂| 比 C4 小（方向预测成立），但只小 5%，仍远超尺子——块大小不是主因。
- 独立配对训练（AdamW4bit 作为真实优化器，种子 0–3，与 R′ 配对）：ΔL = **−0.066**（−0.075, −0.058），4.6σ，**训练层面超出种子
  波动，方向是 loss 更低**。在这个 2,000 步、训练不足的设置里，逐元素缩小更新（小 v 的元素缩得更多）恰好有利。所以「超过尺子」
  的含义是「对训练的改变超过已接受的做法」，不等于「有害」；它是否有害取决于训练长度与学习率是否已调到最优，这里不作推广。
- 上游：torchao 的 issue 中没有关于更新系统性缩小的报告；README 写明了与论文的差别并给出了微调准确率的小差距。按已知设计取舍
  记录（B008），不作为新发现。

## 3. 深案例二：bf16 权重 EMA（C9，按保守量排第二）→ B019

- 机制：EMA 增量 (1 − β)(θ − e)（β = 0.999）小于 e 在 bf16 中的半个 ulp，就近舍入后丢失，EMA 冻结在初始化附近。
- 真实接口复现（预注册）：纯 bf16 模型上 `torch.optim.swa_utils.AveragedModel(model, multi_avg_fn=get_ema_multi_avg_fn(0.999))`，
  种子 0–3：平均模型的验证 loss **9.10 / 9.03 / 9.01 / 8.97**，同一次训练中 fp32 EMA 为 5.16 / 5.15 / 5.17 / 5.16（训练后的模型
  4.89）——高 3.86，约 270σ（预测「远大于 σ」，**成立**）。`AveragedModel` 不接受 fp32 的平均副本（按 dtype 分组时报错）。
- 干预（预注册）：fp32 副本 + 按参数在 fp32 中 lerp 的 `avg_fn`：四颗种子都与 fp32 参照**逐位相同**（预测「差在 σ 之内」，成立）。
- 上游四项检索：PyTorch 没有相关 issue；`swa_utils` 文档没有 dtype 说明；nightly（2.15.0.dev20260907）行为相同；timm 的
  `ModelEmaV3` 与 diffusers 的 `EMAModel` 同样继承模型 dtype。登记为 B019，草稿 `bugs/upstream_drafts/B019_averagedmodel_bf16_ema.md`
  由用户决定是否提交。

## 4. 结论（按计划第 4 节）

- 在作用不经过 Adam 抑制的位置上，按冻结的尺子：低精度优化器状态（bf16 的 foreach / fused、torchao 8 位与 4 位）与 bf16 权重 EMA
  超过尺子；bitsandbytes 8 位、bf16 随机舍入、Muon 的 bf16 Newton–Schulz、bf16 梯度累加在尺子之内（附上界）。
- 一个经预注册复现、上游未见报告的发现：`AveragedModel` 对 bf16 模型的 EMA 停滞且没有 fp32 选项（B019）。
- 不能说的：未测过的优化器实现都安全；超过尺子的实现一定有害（C4 在本设置里让 loss 更低）。

## 5. 局限

同阶段 B：一个模型规模与数据集、2,000 步；影子测量用两颗种子；深案例的配对训练每臂 4 个种子。C5（fp8 状态）需要 sm_89 以上，
未测。EMA 只在纯 bf16 模型上有这个问题；混合精度训练（fp32 主权重）中 `AveragedModel` 的平均副本是 fp32，不受影响。
