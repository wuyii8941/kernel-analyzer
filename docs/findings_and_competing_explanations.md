## 文献核对与可区分预测

2026-09-14 核对 [Understanding Quantization of Optimizer States in LLM Pre-training](https://arxiv.org/html/2603.16731v1)
的第3节：该文把量化后状态保持不变定义为 stalling，并讨论其累积及 reset。
因此“量化状态存在历史误差”不能单独作为本工作的机制创新。
对我们的块量化实现，需要比较反量化后的实际状态是否不变；仅比较整数 code
不足够，因为共享 scale 的变化也改变实际数值。残差补偿改善 loss 并不能自动
判定 stalling 是唯一来源，亦不能排除它。若要进一步区分，应在相同真实梯度中
同时观察未变化状态比例、保存残差及递推后的误差，而不是因引用了论文就追加
一套长期 reset 搜索。

失败诊断另存于 `results/property/result_analysis_v5/`。第一轮使用的 Python 环境
缺少 torchao，在第一次 optimizer step 报执行失败；保留 terminal 记录，不能
计入数值失败或新增样本。后续重试使用已安装该依赖的环境，是否复现第936步仍需
以实际终态及原环境一致性核验为准。

## 真实梯度传播补充核验

`results/property/result_analysis_v5/real_history_reconstruction/result.json` 保存了
已有 selective-parameter 协议第0条 history 的新测量，固定 checkpoint、8次真实
backward、embedding 和最后一层 mixer out projection。它是历史数据的机制核验，
不是新增独立训练确认。每步使用相同梯度，参数恢复到固定起点，moments 递推。

用实际保存残差递推预测 moment 差异，预测中不加入浮点余项。第8步 OFF 的相对
预测残差（预测误差范数/实际 moment 差异范数）为：

| 参数 | 一阶 moment | 二阶 moment |
|---|---:|---:|
| embedding | 0.000331% | 0.000780% |
| 最后一层 out projection | 0.000264% | 0.002477% |

这支持保存残差在该 history 中主导 moment 差异。ON 的对应预测残差约
0.206%–0.278%，但实际 moment 差异范数也大幅下降；不能将相对预测误差上升
误读成补偿失效。上述预测读取每一步实际保存残差，属于条件传播预测，不是仅从
初始输入预言全部后续误差。

额外记录的 effective-state 不变比例还不能直接作为 stalling 率：真实目标增量
为零也会让状态保持不变。要用于停滞归因，需要额外排除这些坐标。这一记录目前
只作描述，不根据该比例宣布新的停滞机制。
