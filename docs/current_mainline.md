# 当前科研主线

本页规定当前研究中心；[方法](method.md)规定实验定义，
[案例地图](case_evidence_map.md)连接推导与原始结果，
[主张账本](claims.md)规定可说到哪一步。旧版本不再覆盖这三者。

## 1. 我们要回答什么

**数学目标相同的具体训练实现为什么会产生不同 update？哪些差异形成系统性的方向
或缩放，哪些主要表现为波动？能否用同一方法测量、判断并指导局部修改？**

起点是 [Qiu 与 Yao 的 FlashAttention 分析](https://arxiv.org/abs/2510.04212)：
从具体舍入行为和 backward 公式出发，分析偏差怎样进入权重更新，再用训练与
针对性修改检查机制。我们沿用这条研究逻辑，不把其中一个 attention 机制当成
所有算子的通用成因，也不把训练崩溃设成每个案例的必要条件。

```text
声明实现与参考 → 数学成因 → local / gradient / 实际参数写入
→ 能量与方向分析 → 声明范围内的判断 → 局部修改与训练验证
```

我们已经有多种机制推导、测量、干预和训练结果。本轮不重新发明理论，不为了某个
分数过线而改成功标准；重点是让这些证据各归其位。

## 2. “数学上可解释”不是给分数换一个名字

对被测实现和声明参考实现，先写出具体运算差异怎样到达目标 gradient/update。
再说明在什么输入、训练状态或舍入条件下，差异有非零平均分量或稳定的相对缩放。

一条公式可以精确说明误差如何传播，但还需要检查保证不抵消的条件。
反过来，测得方向显著也不能代替成因推导。“实际 backward 实现了正确的导数”
与“实现差异形成了 bias”是两个不同的证明问题。

当前已有的成因语言归纳为两项：

- **正负误差或它们与训练状态的配对不平衡**：例如分块累加、舍入、截断、缩放选择
  或前后向保存状态差异。求和顺序只是其中一种。
- **正负误差得到的响应不对称**：即使输入严格为 +e 和 −e，backward 或 AdamW
  产生的额外更新仍不互为相反数。

两项可在选定误差位置上作精确分解，但这个分解本身不证明某个案例非零。
低秩描述偏差怎样集中，不是必要条件；后续训练反馈解释分离怎样延续，不是第三个
原始成因。具体条件和公式保留在[成因推导](effective_antithetic_symmetry.md)中。

## 3. 三阶段测量检查推导，而不是代替推导

```text
算子输出差异 → 真实参数 gradient 差异 → 目标 optimizer update 差异
```

每层同时记录差异大小、共同方向、相对正常计算的缩放和去掉缩放后的剩余方向。
它们回答推导中的作用是否出现、在哪一步改变，以及幅度有多大。

“前一层没检出，后一层检出”是定位线索，不自动证明该层是唯一根因；还应看效应量、
测量能力和干预。Qwen 的 cold-start 短测与 warm-state 长测不同，说明结论依赖
声明状态，不能把“被 AdamW 抵消”写成永久属性。

有限步方向分数、置信区间、工程阈值和 update 等价检查各有明确作用。
等价判断是正式输出之一，但不是对任意未来训练的通用安全证书。

## 4. 训练后果是选定案例的验证，不是分析完成条件

loss 分叉能证明一对轨迹不再相同，但不自动证明质量下降；参数距离也不能替代验证
loss。对最有信息量的案例，使用独立配对训练检查局部修改是否带来质量、训练成本
或稳定性的可重复变化。没有观察到收益时保留负结果并收窄应用主张。

需要对齐模型、实现差异、参数范围、optimizer、初始状态和数据顺序。配对训练从
相同起点出发，随后允许两边的参数和 moments 自然分开。loss 在同一个评估输入上
比较；不能拿两边不同 batch 的 loss 差当实现后果。

应分别记录：

1. 当前仍有目标实现直接造成的 bias；
2. 直接作用减弱，但此前差异通过训练反馈继续影响更新；
3. 只观察到 loss 不同，尚没有与之对应的 bias 证据。

前两类都可能有研究价值；第三类不能仅凭分叉升级为成因案例。已经建立成因、
后续直接作用不再持续的结果仍保留，不能一律删除为“失败”。

“持久”另注明经过了哪些训练阶段、哪些后期窗口检查。它不由 32 或 4096 这个数字
定义。loss 差异的正负也不是 bias 有无的判据。

## 5. 现有证据怎样组成主线

完整来源和比较限制见[案例地图](case_evidence_map.md)，不再用一张旧审计表代替
全仓库当前状态。

| 研究问题 | 已有代表证据 | 不应跳过的边界 |
|---|---|---|
| 数值源怎样打破抵消？ | Liger 分块累加推导、累加精度修改；同 FP32 不同顺序的补充预测实验 | 不同模型和顺序实验不能拼成一次同协议验证 |
| backward 怎样改变偏差？ | Phi、Qwen 的实际 lm-head backward；Phi 同 AdamW 随机舍入干预 | SGD、cold-start、warm-state 分开；局部无偏不保证 optimizer 无偏 |
| 对称误差为何仍留下更新？ | saved-P、SiLU 的严格正负重放与 AdamW 响应分解 | 人工正负响应与自然实现差是两种实验 |
| bias 是否只是一种固定方向？ | Liger 剩余方向，Phi/v-proj/Mamba 的相对 update 缩放 | 不同几何不是自动新增几个独立成因 |
| optimizer 状态是否影响它？ | 两个 DeepSeek 位置的 cold、warm、重置 moments 对照 | 测到缩放不等于已证明每个新位置的具体底层成因 |
| 实现差异是否进入 loss？ | 历史配对长测；新 Liger 小模型全参数训练到 10000 步 | 单参数实验、全参数实验、单轨迹和多条数据流分开 |

### 最新 Liger 后果

高压力设置第一条数据流延续自同一 4096 步 checkpoint，保持 AdamW 历史，
续跑学习率为 1e-4。4 层小型 GPT-2、字符级数据、全参数训练：

| 量 | 4096 步 | 10000 步 |
|---|---:|---:|
| 参数相对 L2 距离 | 19.69% | 23.50% |
| 被测实现 − 参考实现验证 loss | +0.02778 | −0.02325 |

最后 128 步 training-loss 比约 1.00048，未观察到声明的训练崩溃。
**loss 分叉存在，但不是持续朝更差方向发展。** 这条延续没有逐步重新拆直接作用
和反馈，不能从参数距离增大推断后期直接 bias 的强度。
[设置、数据与解释](liger_single_boundary_collapse_experiment.md)

### 实际参数写入与公式 update 必须分开

新采集在原有 Phi `lm_head dX` 对照上同时保存 AdamW 公式给出的 update 和 BF16
参数的实际写入。32 个冻结状态中，公式 update 的确认集合 RMS 比为 5.47%，但实际
BF16 参数写入差异逐位为零。这里没有推翻旧的 optimizer-response 结果；它说明该
结果在这组 cold-start 状态下尚未提交到所声明的 BF16 参数表示。若训练使用 FP32
master parameter，必须按对应写入路径重新测量，不能沿用本结论。

[机器生成结果](training_numerical_analysis_v1.md)

同一套新采集也复核了两个已有 DeepSeek 开发案例。normalization backward 与
attention projection backward 的实际参数写入 RMS 分别为正常写入的 53.04% 和
46.02%；相对缩放区间分别为 −16.76% 至 −12.15%、−12.08% 至 −9.34%。两者的
公式 update 与实际写入接近，说明差异确实提交到了声明参数。它们用于验证统一
采集路径和 optimizer-state 机制，不重新包装成未见实现确认，也没有在本轮声明
新的训练质量后果。

Liger 的同一统一采集给出另一种边界：AdamW 公式 update 的 RMS 比为 0.653%，
在 1% 能量范围内；写入 BF16 参数后总差异 RMS 升为 4.936%，因而不能给出固定集合
等价判断。公式层的 additive 与 residual direction 都是可检测但小于 0.1% 范围，
实际写入层没有确认这两个方向，只保留约 −0.18% 的小幅相对缩放。这个结果说明
存储舍入可增加差异能量，却没有在该固定集合中重新确认一个强共同方向；历史 Liger
成因与长程证据仍按其原协议解释。

### 新增的配对训练验证

在结果揭示前冻结的 Liger 第三条数据流（stream 111）完成 4096 步。被测实现与
参考实现的共同验证 loss 分别为 2.07744 和 2.08690，差为 −0.00946；4096 个训练
loss 中有 4094 步不同。它确认这条训练轨迹不再相同，但方向与前两条历史数据流
相反：历史差分别为 +0.02778、+0.02821。三条差的描述性区间为
[−0.03820, +0.06923]，跨过零。因此当前不支持可重复的质量改善或恶化，只支持
该数值实现选择能够改变配对训练轨迹。

## 6. 研究范围与实现身份

研究具体训练算子与边界明确的计算区域，重点是 Triton，也允许 ATen/CUDA、
非融合表达和混合路径。三个问题必须分开：做什么数学计算、实际执行什么代码、
哪个实现被选作比较参考。

参考不是绝对真值，提高精度也不自动证明全部语义正确。只有在声明目标上改善并有
验证的变体才称为修复。数学结论应明确是相对哪个参考、在哪些条件下成立。

特别是，Liger 库使用 Triton 不代表其每个误差位置都在 Triton 内。当前安装源码的
dW 累加在常规矩阵乘结果之后；历史运行的具体执行身份仍以当次证据为准。

## 7. 保留的工具与历史结果

- 首轮 1,562 个输出位置是覆盖数，不是完整 bias → loss 案例数。
- 历史六个完整 F+B/参考/参数/32 步记录、统一 AdamW 三个主案例、
  五例统一测量、16 项冻结验证集和 4096 步逐行审计，是不同集合。
- 三阶段测量 v2、等价检查 v2、长程标签各有协议，不共享一个“v2”含义。
- 阴性、未决、非零但不持续的记录全部保留；它们限定成因与后果的范围。
- 大向量随机摘要不是原向量能量的严格上界。已有摘要结果保留其原测量含义；
  不把旧标签改写成数学保证。
- 新的整理和重新分析不回填为旧实验的事前预测。loss 方向放大检查不是未来训练
  外推，人工注入也不是自然实现已经发生的后果。
- 新采集把 AdamW 公式计算出的 update 与参数存储格式中的实际写入分开；旧结果只按
  其原端点解释，不通过改名升级为实际写入证据。

组织。loss 与训练成本是少量案例的实际验证，不再作为每条记录的必经终点。
