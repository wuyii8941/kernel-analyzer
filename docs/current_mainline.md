# 当前科研主线

本页只维护研究问题、优先级和停止条件。逐问题组的数量、来源等级、bias 证据、训练
后果及未解原因只查[全部案例结论](root_cause_closure_current.md)，不在多个页面复制。

## 研究问题

从真实 LLM training 实现中找出可解释的数值偏差：差异从哪个计算选择开始，为什么
形成，在什么输入或状态下具有平均方向或系统性缩放，以及针对性干预是否改变训练。
Triton 是重点；PyTorch/ATen/CUDA、TileLang 和混合实现可复用相同测量方法。
低精度、optimizer state 和 QK channel 都不是预设成因；同精度的合法实现变化同样重要。

研究路线分五步，但不要求每个案例都走到底：

1. 声明语义与比较边界，用同输入、单变量干预定位差异来源。
2. 沿 local、gradient、实际 parameter write 测量传播，不用公式 update 代替写入。
3. 在声明的输入分布和独立统计单位上检验平均方向或缩放；固定集合只作集合内结论。
4. 对值得深入的案例研究历史状态中的传播与累积，不把轨迹距离当作 bias。
5. 用预声明的配对训练终点检验后果；未确认收益、失败和反转均保留。

“有数值差异”“来源已定位”“有平均 bias”“loss 变差”是不同结论。
**根因闭合是纳入最终来源案例的条件，不是总体 bias 已证明的充分条件。**
边界级归因、分量级归因与具体指令级归因也必须分别标注。

## 现有证据承担什么角色

- AdamW8bit 承担残差传播、针对性干预和独立训练结果的主要案例。训练改善不证明
  平均 bias 是唯一中介，也不代表通用优化器改进。
- Liger、Granite 的同精度顺序对照说明精度名称不能决定是否有实现差异；经验库的
  方向检验只覆盖该库、参数载体和 optimizer 条件，不外推自然训练总体。
- saved-P 提供保存量不一致的局部来源；RoPE 等提供物化边界和状态依赖的证据。
  这些结果不能自动升级为长期质量损害。
- 其他来源案例、尚未唯一定位的案例、区域差异和阴性控制分别保留。当前状态以
  [案例总表](root_cause_closure_current.md)为准，不从旧专题的标题判断是否已闭合。

## 工具与研究的分工

已有 `check_bias` 在调用包装、reference 和输入生成器齐备后，自动执行输出级及有限
backward 探针。已有 `diagnose_kernel` 在没有完整 reference 时执行调用者提供的性质
检查和合法变体比较；它目前只给证据，不签发总体 bias 判断。

近期小工具目标是：**家族规格审核一次，新实现只补调用与输入，即可复用性质检查和
有条件的 bias 检验。** 无 reference 不等于无规格；完整正确性、任意源码自动理解、
自动根因解释和训练后果都不作为最小入口的承诺。具体实施及验收统一放在
[系统文档的小工具计划](system.md#轻量诊断工具实施计划)，不另建进度文档。

## 统计与停止条件

Q、平均方向、aligned scaling、超界比例和 loss 各自回答不同问题，保证不能互相借用。
方向或修改选自开发数据时，确认单位不得参与选择；重放相同数据不增加独立样本数。
失败不填成任意大 loss，也不从汇总分母中删除。详见[方法](method.md)、
[统计对齐](statistics_experiment_alignment.md)及[总体合同](population_inference_contract.md)。

接下来不以增加位置数为默认进度。先完成小工具对已有真实案例的可复用诊断，再只为
影响核心解释的竞争假设补实验。未闭合案例的下一次干预必须能区分具体解释，否则保留
边界并停止该轮探索；不把“现有数据不能再分辨”写成“任何人都无法找到原因”。

完成标准是：主要主张有可追溯证据，未知和阴性如实呈现，统计对象与采样一致，
统一工具确实复用代码，代表性干预有训练验证。不是所有 kernel 都自动解释或每例都崩溃。
