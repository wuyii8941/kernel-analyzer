# Liger 单边界训练崩溃实验

## 目的

这组实验检验一个具体问题：只把 Liger fused cross entropy 的 `dW` 累加从
FP32 改为 BF16，能否在一个完整训练的小型语言模型中复现类似 FlashAttention
论文的 loss 爆炸。

被测实现与修复实现从相同模型、数据、随机状态和 AdamW 状态出发。两者唯一声明
的差别是该 `dW` 累加精度。所有模型参数都参与训练。

## 预先定义的崩溃标准

只有满足下列条件才称为训练崩溃：

- 被测实现出现非有限数值；或
- 被测实现的 128 步平均 loss 超过修复实现的 1.5 倍，并持续至少 256 步。

有限的 loss 差异、参数距离或单个较高 loss 点都不算崩溃。

## 实验一：普通训练设置

- 4 层、隐藏维度 256、序列长度 256、batch size 8；
- AdamW 峰值学习率 `3e-4`；
- 2048 步；
- batch 中的样本独立抽取。

结果：被测实现和修复实现均正常完成。最大 128 步平均 loss 比为
`1.000139`；最终验证 loss 分别为 `1.842756` 和 `1.842701`。两者轨迹并非
逐位相同，但没有训练崩溃。

## 实验二：高压力训练设置

- 模型大小保持不变；
- AdamW 峰值学习率提高到 `1e-3`；
- 4096 步；
- 每个 batch 内重复同一段文本，用来加强相似表示和相关梯度；
- 使用两条互不相同的数据流独立检查。

| 数据流 | 最大 128 步平均 loss 比 | 最后 128 步平均 loss 比 | 被测实现验证 loss | 修复实现验证 loss | 结论 |
|---|---:|---:|---:|---:|---|
| 1 | 1.0061 | 1.0039 | 2.0389 | 2.0111 | 正常完成，无崩溃 |
| 2 | 1.0267 | 1.0091 | 1.9915 | 1.9632 | 正常完成，无崩溃 |

第一条数据流的最终参数相对距离为 `19.69%`。这说明局部实现差异经过闭环训练
可以使参数轨迹明显分开；但两边的 loss 都继续下降，所以参数分离不能被直接解释
为训练失稳。

## 放大实验

普通设置还测试了两类受控放大：

1. 按每一步真实 Liger update difference 的形状放大；
2. 沿校准阶段得到的固定方向注入同等量级的更新。

真实形状放大到累计 RMS 约为正常训练 update RMS 的 `93%` 时，训练仍保持有限；
固定方向放大产生了更明显的验证 loss 变化，但在协议允许范围内仍没有达到崩溃
标准。这些实验只能说明方向结构比能量更影响后果，不能作为自然 Liger 崩溃证据。

## 结论

当前实验没有复现类似 FlashAttention 论文的训练爆炸。最准确的结论是：

> Liger BF16 `dW` 累加这一具体边界能够造成可复现的训练轨迹和验证 loss 分叉，
> 但在两个声明协议、两条高压力数据流和较强受控放大下，都没有形成灾难性失稳。

这表明 FlashAttention 的爆炸不仅需要一个有方向的局部误差，还依赖 attention
内部相似表示、谱增长与误差反馈相互加强的特殊闭环。当前 Liger 案例缺少已验证的
同类放大链条，不应被写成 FlashAttention 式崩溃案例。

## 从 4096 步续跑到 10000 步

高压力设置的第一条数据流从第 4096 步 checkpoint 原样续跑：参数与 AdamW
历史状态均不重置，学习率保持 `1e-4`，训练数据从后续位置继续抽取。

- 第 4097–10000 步的最大 128 步平均 loss 比为 `1.00876`；
- 最后 128 步平均 loss 比为 `1.00048`，两条训练曲线已经非常接近；
- 续跑阶段 candidate 的平均训练 loss 仍高 `0.00889`，但差异从中段开始下降；
- candidate 与 repair 的最终参数相对距离从 4096 步的 `19.69%` 增至
  `23.50%`；
- 固定验证集上的差异发生反转：4096 步时 candidate 高 `0.02778`，10000
  步时 candidate 低 `0.02325`。

因此，4096 步观察到的 loss 分叉不是持续朝同一个质量方向恶化。实现差异继续
改变参数轨迹，但训练 loss 差距在后期趋近于零，验证 loss 的优劣方向也会翻转。
这进一步排除了“Liger 差异正在发展成 FlashAttention 式爆炸”的解释。
