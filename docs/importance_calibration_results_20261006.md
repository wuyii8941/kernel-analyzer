## 2. 剂量反应（在 R 上每步注入，种子 0–3 与 R 同种子配对）

| 注入 | 1e-4 | 1e-3 | 3e-3 | 1e-2 | 3e-2 | 1e-1 | 3e-1 |
|---|---|---|---|---|---|---|---|
| u = γ·r：ΔL | +0.0008 | +0.0003 | +0.0005 | +0.0010 | −0.0060 | **−0.0183** | **−0.0535** |
| u = b·‖r‖·ν：ΔL | +0.00002 | +0.0001 | +0.0003 | +0.0018 | +0.0048 | **+0.0432** | — |

（γ = −0.03、−0.1 的 ΔL 为 +0.0051、**+0.0259**。粗体：|ΔL| ≥ σ_seed 且区间不含 0。）

- 阈值：**d*_γ = 0.1，d*_b = 0.1**。缩放型注入就是把每步更新放大 1 + γ，等价于调学习率；本设置训练不足，γ > 0 降低 loss、
  γ < 0 升高 loss，量级约 0.2·γ。固定方向型注入每步沿同一随机方向推 b·‖r‖，b = 0.1 时 loss 升高 0.043（3σ）。
- **训练层面的噪声底**：配对训练在微小扰动下也会分岔（混沌放大），单步作用低于约 10⁻² 时 |ΔL| 在 10⁻⁵–5·10⁻³ 之间随机，
  不随作用大小单调变化（图中左半部分）；作用约 0.05–0.1 时才越过种子波动。

- 可接受改动本身就有可测的单步作用：bf16 autocast 每步有约 0.11% 更新范数的固定方向分量（14 步之后平均作用盖过它自己的
  波动），TF32 为 0.017%。它们都在种子波动之内（第 1 节）——**「存在可测的平均作用」与「重要」是两回事**，这正是本阶段要分开的。
- 已登记的 Unsloth kernel（X1–X3）的单步作用都不到 bf16 autocast 的 0.13 倍（缩放型）与 0.001 倍（固定方向型）；纯 bf16 语境下
  编译后的 RMSNorm 与 Unsloth RoPE 的缩放型作用是 bf16 autocast 的 5 与 20 倍（方向相反），但都比 δ（0.05）小两个数量级以上。

- **类别一致 9/9；预测与观察 |ΔL| 的 Spearman 为 0.45。按事先写定的规则（一致 ≥ 7/9 且 Spearman ≥ 0.6），预测效度记为「差」。**
- 为什么排序失败：9 个替换中 8 个的单步作用都在 10⁻² 以下，落在第 2 节的训练层面噪声底里——预测值都约 0.0008（剂量反应最小
  剂量处的值），观察值是 10⁻⁵–5·10⁻³ 的配对分岔噪声，两者之间的秩相关没有信息。唯一越过噪声底的 X4 方向判断正确，但量级
  低估约一半（其 b̂ = 0.29 超出所测的最大剂量 0.1，预测在曲线端点截断）。
- 所以本设置下能说的是：**单步作用能把「是否超过种子波动」分对（9/9），不能在噪声底以下给出排序或 loss 差的大小**。按计划第 4
  节，预测效度「差」时主张收回到「存在、归因与两轴判定」，加上一条经过检验的二分判断；多步测量与更大的剂量范围写进后续工作。

## 5. δ（阶段 C 之前冻结）

按协议第 7 节：**δ_γ = d*_γ / 2 = 0.05，δ_b = d*_b / 2 = 0.05**（相对每步更新范数的平均作用）。含义：在本设置里，平均作用超过
每步更新的 5% 的替换才有可能把 loss 推出种子波动；可接受改动（bf16 autocast 的 0.11%）离这条线约 45 倍。这取代审计不接受的
「10⁻³·q_R」作为更新层的门槛来源；输出层的 2⁻²⁴·q_R 仍只作本轮的分析尺度。

## 6. 局限

一个模型规模（1,300 万参数）、一个数据集、一个优化器（AdamW）、2,000 步；配对训练每臂 4 个种子；单步状态取自一条参照轨迹的
4 个时刻；T* 假设相邻步的批独立（τ = 1）。δ 与「噪声底以下不能排序」的结论限定在这个设置；计划中的「在两个规模上各测一次
可接受改动的 ρ」尚未做。

## 7. 状态

已完成且有报告：两把尺子、剂量反应、9 个替换的单步作用与 ρ、预测效度（类别 9/9，排序不成立，按规则记为「差」）、δ 的来源。

## 8. 补充：第二个规模上的 ρ（协议第 10 节，运行前提交）

第二规模（d = 512、8 层，结束时验证 loss：R 4.443、R′ 4.419，各一颗种子）上重测 A1–A3、X1–X3 的单步作用
（`results/importance/scale_check/`）：

| 替换 | 规模一 γ̂ / b̂ | 规模二 γ̂ / b̂ |
|---|---|---|
| A1 bf16 autocast | 3.2e-5 / **1.13e-3** | 5.6e-5 / **5.89e-3** |
| A2 TF32 | −1.4e-6 / 1.73e-4 | −3.9e-6 / 1.98e-4 |
| A3 compile | −7.7e-10 / −2.4e-9 | −1.1e-9 / −1.7e-8 |
| X1 Unsloth RoPE | −4.0e-6（含 0） / 1.5e-6（含 0） | −7.7e-6 / 2.9e-6（含 0） |
| X2 Unsloth SwiGLU | −8e-9（含 0） / ≈ 0 | −4.2e-8 / ≈ 0 |
| X3 Unsloth 交叉熵 | −5.1e-7 / ≈ 0 | −1.0e-6 / ≈ 0 |

按事先的判定（分母区间不含 0 的比值，两规模之比在 [0.5, 2] 内为稳定）：**稳定 3 个、不稳定 7 个、无定义 10 个**
（`compare.json`）。原因主要在尺子本身：bf16 autocast 的固定方向分量随模型变宽增大约 5 倍，TF32 的几乎不变；候选 kernel 自身的
作用在两规模间大多在 2 倍以内（其中 X1–X3 的固定方向分量本来就不显著，比值是噪声）。结论：**ρ 相对可接受改动是同一设置内的比较，
不是与规模无关的量**；δ 也只在标定它的设置里成立。这与第 6 节的局限一致，并把它从「未检验」变为「已检验：不稳定」。
