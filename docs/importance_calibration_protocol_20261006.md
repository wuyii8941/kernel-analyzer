# 重要性标定协议（阶段 B，`docs/next_phase_plan_20261006.md` 第 2.1–2.3 节，2026-10-06，运行前写定）

本文在任何标定数据之前提交。已经做过的只有搭建检查：两次 200 步与两次 2,000 步的参照训练（种子 0，fp32 与 bf16，用于
确定步数与确认逐位可重复；不进入任何结果），以及 60 步的配置冒烟（确认每个配置都逐位可重复、哪些替换在本模型里确实改变
计算）。之后的改动只追加到第 9 节。

## 1. 训练设置（`scripts/importance/small_lm.py`）

- 模型：Llama 式解码器，4 层，d = 256，4 个头，SwiGLU（ffn 688），RMSNorm（eps 1e-5），RoPE（θ = 10000），绑定词嵌入，
  GPT-2 词表（50,257）；序列 256，批 32。
- 数据：wikitext-103 训练分片 0 的 GPT-2 token（1.08 亿个）；训练块的顺序由种子决定（同一种子看到同样的批）；验证集为
  wikitext-103 验证集的前 32 批。
- 优化：AdamW（lr 1e-3，β = (0.9, 0.95)，eps 1e-8，weight decay 0.1，作用于二维参数），预热 100 步后余弦降到 10%，
  梯度裁剪 1.0，共 2,000 步。指标：结束时的验证 loss。
- `torch.use_deterministic_algorithms(True)`：同一配置同一种子逐位可重复（已确认）。配对比较的两条训练除被比较的那一项外
  完全相同。

## 2. 参照、可接受改动与候选替换

| 记号 | 配置 | 对照 | 类别 |
|---|---|---|---|
| R | fp32（TF32 关），全部 torch 实现 | — | 参照 |
| R′ | bf16 autocast（fp32 主权重），torch 实现 | — | bf16 语境的参照 |
| P | 纯 bf16（bf16 参数与 AdamW 状态，bf16 autocast），torch 实现 | — | 纯 bf16 语境的参照 |
| A1 | R′ | R | 可接受改动：混合精度 |
| A2 | TF32 矩阵乘 | R | 可接受改动 |
| A3 | `torch.compile`（Inductor） | R | 可接受改动 |
| X1 | R′ + Unsloth RoPE | R′ | 候选 |
| X2 | R′ + Unsloth SwiGLU（前向与反向 kernel） | R′ | 候选 |
| X3 | R′ + Unsloth 交叉熵 | R′ | 候选 |
| X4 | P | R′ | 候选（纯 bf16 训练） |
| X5 | P + 编译后的 HF RMSNorm | P | 候选 |
| X6 | P + Unsloth RoPE | P | 候选 |

不纳入（冒烟已确认在本模型里不改变计算）：HF 式 RMSNorm 中间转换与 HF 式 SwiGLU 在 R′ 下（残差流为 fp32、`F.silu` 本来只
舍入一次）与在 P 下（范数权重在纯 bf16 里停在 1.0：每步更新小于 bf16 在 1 附近的半个 ulp）都与 torch 实现逐位相同；Unsloth
RMSNorm 的反向不计算权重梯度（Unsloth 冻结范数权重），放进从头训练会改变语义而不是数值。

## 3. 尺子

1. **种子波动**：R 的种子 0–7，结束时验证 loss 的样本标准差 σ_seed（不配对）。外部参照另列 0.25%·L̄_R（DeepSeek-V3 的
   相对误差口径），只作对照，不作判定。
2. **可接受改动**：A1–A3 的单步作用 μ_A（第 4 节）与配对训练差（第 6 节）。

## 4. 单步测量（`scripts/importance/single_step.py`）

- 状态：对应参照（A1–A3 用 R，X1–X4 用 R′，X5–X6 用 P）种子 0 在第 250、500、1000、1500 步之后保存的完整训练状态。
- 单位：每个状态 24 个随机训练批（批种子 777），其中 8 个为开发单位、16 个为确认单位，共 96 个（32 开发、64 确认）。
- 同一状态、同一批上，对照与替换各走一步：r = θ⁺_对照 − θ，u = (θ⁺_替换 − θ_替换) − r。
- 作用量（在确认单位上，95% t 区间）：缩放型 γ̂ = mean(⟨u, r⟩ / ‖r‖²)；固定方向型 b̂ = mean(⟨u, ν̂⟩ / ‖r‖)，ν̂ 为开发单位上
  u 的平均方向（交叉拟合）。另记 u 的相对 RMS 与 T*（τ = 1，第 2.3 节）。
- 比值 ρ_X = μ_X / μ_A：用 97.5% 的单个区间构成矩形，ρ 的区间取矩形上 x / a 的最小与最大值；μ_A 的区间含 0 时记为
  「ρ 无定义（可接受改动的作用未建立）」。对每个 X 报告相对 A1、A2、A3 的 ρ。

## 5. 剂量反应（注入，均在 R 上，种子 0–3，与 R 的同种子配对）

- 缩放型：每步优化后 θ ← θ + γ·r，γ ∈ {1e-4, 1e-3, 3e-3, 1e-2, 3e-2, 1e-1, 3e-1, −3e-2, −1e-1}。
- 固定方向型：θ ← θ + b·‖r‖·ν，ν 为整个参数向量上的固定随机单位方向（种子 12345），b ∈ {1e-4, 1e-3, 3e-3, 1e-2, 3e-2, 1e-1}。
- 每档的配对差 ΔL = L(注入, s) − L(R, s)，报告均值与 95% t 区间。阈值 d*：最小的正剂量，使 |mean ΔL| ≥ σ_seed 且区间不含 0。
- 注入的单步作用已知（缩放型 γ̂ = γ，固定方向型 b̂ = b），所以剂量反应直接给出「单步作用 → loss 差」的标定曲线。

## 6. 预测与检验（预测效度）

- 第一步（阶段 B-1）：R 的种子 0–7、全部注入训练、R′ 与 P 的种子 0（保存状态）。**R′ 与 P 的训练结果写入文件但在预测登记
  之前不读取**（它们也是 A1、X4 的结果）。
- 第二步（B-2）：对 A1–A3、X1–X6 做单步测量，按下面的规则写出预测，提交后才进入第三步。
- 预测规则：f_γ、f_b 为剂量反应中 |mean ΔL| 随正剂量的曲线（在 log 剂量上线性插值；小于最小剂量取最小剂量处的值，大于最大
  剂量记为「超出标定范围」）；预测 |ΔL_X| = f_γ(|γ̂_X|) + f_b(|b̂_X|)（点估计），另给用区间上界的上限预测；预测类别为
  「超出种子波动」当且仅当预测 |ΔL_X| ≥ σ_seed。
- 第三步（B-3）：全部替换的配对训练，种子 0–3（与各自对照的同种子配对），观察 |mean ΔL| 与 95% 区间；观察类别「超出」当且
  仅当 |mean ΔL| ≥ σ_seed 且区间不含 0。
- 预测效度的结论（事先写定）：9 个替换中类别一致的个数，以及预测与观察 |ΔL| 的 Spearman 秩相关。一致 ≥ 7/9 且 Spearman ≥ 0.6
  记为「好」，否则记为「差」；两种结果都按第 4 节第三段的写法报告。另检验两把尺子是否一致：A1–A3 的训练差是否落在种子波动内。

## 7. δ 的来源（阶段 C 之前冻结）

δ_γ = d*_γ / 2，δ_b = d*_b / 2（以剂量反应阈值的一半为门槛）；若在所测剂量内没有超出种子波动的档，δ 取最大测量剂量，并说明
这只是上界。同时报告每个 X 相对 A1–A3 的 ρ。
