## 3. 机制

**N3（预注册归因，第 7 节第 5 项；种子 0）。** 候选先把放大后的梯度裁剪到范数 1（只要 ‖g‖ > 1/s 就会裁剪；第 0 步 s‖g‖ = 1.8·10⁵），
再除以 s = 2¹⁶，所以每步梯度的范数恒为 1/s ≈ 1.5·10⁻⁵；第 0 步只有 1.5% 的元素大于 Adam 的 eps（10⁻⁸），其余元素的更新被 eps 压小。把 eps 同样
缩小 2¹⁶ 倍（N3e）之后：γ̂ = **+0.048**（+0.039, +0.057），b̂ = 0.039（0.028, 0.049），相对 RMS 13%。预测 |γ̂(N3e)| < 0.1·|γ̂(N3)|
= 0.092 **成立**：每步更新缩小 92% 主要来自梯度被缩小后 eps 占主导。剩下的部分来自每步梯度都被归一到同一范数（改变了步与步之间
的相对权重）；它本身就在 δ 附近（γ̂ 的区间跨过 0.05，相对 δ 判不了），不是可以忽略的量。

**N1（探索性，未预注册；`n1_token_weights.json`）。** N1 相对对照把微批 i 中每个 token 的权重乘以 N / (k N_i)。在种子 0 的 2,000 个
训练批上，这个权重的均值 1.04、标准差 0.22（5%–95% 分位 0.77–1.44），并且与内容相关：有效 token 不足 64 的段落按 token 加权的
平均权重 1.11，192 以上的 0.95；位置 0 的平均权重 1.04，位置 255 的 0.94。即 N1 系统地加重短段落与靠前的位置——这是一个改变了
训练目标的偏差，单步测量看到的固定方向（b̂）就是它；评价按 token 加权，所以 N1 的 loss 更高。

**N4（探索性，第 7 节第 6 项；种子 0，`n4_attribution.json`）。** 以 2,000 步检查点逐位重跑 R 与 N4。N4 中 8 个块内 RMSNorm 增益的
均值都比 R 低约 10%（比值 0.898–0.903，与 exp(−wd·Σ lr_t) ≈ 0.896 几乎相同，即梯度几乎没有抵消这部分衰减），最后一个增益低 6.7%。
在 R 的最终模型中只换入 N4 的最后一个增益，验证 loss 升高 0.047；换入全部 9 个增益，升高 0.075——分别是实际 ΔL（种子 0 为 0.0118）
的 4.0 倍与 6.3 倍。预测「(i) 解释 ΔL 的一半以上」字面成立，但换入不是可加的分解：N4 自己的其余参数部分补偿了增益的衰减。它
说明的是敏感度：只动 2,304 个参数约 10%，loss 就变化几个百分点。

## 4. 尺子的一个失效方式：不分方向

N4 的单步作用 b̂ = 0.0052（δ 的十分之一）。阶段 B 的固定方向剂量反应在 b = 0.003 与 0.01 时 ΔL 为 +0.0003 与 +0.0018，按此 N4 的
训练层面作用应在 10⁻³ 量级；实测 +0.013，大约十倍以上。原因见第 3 节：剂量反应用的是遍布全部 1,300 万参数的随机方向（大部分
落在词嵌入与线性层上，loss 对它们平坦），N4 的固定方向全部落在 loss 很敏感的 2,304 个增益上。δ 以每步更新的范数为单位，**不区分
作用落在哪些参数上**。按事先规则 N4 仍「在种子波动之内」（0.92σ），二分判断没有错，但它贴着边界，且它的训练层面作用不是噪声
（区间不含 0、四个种子同号）。

所以「尺子随设置移动」从规模（阶段 B 第 8 节）扩展到了两个方向：数据设置（N1：噪声底不同）与作用落在的参数（N4：敏感度不同）。
可能的改进（未运行）：把 u 按 loss 的敏感度加权——例如在每个测量单位上同时算一次验证集梯度，报告一阶 loss 变化 ⟨∇L_val, u⟩；
或者剂量反应按参数组分别标定。

## 6. 结论

- **能抓到非精度的系统性偏差。** 四个训练程序层面的偏差——梯度累加的归一化（已知阳性）、fp16 AMP 的裁剪次序、权重衰减的
  参数分组、学习率调度的次序——在两颗种子上全部检出，其中一个（N5）与解析值吻合到 0.05%。这些候选都不是 kernel：影子状态让
  候选的训练程序自己生成梯度或设置优化器，作用在更新层测量，方法本身不限于数值精度。
- **论文的发现部分不再只有精度问题**：fp16 AMP 中先裁剪再 `unscale_` 每步把更新缩小 92%，loss 高 0.61（43σ），机制经预注册的
  干预确认（eps 占主导）。但四个候选都有公认的正确写法，本轮检验的是检出能力，不是新发现；没有提交上游。
- **二分判断 4 个对了 3 个，错的那个来自尺子。** N1 在 R 中标定的 δ 之内，在 D 自己的种子波动之外；N4 判对但贴着边界，比剂量
  反应按范数预测的大十倍以上。δ 是同一设置、同一类方向内的尺子。

## 7. 局限

- 候选都有已知的正确写法；N1 是唯一一个事先知道「在真实训练中造成过可见影响」的阳性。
- 影子测量两颗种子，配对训练每臂 4 颗；σ_F 只有 4 颗；σ_D 的 4 颗与 8 颗估计相差 3 倍（0.0017 / 0.0054），结论按 8 颗写。
- D 的评价按 token 加权；N1 训练的目标（按微批加权）与评价口径不同——这正是这个问题被修复的原因，但 N1 的 ΔL 有一部分就是
  目标不一致本身。
- 一个模型规模、一个数据集、AdamW、2,000 步；N3 的大小依赖 Adam 的 eps 与放大系数（本轮放大系数一直是 2¹⁶）。
- N4 的归因用换入，有补偿，不是可加的分解；第 4 节的改进建议未运行。
