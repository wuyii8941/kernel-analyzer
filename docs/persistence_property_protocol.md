# Persistence Property v1

## Objective

This protocol tests whether inexpensive local probes can predict which
implementation-induced errors persist in training.  It does not redefine the
existing eight-case ledger and does not assume one universal property.

The measured chain is

```text
local residual epsilon
  -> parameter-gradient residual g
  -> common-state effective-update effect L
  -> closed-loop feedback B
  -> actual drift increment D.
```

Source/transport persistence and feedback susceptibility are separate claim
tracks.  A source-only predictor is not allowed to claim coverage of a
feedback-sustained case.

## Common statistic

For every vector sequence `X` the primary continuous statistic is

```text
A_X(T) = ||sum_t X_t|| / sqrt(sum_t ||X_t||^2).
```

The final value is invariant to a permutation of the observed steps.  It must
therefore be accompanied by natural-order prefix curves and lag-resolved
inner products.  Sign-flip and structure-matched nulls provide finite-window
calibration; `A=2` is retained only as an old engineering gate, not a universal
constant.

The five-level signature is

```text
A_epsilon, A_gradient, A_local, A_feedback, A_actual
```

with `cos(sum(local), sum(actual))` and
`cos(sum(feedback), sum(actual))`.  Coordinate spaces are kept separate.

## Semantic-orbit decomposition

For state `t` and a predeclared set of exact-real-arithmetic-equivalent
schedules `pi`, define

```text
e[pi,t] = fl_pi(a_t) - y_star_t
m_t     = mean_pi e[pi,t]
r_t     = e[default,t] - m_t.
```

`m_t` is a vector, not a scalar.  A nonzero per-state norm is not persistence;
the temporal amplification and lag correlation of both `m_t` and `r_t` are
reported.  The first reduction orbits are joint token permutation for Liger
and joint vocabulary permutation for Phi.  Qwen128 MM reduction and output
rounding are separate orbits because the identified source is the output cast.

## Feedback probes

The exact symmetric recurrence is

```text
D_(t+1) - D_t = L_t + B_t + recurrence_residual_t.
```

Natural residuals are compared under stateless SGD, zero-moment AdamW,
live-moment AdamW, moment reset, and moment swap.  Null residuals must match
support and parameter blocks in addition to RMS; isotropic white noise alone
is insufficient.

## Claim boundary

Development cases can establish a mechanism taxonomy or candidate property.
Only predictions committed before new consequence measurements can upgrade a
candidate to a supported property.  `NOT_APPLICABLE` and `UNRESOLVED` remain
in the denominator and are never converted into negative labels.

The machine-readable frozen protocol and roster are generated by
`scripts/freeze_persistence_property_v1.py` under
`results/property/persistence_v1/`.

## Automated transported-orbit oracle

`transported_orbit_certificate_from_gram` is the reusable decision entry. Its
rows are state-major effective-update errors for a frozen semantic orbit, after
each orbit member has traversed the same proven F+B/optimizer boundary. It
tests the orbit mean against a norm-preserving sign-flip null and emits either:

* `PERSISTENT_TRANSPORTED_CONDITIONAL_MEAN`; or
* `NO_DETECTABLE_PERSISTENT_MEAN_UNDER_PROTOCOL`.

The second result is not named `SAFE`. Missing semantic orbits, incomplete VJP
bindings, nonfinite values, or insufficient states remain abstentions in the
calling runner. The research implementation uses eight orbit members and 16
states. Production can share a captured forward and replay the local VJP; it
does not need to rerun an entire model step for every orbit member.
