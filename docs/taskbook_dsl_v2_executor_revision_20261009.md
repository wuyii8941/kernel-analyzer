## 6 W3 效应与来源（约 2 周，与 W2 后半并行）

- **来源**：存储身份、生命周期、地址到元素的映射、实际生产者与同步事实。数值相等、全零、地址复用都不能证明来源。
- **逐样本竞争检查**：解释时为每个地址记录最后一次写入者（program、操作序号、屏障阶段）。
  同一 program 内没有屏障的写后读、同一次启动中跨 program 的非原子冲突访问，都使程序不被接纳。
- **重复启动检查**：每个输入至少两次。不一致且已接纳时，按 02 §8.7 处理。
- **原子与访存**：原子折叠条件见 02 §6.3；block pointer 先行，descriptor / TMA 的异步 token 随后；atomic_cas 留到本轮之后。
- **缓存键**包含输入内容、逻辑坐标与布局、语义版本、IR 与编译配置、工作精度与求值器版本，以及来源证明。
- **调用级**：从 torch.compile 的图拿到 kernel 输入的生产者；纯布局操作用精确语义，mm 类用大整数精确计算，其余作为声明的边界。
- 【补】回归必须包括：
  - T5 的四个程序与 prog_26 以竞争被拒；
  - T7 的四个原子程序按可交换原子接纳，并走重复启动协议；
  - prog_01 一类的不一致（两次启动 0/96 逐位相同）先诊断，不自动当作随机性。
- 【补】把 T7 的输入内平均从适配器移进工具（02 §8.7），适配器不再承担任何统计。
- 【补】验收中取消模式 A 的一致性重跑，改用每个输入两次启动的逐位比较。上一轮模式 A 占了约 24% 的机时，只提供了这一项信息。

完成标准：
- 审阅方生成的有意竞争程序 100% 被拒，且理由正确；
