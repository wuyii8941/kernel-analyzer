## 找问题（计划第 6 节）

| 方向 | 结果 |
|---|---|
| OpInfo 前向全量筛查 | `__rdiv__`/`__rmul__` 的候选来自同进程用例复用编译缓存 → **B017**（Dynamo 对图内函数只按代码对象守卫，新问题；描述符一支是已知的 #197811） |
| 放宽容差批次 | `index_reduce.amax/amin` 单元素反向的 inf：B016 的同一机制，正是 PyTorch 测试关掉这两项梯度检查的原因 |
| `dynamic=True` 全量（2149 个用例，直接差分预筛） | 只有编译崩溃，全部已知或 main 已修（#180583、#182004、#169757、#159550、#179383、#188217） |
| Inductor mix-order reduction（OSS 默认开、fbcode 默认关） | LayerNorm / RMSNorm 反向、双向求和，行数跨越分块边界，均在 fp32 舍入内正确 |
| Inductor online softmax（默认开），词表大小的 softmax / log_softmax / cross_entropy，掩码与全掩码行、极大 logit、bf16 | 与 eager 同精度，特殊值一致 |
| 归一化与方差（输入均值远大于标准差） | 编译与 eager 同精度，没有朴素方差路径 |
| Dynamo 对各类值的守卫（partial、methodcaller、Enum、类、绑定方法、ufunc、dtype） | 都正确；只有 B017 的共享代码对象与已知的描述符 |
| Inductor 注意力融合（模式改写比语义宽） | **B018**：2.10 中缩放常数与填充值是通配符（温度 / √d_model 缩放被改成 1/√head_dim，差 O(1)）；DistilBERT 模式的替换保留 `== 1` 而模式屏蔽 `== 0`（main 仍有） |
| Inductor `pointless_convert`（删去 dtype 往返转换） | 显式的 `x.to(bf16).to(fp32)` 舍入被删去，`emulate_precision_casts=True` 也一样；已知（#181568，main 有相关改动） |
| 特殊值：435 个一元 / 二元 ufunc 用 OpInfo `reference_inputs`（NaN、±inf、-0.0、极值），直接差分预筛 | 只有 2 处：`softshrink(NaN)` 编译后为 0（已知 #199017）、`frexp` 对 inf / NaN 的指数为 -2³¹（已知 #143790，main 已修）；有符号零无差异 |
| Inductor split/cat 改写（默认开）：300 个随机组合 | 全部逐位相同 |
| SymInt 的 Python 语义（41 个整数 / 浮点表达式，`dynamic=True`，10 个尺寸） | 只有已知的 `round(n, -k)`（#198064）；部分表达式因图断开与重编译退回 eager，符号路径覆盖不全 |
| vLLM `causal_conv1d` 的前缀缓存参数 | main 中没有调用方传入（前缀缓存改为 align 模式 + precopy，后者有测试），是死代码，不再作为候选 |
