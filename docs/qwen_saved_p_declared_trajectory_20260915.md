# Qwen saved-P：1024 步声明轨迹核验

本次运行修复了编译图重新生成后前向 fused-softmax 名称变化造成的边界绑定问题，
只在 Qwen 第 27 层目标 softmax 的前向末次调用和反向首次调用应用 saved-P 重构；
其他层保持原实现。

结果是实际读回的 GPU 运行记录，不是离线推断：

- 1024/1024 个测量状态的目标边界都产生非零局部修改；
- 1024/1024 个状态的直接 update 差异非零，平均 L2 为 `1.2036499794e-4`；
- 累积 update 的 resultant 为 `3.9940802384e-3`，扩散尺度为 `3.9968277190e-3`，
  coherence amplification 为 `0.9993`，因此没有显示出强的共同方向累积；
- 配对轨迹两侧均完成 1024 步，末步参数距离为 `0.05125`；
- 末步 candidate−repair loss gap 为 `+0.00544`，但全程平均仅 `+5.58e-5`，
  其中 507 步为正、517 步为负；最后 512 步均值为 `+1.09e-4`。

因此，本案例现在可以写成：

> saved-P 的局部算术不一致能够进入 q/k 梯度，在声明 warm-state 轨迹上造成非零
> update 和参数/轨迹 non-identity。

不能写成持续恶化、稳定质量损失或自然训练总体 bias。该运行使用声明的顺序状态银行，
不是 iid 总体样本；loss 差异跨步改变符号，且 update 方向接近扩散型。自然总体 bias
和 material training-quality consequence 仍需独立抽样与预注册终点才能判断。

原始运行文件留在过程缓存中；仓库只保留本无过程标识的摘要，便于复算结论边界。
