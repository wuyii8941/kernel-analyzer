# 逐层效应量表协议（RQ4 / M4，2026-10-06，运行前写定）

同一个实现差异经过不同的下游映射后效应量如何变化，哪些变化只有测量实际写入才能看见。本文在任何测量之前提交，之后的
改动只追加到第 6 节。

## 1. 场景

混合精度训练中的 HF `LlamaRMSNorm`（transformers 的公式：转 fp32、`x · rsqrt(mean(x²) + eps)`、转回输入精度、乘权重），
由 `torch.compile`（Inductor，torch 2.10.0、Triton 3.6.0）编译，前向与反向都是 Inductor 生成的 Triton kernel。
权重 fp32（hidden 2048，参数 θ 在各种子间固定：1 + 0.1·N(0, 1)，生成器种子 7777），激活 x 与上游梯度 dY 为 bf16 的
N(0, 1)（64 行）。eps = 1e-6。

## 2. 测量点（每行同一组种子 0–95，开发 0–31、确认 32–95）

| 层 | 量 | 口径 |
|---|---|---|
| L1 输出 | y = RMSNorm(x)（fp32） | e_num = K − K_R、e_sem = K_R − f（f：fp64 的实数公式） |
| L2 梯度 | ∂L/∂w = Σ_rows dY ⊙ x̂（fp32） | 同上（f：fp64 公式经 autograd） |
| L3 理想响应 | u = Δθ(K) − Δθ(K_R)，真实优化器语义的区间（`update_layer`） | SGD；AdamW 零状态（t = 1）；AdamW 历史状态（t = 10，状态由 9 次 f 梯度生成，生成器种子 2000–2008） |
| L4 实际写入 | u = θ′(K) − θ′(RN32(K_R))，同一个 fp32 torch 优化器（CPU、foreach=False），只替换梯度；K_R 两端舍入到不同 fp32 值时最多枚举 4 个候选，超出记为未建立 | 同 L3 的三种优化器 |

常数：lr = 2⁻¹⁰，β = (0.9, 0.999)，eps = 2⁻²⁷，weight_decay = 0（与盲测 v2 第 3 阶段相同，精确的二进分数）。

## 3. 判定与报告

- 每行报告规则 R1、R2、R3、R5 的平均投影（相对参照范数的效应量）与区间、参照类别（L1–L2：完整参照比例；L3：区间
  宽度；L4：唯一重放 / 枚举 / 未建立的坐标数），判定只作最后一列。
- Holm 覆盖全表的规则检验；偏斜按统计校准文档第 4 节处理。
- 不以「这一层检出、下一层未检出」推断抑制；层与层之间只比较效应量与区间。
