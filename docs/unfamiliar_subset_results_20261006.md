## RQ3：e_num 的平均作用（Holm 覆盖全部 248 个规则检验）

| 入口与输出 | 确认的规则 | K 的相对收缩（s3） | 正确舍入 RN(f) 的 s3 | 归类 |
|---|---|---|---|---|

| U05 SwiGLU 的 de；U07、U09 GeGLU 的 de | R2+ R3+ | 3.2–4.2·10⁻⁵ | 3–7·10⁻⁶ | 实现特有（机制未逐个核实） |
| U06–U09 GeGLU 的 h、df | R2−（幅度被推离 0；U06、U08、U09 另有 R3−） | −1.4·10⁻⁵ 至 −9.5·10⁻⁵ | \|s3\| ≤ 1.3·10⁻⁵ | 实现特有（机制未核实） |
| U12 softcap 交叉熵的 loss（fp32） | R1− R2− R3− R5+ | −2.8·10⁻⁸ | 1·10⁻⁹ | 实现特有（fp32 级，机制未核实） |

| U01 的 dX，U02（Gemma）、U03（LayerNorm）的全部输出 | 无（未经 Holm 前有 R2/R3 检出） | 2–5·10⁻⁶ | 与 K 相同 | 输出格式本身：bf16 正确舍入在这一输入分布上也有同样的收缩 |
| 其余（交叉熵 loss 与 dlogits 等） | 无 | — | — | — |

s3 = Σ(x − f)(−f) / Σf²，在确认种子 32–95 上取平均；f 代替 K_R（各输出的 e_sem 为 0 或常数级）。对照的意思：同一个
函数、同样的输入，若只在最后正确舍入一次到 bf16，平均作用是多少。

**RoPE 的机制（逐位核实）。** kernel 在 bf16 里计算 `Q1·cos − Q2·sin` 与 `Q2·cos + Q1·sin`（`sin1.dtype` 为 bf16）。
PTX 全部是 `fma.rn.bf16`；设备输出与两种运算次序逐位比较：前半为 fma(Q1, cos, −RN(Q2·sin))（100% 逐位相同），后半为
fma(Q1, sin, RN(Q2·cos))（100%）——编译器的乘加合并在后半先把 `Q2·cos` 舍入到 bf16。bf16 的 cos 在低频维接近 1
（1 − k·2⁻⁸），`Q·cos` 舍入回 8 位有效位时系统地偏向 0。按这两个次序模拟：前半 2.3·10⁻⁵、后半 1.24·10⁻⁴、平均
7.3·10⁻⁵；设备实测 7.5·10⁻⁵（前半 2.7·10⁻⁵、后半 1.23·10⁻⁴）。对照：同一 kernel 改用 fp32 的 cos / sin（在 fp32 里算、
写回时舍入一次）为 4.8·10⁻⁶；torch bf16 eager 的 `q·cos + rotate_half(q)·sin`（每步舍入）为 1.49·10⁻⁴，是 Unsloth 的两倍。

## 结论

- **RQ1**：14 个此前未经工具检查的入口，参照全部建立（31/31），没有不支持的操作。
- **规格**：没有规格差异候选。
- **RQ3（发现型，无先验标签）**：经 Holm 确认的平均作用都属于「实现特有」：比只舍入一次的正确实现多出 10⁻⁵–10⁻⁴ 的
  系统收缩或扩张。已核实机制的三类（RoPE 的 bf16 运算次序、RMSNorm 与 SwiGLU 照抄 HF 的中间 bf16 转换）在 HF 参考实现
  里同样存在（RoPE 的 eager bf16 版本还更大），所以**不是 Unsloth 的缺陷**，是 bf16 中间转换在这类算子上的一般性质；
  改为 fp32 计算、最后舍入一次可去掉 94–98%（RoPE 为实测，RMSNorm 与 SwiGLU 为模拟）。作用大小（相对 10⁻⁴）是否影响训练，本工作没有证据，不作主张。
- 工具在这里的作用：无标签、无提示地找出这些方向作用；「正确舍入」对照把它们与输出格式本身的作用分开；逐位比较
  把 RoPE 的来源定位到具体的乘加合并次序。

状态：已完成且有报告（RQ1、规格、RQ3 的检出与归类）；待核实（GeGLU 扩张、各 de、softcap loss 的机制）。
