# 所有历史偏差候选的长程复核

仓库中有 **23 个唯一主矩阵 case ID**；本审计逐行复核 **301 行**。其中包含历史案例、69 行冻结短筛候选、57 行旧 coherent F+B 候选、150 行 Gemma/Llama exact targets，以及 roster/control rows。这些来源可能重叠，因此分别报告来源分母和逐行审计分母，不能相加冒充独立案例数。

当前机器标签中有 **43 行**同时具备 long-run bias evidence 和 paired loss split：

- **3 行**为已导出后半程窗口的 direct bias；
- **8 行**有整段 long-run direct bias，但 late-window statistics 尚未单独导出；
- **32 行**为 feedback-sustained bias；
- 目前合计只有 **4 行**具有显式 late rolling-window confirmation。

另有 **5 行**出现 paired loss split，但 direct bias 没有通过 long-run gate。更宽的 `outcome_relevant_case_count` 为 **105 行**，其中包含 **57 行**尚未测量 4096-step persistence 的历史 coherent candidates，因此不能全部称为 final persistent cases。未决或 abstain 共 **45 行**，不作阴性判断。

三类追加候选的统一重放分母是 **276 个**：冻结短筛候选 69 个、旧 coherent F+B 候选 57 个，以及 Gemma/Llama exact targets 150 个。当前机器审计中仍有 **41 个**待完成或未决；其余已经得到终态标签，但终态可能是 persistence 未测量、feedback、not applicable 或 unresolved，不能自动算 direct bias。

Gemma/Llama 的追加首轮扫描有 **242 行**，冻结升级门通过 **0 行**；其中 **150 个**残差非零目标绑定到 exact target replay。已经完成 16-step pilot **125 个**，需要 long replay **53 个**，完成 long replay **46 个**，其余 **41 个**待完成或未决。

短筛候选图中有 **69 个**候选，其中 **50 个**已有旧确认材料。它们都已进入长程任务并得到终态记录；其中大多数仍只有“出现 paired loss split、但 formation/persistence 未确认”的候选标签，不能当作 final persistent cases。

旧的全量 T3/F+B 结果中另有 **57 个**具体 endpoints 曾出现方向信号。它们的旧标签只负责送入长程后果审计；当前记录仍未提供 4096-step persistence measurement，因此保留为 outcome-relevant historical candidates，不升级成持久性 bias。

持久性 bias 的必要条件是 bias 本身在 4096 步仍然存在：直接源方向或反馈有效更新方向至少有一个通过长程检验。配对训练中的参数或 loss 分叉是后果证据，不足以单独把一个没有持久 bias 组件的记录升级为案例。这里不要求两条训练轨迹收敛到不同的最终 loss，也不作这种声称。

## 口径

- 32 步只能说明短程方向性，不能单独称为持久性 bias。
- 4096 步是同一训练状态下的直接更新审计，不等于完整全参数训练收敛。
- 配对 loss gap 是功能后果信号；这里不要求、也不声称两条轨迹收敛到不同的最终 loss。
- 反馈造成的轨迹分离不能替代直接 bias 证据。
