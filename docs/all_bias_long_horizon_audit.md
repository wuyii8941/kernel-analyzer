## 口径

- 32 步只能说明短程方向性，不能单独称为持久性 bias。
- 4096 步是同一训练状态下的直接更新审计，不等于完整全参数训练收敛。
- 配对 loss gap 是功能后果信号；这里不要求、也不声称两条轨迹收敛到不同的最终 loss。
- 反馈造成的轨迹分离不能替代直接 bias 证据。
