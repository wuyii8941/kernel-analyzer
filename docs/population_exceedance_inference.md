# 随机训练状态中的超界比例检验

固定集合的总 update 差异可以直接计算，但不能自动推广到随机训练状态总体。总体
平均能量

\[
Q=\frac{\mathbb E X}{\mathbb E B}
\]

仍只有两条诚实路径：使用带明确矩条件的大样本近似，或在实验前能证明
`X`、`B` 总体上界时使用有限样本有界检验。现有检查已经表明，前者在本项目的
小样本和稀有大误差场景中会明显错误通过；后者在真实训练中常因上界太宽而缺少
检出能力。

为给下一阶段提供一个条件更现实的有限样本结论，生产代码另行实现以下对象：

\[
p_\delta=\Pr\!\left(\sqrt{X/B}\geq\delta\right).
\]

它回答：从声明的训练状态生成过程中独立抽取一个状态，其实际参数写入差异超过
逐状态 RMS 范围 \(\delta\) 的概率有多大？协议事前声明可接受比例
\(\varepsilon\)，使用精确二项分布单侧界判断 \(p_\delta<\varepsilon\)。处在
margin 上的状态按超界计数。

这个结论需要：

- 每行对应一个由声明生成过程独立抽取的单位；连续训练步骤不能冒充独立单位；
- 每个单位的正常 update 能量严格高于事前声明的下限；
- candidate/reference、参数范围和实际参数写入协议已经锁定；
- 多案例“至少一个超范围”的发现另行使用 Holm 等校正。

它不需要预先知道误差能量最大值，也不依赖正态近似。但它**不是平均能量
\(Q\) 的证书**：一次超界究竟大多少不会改变超界计数。因此仓库保留两个不同输出：

| 总体问题 | 方法 | 当前状态 |
|---|---|---|
| 平均 update 能量是否低于范围 | 有界 Hoeffding；需事前总体能量上界 | 条件性可用，普通训练的有用上界仍待建立 |
| 超过逐状态范围的状态比例是否足够低 | 精确二项单侧界；需独立单位 | 生产实现与完整合成路径已验证，真实总体数据尚未采集 |

生产验证从高维 `u/r` 向量出发，经原坐标统计进入同一分析函数。对边界总体，16、
64、299 个独立单位的精确错误通过概率分别为 2.81%、3.75%、4.95%，均不超过
名义 5%。当允许最多 1% 的状态超界且观察到零次超界时，298 个单位仍为
`INCONCLUSIVE`，299 个才可返回 `EQUIVALENT`。机器结果见
`results/property/numerical_coverage_v1/population_statewise_exceedance_validation_v1.json`。

这些结果证明所实现二项判断的有限样本错误率，不证明已有固定窗口来自声明随机总体，
也不把没有收集的真实训练单位补造成总体证据。

采集程序提供独立单位的原坐标统计后，统一入口为：

```bash
python scripts/run_training_numerical_analysis.py population-exceedance \
  RAW.json PROTOCOL.json OUTPUT.json
```

该入口会核对实际参数写入、实现边界、显式且不重复的 `inference_unit_ids`、正常
update 能量下限和总体对象；缺一项就返回无法判断或无效，不会从 `state_ids` 猜独立性。
