# Bias、来源、干预与复用：计划执行结果

本页回答一个收窄后的问题：能否在真实实现中区分系统性 bias 与单纯误差能量，
定位其数值来源，验证针对性修改的训练作用，并在另一个算子族复用诊断流程？
机器汇总由 `scripts/build_bias_proof_audit.py` 生成到
`results/property/bias_proof_plan_v1/result_v2.json`。它读取既有原始记录并调用当前生产
统计代码，不手抄实验数值，也不把旧数据改称新的未见确认。

截至 2026-09-15，新增的 SiLU source-factorial、saved-P 轨迹和 Liger 长度 256
确认已纳入[当前根因闭环账本](root_cause_closure_current.md)。本页保留原计划的
验收结构；若与当前账本的根因等级或开放分支冲突，以当前账本为准。

## 验收结论

| 要证明的内容 | 当前证据 | 结论 |
|---|---|---|
| 不只是误差能量，而有系统性结构 | AdamW8bit 的 32 条独立、预先声明的新 gradient histories 中，candidate-reference write 与 FP32 write 的内积 32/32 为正；正方向比例的一侧 95% 下界为 91.06% | 确认声明 history 总体中的 repair-aligned 系统性效应；没有证明完整高维均值向量非零 |
| 来源如何进入训练状态 | 真实 8-step gradient history 上，仅用实际保存残差递推即可预测第 8 步 moment 差；OFF 最大相对预测误差约 0.00248%。同一批 16 条冻结 histories 上，正确读回残差令绝对 aligned gain 16/16 下降 | 保存残差是所测 moment 差和 aligned effect 的直接来源；仍不是完整向量均值或 loss 唯一中介证明 |
| 针对性修改是否影响训练 | 正确读回残差在固定 histories 中 8/8 优于坐标移动和时间倒序；8 对独立训练的 OFF−ON loss 均值为 +0.02829，95% 区间为 [+0.01574,+0.04083] | 修改在声明设置中具有实际训练收益；尚不能说平均 bias 是唯一中介 |
| 诊断能否复用于另一算子族 | Liger 的 FP32 dW 累加顺序协议在看结果前冻结；forward 与 hidden gradient 逐位相同，matched sham 精确，长度 64/256 的互斥确认均复现预先声明的来源方向 | 同一阶段/方向诊断能定位另一个同精度算术来源；幅度很小，没有原坐标写入或长期 loss 后果主张 |

四项均有对应证据，但不是同一种“完成”。第一项是总体方向频率结论；第二项是固定真实
history 的机制重构；第三项是独立配对训练；第四项是另一个固定集合算子族的诊断复用。
不允许把它们拼成“平均 bias 已被证明是 loss 改善的唯一原因”。

随后对 Liger 使用互斥的长度64输入库进行了确认：32/32状态完成，前向与
hidden-state gradient 逐位相同，顺序预测方向在确认半区14/16同向；参数梯度的
additive/residual 分支和零矩 AdamW 首步的三个分支均确认。该运行是对既有顺序预测的
互斥输入复核，不是新的盲法则或长程训练结果；详细记录见
`results/property/liger_fp32_chunk_order_v1/length64_confirmation.json`。

## Bias 与波动怎样分开

AdamW8bit 的主要严格证据不是 4% 左右的 RMS，而是预先声明方向上的 32/32 同号结果。
逐 history aligned gain 的均值约为 0.07808%，条件 Student 区间约为
[0.06198%, 0.09417%]；更稳妥的有限样本结论仍是正方向比例，因为后者只需要 iid
二元指标，不需要对 gain 的小样本分布作正态近似。

生产 profile 另加入一个高能量零均值对照：确认集合在同一方向上交替 +2% 与 −2%，
总 RMS 为 2%，但三个均值分支均不确认。它验证程序不会仅因能量很大就把波动写成
平均 bias。这个合成对照不能代替真实实现证据，只用于校准统计语义。

因此，本案例现在可以说：

> AdamW8bit 在声明的随机 history 总体中具有可复现的 repair-aligned 系统性效应；
> 保存状态残差能够定量解释所测 history 的 moment 差，正确读回它能改善声明训练设置。

不能把这句话缩写成“已证明完整向量均值 bias 导致 loss”。残差的方差、坐标对应、
时间结构及 optimizer 的非线性响应仍可能共同影响训练结果。

## 来源与 bias 的直接连接

早期证据分别确认了默认实现的 aligned effect 和残差的 moment 递推，但二者来自不同
分析，不能仅靠叙事拼成根因。为补这个缺口，本轮在此前为补偿 RMS 实验冻结的同一批
16 条 histories 上重新读取三种实际参数写入：默认 AdamW8bit、正确残差读回和 FP32 AdamW。
这是结果后的新统计问题，不是新的盲案例发现。

- 默认 aligned gain 16/16 为正，均值约 0.07782%，条件区间约 [0.05646%, 0.09918%]。
- 正确读回后均值约 0.00000465%，条件区间约 [−0.00001259%, 0.00002189%]，正负各 8 条。
- 16/16 histories 的绝对 aligned gain 都下降，一侧 95% 比例下界约为 82.93%。

因此现在不再只是“总误差得到改善”：在相同 histories、相同 FP32 reference 和相同
方向定义下，读回保存残差显著降低了观察到的 aligned 分量；区间包含零不证明该分量为零。
它仍不证明所有
坐标的向量均值为零，也不把训练 loss 改善唯一归因于 aligned 均值。

## 第二算子族为什么有诊断增量

Liger 比较的两个实现使用相同 FP32 数值，只改变 64 个 dW 分块结果的加法顺序。
如果只检查 forward 或 hidden gradient，结果完全相同；确认集合的 parameter-gradient
和公式 update 的摘要相对 RMS 也分别只有约 0.0000213% 与 0.000000308%。
采集器将它们投影到 8192 维摘要；其中 update 来自 `adam_delta`，没有实际执行参数写入。
因此这些比例不是原坐标实际写入的 RMS，不能用来签发实际写入等价或训练损害结论。

但阶段追踪、held-out direction 和事前声明的不同加法顺序预测共同指出：差异开始于
dW 累加，并在保存的 gradient/公式 update 摘要中留下方向结构。这提供了来源定位的
案例证据，不证明已经到达实际参数写入；也未完成独立来源标签下的诊断优势比较。
固定输入的状态 ID 不构成 iid 抽样证明，事后 Student 区间不升级为总体保证。

## 自动化边界

以下部分已经自动化：读取充分统计量、区分能量与 aligned effect、计算条件区间和精确
方向频率界、执行零均值对照、核对机制/干预/训练记录，并生成四项验收结果。

以下仍需科研判断：reference 语义是否合理、哪个方向应在开发阶段后冻结、统计单位是否
真的独立、干预是否只改变声明计算，以及如何解释 loss。程序不会从文件数量自动推出
根因，也不会自行把有利结果升级为因果主张。

## 最终边界

旧机器汇总的完成标签是当时四项任务的会计结果，不是本轮复核后的统一科学完成声明。
AdamW8bit 的来源传播与独立训练结果保留；Liger 的同精度诊断复用限于局部/摘要证据，
若要支持真实写入链，必须补实际写入观测。跨模型外推、完整高维均值保证和诊断优势
评价分别判断，不由这个旧完成标签获得。
