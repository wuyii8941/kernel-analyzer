# 总体能量等价检验：样本量检查

本次直接调用生产函数 `population_total_energy_equivalence`，不改变 margin、
分类器或 nominal alpha。记录见
`results/property/numerical_coverage_v1/population_sample_size_audit_v1.json`，
共 36 个设置，每个设置 2,000 次模拟。输入先形成一维 effect/reference
向量，再计算原坐标能量；这是 Q 推断检查，不是全部三阶段生产链的验证。

## 关键结果

在真实 RMS 比例恰为 margin=0.01 的边界，严格等价零假设成立。
因而返回 EQUIVALENT 属于错误通过。名义单侧错误率为 5%。

| 能量分布 | 独立单位数 | 错误通过率 | 模拟比例的逐项 95% 区间 |
|---|---:|---:|---:|
| 标准化 t8 平方 | 16 | 16.60% | 15.03%–18.29% |
| 标准化 t8 平方 | 64 | 11.90% | 10.55%–13.39% |
| 标准化 t8 平方 | 256 | 8.00% | 6.89%–9.27% |
| 标准化 t8 平方 | 1024 | 7.50% | 6.43%–8.74% |

这些区间描述模拟比例的不确定性，不是训练效果的置信区间，也没有声称
对全部场景同时覆盖。t8 平方具有有限方差；因此不能将这里的问题全部
归因于违反有限方差条件。渐近条件成立不保证当前样本量足够。
另测的 t3 平方不满足能量有限方差条件，只用于展示适用范围外的失败。

不能依据双侧区间总体覆盖接近 90% 就忽略错误通过偏向一侧的问题。
也不能事后挑一个较好的分布或样本量，将全部检查标为通过。

## 对当前工作的影响

- 固定集合原坐标能量的直接计算仍保留其集合范围，不能自动推广到总体。
- 当前 studentized 总体检验不具备这里所需的小样本错误率保证。
- 本次没有修改正在运行实验的统计源码、阈值或历史协议。
- 下一步必须检验具有明确附加条件的有效推断方案，并评估这些条件能否
  在真实训练数据中建立；不能用观测最大值冒充总体有界条件。
- 重新选择方法后，应使用另外冻结的随机数据验证，不能把这批已见模拟
  重新称为未见确认。统计理论目标仍未完成。

## 一个可直接计算的有限样本反例

令正常更新能量 B 恒等于 1，margin 为 δ。取独立 Bernoulli(p) 随机变量 Z，
令差异能量 X=δ²Z/p。这可以由一维更新差异 u=δ√(Z/p)、参考 r=1 实现。
则 E[X]=δ²，Q=δ²，正好处于严格等价检验的零假设边界。
每个固定 p>0 的分布都有有限支撑、所有矩有限，且 X 的总体方差非零。

在 n 个样本全部没有出现稀有事件时，所有观测 X 都为零。
当前生产函数返回 EQUIVALENT，而这个事件的概率是 (1-p)^n。
例如取 p=1/(20n)，n=16、64、256、1024 时，此概率均约为 95.12%。
本机已直接调用生产函数核对这些全零样本的判定；这里的错误概率下界由
上述分布精确计算，不是 Monte Carlo 估计。

注意每个 n 使用不同 p，因此这不是反驳固定分布下的渐近收敛。
它说明：仅列出“独立、有限方差”，不能给当前有限样本判定一个对这些
分布统一有效的 5% 保证。增加一个固定样本数无法消除这个逻辑缺口。
观察到样本方差为零也不证明总体方差为零。

可执行修正需要真实可用的附加信息，例如事前已知的能量范围或尾部约束，
并使用与该信息匹配的推断。观测最大值不是这样的总体范围证明。
本反例不证明所有可能检验都失败，也不支持直接丢弃总体分析目标；它约束
的是当前方法可以声称什么，以及后续修正必须解决的问题。

## 条件性有限样本修正（2026-09-08）

生产代码现增加两个有界总体函数，分别检验总 update 能量和整体 aligned scaling。
实验协议必须在观察统计单位之前给出有限的 effect/repair 能量上界及来源；程序用
Cauchy--Schwarz 推出 inner-product 上界，再对相应均值不等式使用 Hoeffding 界。
观测最大值不能充当该上界，任何观测超过声明范围都会使测量无效。

[完整向量到生产判断的验证](../results/property/numerical_coverage_v1/bounded_population_equivalence_validation_v3.json)
在 2,000 次稀有事件边界重复中，总能量和 aligned 两项均为 0 次错误签发；各自错误率
的逐项 Wilson 95% 上限约为 0.192%。这个结果验证实现和该合成设置，不把模拟升级为
数学证明；有限样本保证来自明确的独立性和事前有界条件。普通 LLM training 若不能
证明有用上界，仍不得签发这一总体结论。原 studentized 结果继续作为失败记录保留。
