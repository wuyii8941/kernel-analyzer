# 统计公式与实验设计对齐

本页补充[方法](method.md)，不改变历史协议、原始结果或冻结源码。每个结论都必须同时声明统计对象、独立单位、数据生成方式和数据用途。

## 1. 统计单位

- 固定状态集合：直接计算该集合的量，不外推到随机总体。
- 独立抽取的 gradient history：一整条 history 是一个单位，其中的多个步骤不是多个独立样本。
- 完整配对训练：共享起点、数据与随机策略的一对运行是一个单位。
- 同一数据流的重复执行只检查重复性，不增加独立单位数。
- 同一训练运行的多个评估时点组成该运行的轨迹，不增加训练重复数。

共用 checkpoint 将结论限制在该 checkpoint；它不自动破坏按照声明机制独立抽取的数据流之间的独立性。

## 2. 固定集合

令候选与参考的实际参数写入差为 \(u_i\)，参考写入为 \(r_i\)，并定义

\[
X_i=\lVert u_i\rVert^2,\qquad
B_i=\lVert r_i\rVert^2,\qquad
A_i=\langle u_i,r_i\rangle.
\]

对声明集合 \(\mathcal S\)：

\[
Q_{\mathcal S}=\frac{\sum_iX_i}{\sum_iB_i},\qquad
s_{\mathrm{rms},\mathcal S}=\sqrt{Q_{\mathcal S}},\qquad
\beta_{\mathcal S}=\frac{\sum_iA_i}{\sum_iB_i}.
\]

这些是集合内的直接量。只有原向量或完整 Gram 足以恢复向量均值时，才能计算

\[
M_{\mathcal S}=\frac{\lVert |\mathcal S|^{-1}\sum_i u_i\rVert^2}
{|\mathcal S|^{-1}\sum_iB_i}.
\]

仅有能量标量不能恢复 \(M_{\mathcal S}\)；CountSketch 中的量也不能称为原坐标精确量。

## 3. 随机 history 总体

平均能量问题定义为

\[
Q=\frac{\mathbb E X_j}{\mathbb E B_j},\qquad
D_j=X_j-\delta_Q^2B_j.
\]

当且仅当观察前存在可审核的总体上界 \(0\le X_j\le X_{\max}\)、
\(0\le B_j\le B_{\max}\) 时，使用生产实现中的单侧 Hoeffding 界：

\[
U_D=\bar D+(X_{\max}+\delta_Q^2B_{\max})
\sqrt{\frac{\log(1/\alpha)}{2n}}.
\]

\(U_D<0\) 支持相应的平均能量等价判断。样本最大值不能充当总体上界；上下界各是错误概率为 \(\alpha\) 的单侧界，不合称一个 \(1-\alpha\) 同时双侧区间。

逐 history 超界比例是另一个问题：

\[
I_j=\mathbf 1\{X_j\ge\delta_Q^2B_j\},\qquad p=\Pr(I_j=1).
\]

独立同分布单位和 repair-energy floor 有效时，使用精确二项单侧界。上界低于允许比例时通过；下界高于允许比例时不通过；其余为证据不足。它不控制平均 \(Q\) 或超界后的幅度。

## 4. 方向频率与平均方向

方向必须在确认单位揭示前冻结；它可以是一条固定向量，也可以是事前冻结的逐单位方向生成规则。对 \(Z_j=\langle u_j,v_j\rangle\)，正方向频率、负方向频率和零值分别记录。

正方向频率不等于平均投影大小，更不能替代

\[
M=\frac{\lVert\mathbb E U_j\rVert^2}{\mathbb E B_j}.
\]

当前修正入口把“正方向频率低于基准”按其真实含义报告，不解释成负方向频率已被确认。

## 5. 完整配对训练

第 \(i\) 对训练在固定评估集和预声明终点 \(T\) 上均完成且有限时，定义

\[
d_i=L_T^a-L_T^b.
\]

历史协议的配对 t 区间为

\[
\bar d\ \pm\ t_{n-1,0.975}\frac{s_d}{\sqrt n}.
\]

这里 \(n\) 是配对训练数。其精确解释依赖独立、同分布且正态的配对差；在当前小样本下属于带假设的区间。固定评估集使比较更精确，但结论也条件于该评估集。

同一数据上提出修改并重新执行，支持该数据上的机制归因。它不能同时增加“未参与选择的新数据确认”的独立证据。最终平均改善若作为外推主张，应在修改、训练长度、主要比较、评估集、margin 和失败规则全部冻结后，使用未参与修改选择的新训练流。

## 6. 训练数值失败

对条件 \(a\) 的第 \(i\) 条训练定义

\[
F_i^a=\mathbf1\{\text{在终点 }T\text{ 前发生协议定义的训练数值失败}\}.
\]

非有限 loss 或参数属于训练数值失败。CUDA 不可用、依赖缺失、OOM、编译和运行时中断属于执行失败。同一数据流的多次重试是同一个统计单位。

若任一比较条件没有完整有限终点，原定最终-loss差值没有定义。处理规则是：

1. 按“数据流＋条件”报告完成、数值失败、执行失败和未完成数量；
2. 不用大常数或无穷替代缺失的最终 loss；
3. 可以描述双方均完成子集，但必须标为条件于完成；
4. 本轮结果后的失败率只作描述，下一轮推断前冻结失败端点和多重性。

当前新增的失败感知汇总入口为：

```bash
PYTHONPATH=.:src python scripts/summarize_structured_residual_training_v2.py \
  --root results/property/result_analysis_v3/structured_training \
  --output results/property/result_analysis_v3/structured_training/failure_aware_summary.json
```

它读取原始运行和所有失败尝试，按统计单位去重。完整运行优先于此前的环境失败；真实数值失败阻止对应的全体最终-loss判断。

## 7. 当前证据与已完成的新确认

- 固定集合的原坐标 Q、实际参数写入和固定 gradient history 机制实验继续保留。
- AdamW8bit 的 32 条 iid 有放回 gradient histories 支持声明经验总体中的超界比例结论。
- 8 对 OFF/ON 同路径实验支持已选数据流上的干预归因；重复历史 ON 不增加 \(n\)。
- 当前结构干预使用同一批已见训练流，属于机制归因。
- 历史训练流经过最小距离筛选，不满足严格 iid；相应 t 区间保留为条件性近似。
- 最终方案确定后冻结的独立有放回完整训练流确认已经完成：8 对均有有限终点，
  OFF−ON 均值 `+0.0282858`，95% 配对 t 区间 `[+0.0157405,+0.0408311]`。
  抽中的数据若发生重叠仍按原抽样执行；本次结论条件于固定 checkpoint、评估集、
  声明起点总体和配对差值正态假设。

多项等价都必须通过时继续使用 IUT；分别报告多个超范围结论时按照事前检验组控制多重性。统计校正不能修复数据选择、伪独立或未定义的终点。
