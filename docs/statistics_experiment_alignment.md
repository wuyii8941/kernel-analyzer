# 统计公式与实验设计对齐

本页只维护“实验怎样形成统计单位、怎样使用数据、失败怎样汇总”。总体检验的公式、
有限样本条件和验证结果统一维护在[随机总体推断合同](population_inference_contract.md)；
测量量的完整定义统一维护在[实验方法](method.md)。本页不复制另一套总体保证或逐案例
结论。

## 1. 统计单位

- 固定状态集合：直接计算该集合的量，不外推到随机总体。
- 独立抽取的 gradient history：一整条 history 是一个单位，其中的多个步骤不是多个独立样本。
- 完整配对训练：共享起点、数据与随机策略的一对运行是一个单位。
- 同一数据流的重复执行只检查重复性，不增加独立单位数。
- 同一训练运行的多个评估时点组成该运行的轨迹，不增加训练重复数。

共用 checkpoint 将结论限制在该 checkpoint；它不自动破坏按照声明机制独立抽取的数据流
之间的独立性。独立性由生成机制决定，不由状态编号或文件行数决定。

## 2. 固定集合

固定集合只报告该集合内的直接量，不能外推为随机总体或训练质量结论。候选/参考写入、
总能量、RMS 和整体缩放的唯一公式与原坐标要求见[实验方法](method.md)第 3、5 节；
本页不再复制公式。只有保存原向量或足以恢复均值的完整 Gram 时，才能附加报告集合平均
方向能量；仅有能量标量或摘要不能称为原坐标精确均值。

## 3. 随机总体、方向与总体保证

总体平均能量、逐状态超界比例、方向比例和平均方向是不同问题。本页只规定设计要求：
方向必须在确认数据揭示前冻结；每行必须对应声明生成机制产生的独立单位；固定集合、
历史复算和同一轨迹窗口不能冒充随机总体。正方向频率不能替代平均投影或全向量均值。

各总体量的估计式、Hoeffding 条件、精确二项界、允许比例、repair-energy 下限和当前
AdamW8bit 结果只查[随机总体推断合同](population_inference_contract.md)。条件缺失时
返回不作判断，不把“小样本区间跨零”写成总体等价。

## 4. 完整配对训练

第 (i) 对训练在固定评估集和预声明终点 (T) 上均完成且有限时，使用
`method.md` 第 7 节定义的配对差与区间；本页不再复制公式。

这里 (n) 是配对训练数，而不是步数、评估窗口数或单条轨迹的记录数。区间的经典精确
解释依赖独立、同分布且正态的配对差；当前小样本只作带假设的条件性推断。共用评估集
提高配对精度，但结论仍条件于该评估集。

在同一批已见数据上提出修改并重放，支持该数据上的机制归因；它不增加未参与修改选择
的新确认样本。要外推平均改善，必须在修改、训练长度、主要比较、评估集、改善门槛和
失败规则冻结后，使用新的独立训练流。

## 5. 训练数值失败与汇总

对条件 (a) 的第 (i) 条训练，定义

\[
F_i^a=\mathbf1\{\text{终点 }T\text{ 前发生协议定义的数值失败}\}.
\]

非有限 loss 或参数属于训练数值失败；CUDA 不可用、依赖缺失、OOM、编译失败和运行中断
属于执行失败。同一数据流的重试仍是一个统计单位。

若任一条件没有完整有限终点，最终有限 loss 差没有定义：不填大常数或无穷值进入 t
区间；分别报告完成、数值失败、执行失败和未完成数量；双方均完成子集只能标为条件于
完成。失败率属于结果后的补充分析，不能倒推修改主要终点。

当前失败感知汇总入口为：

```bash
PYTHONPATH=.:src python scripts/summarize_structured_residual_training_v2.py \\
  --root results/property/result_analysis_v3/structured_training \\
  --output results/property/result_analysis_v3/structured_training/failure_aware_summary.json
```

## 6. 当前数据用途

- 固定集合原坐标 Q、实际参数写入和固定 history 机制实验：集合内描述与来源分析。
- AdamW8bit 的独立 history：只支持合同中声明的经验分布总体端点。
- 结构干预与同路径 OFF/ON：已见数据上的机制归因，不增加新的独立训练样本。
- 最终冻结后的独立训练流：用于预声明主要训练比较；具体结果和范围只维护在
  [主张账本](claims.md)与[总体推断合同](population_inference_contract.md)，本页不复制数值。

旧训练流经过最小起点间距筛选，不满足严格 iid；其区间保留为冻结数据流上的条件性近似。
同一数据流的复现运行不增加 (n)。

## 7. 生产入口与统计边界

统计不是手工填写：`training_bias_profile.py`、`training_equivalence.py`、
`population_direction.py` 和训练分析脚本提供生产计算；人工仍需声明参考语义、数据用途、
独立单位、参数范围和机制解释。程序不能凭输入编号证明独立性，也不能把结果后选择变成
前瞻确认。

Student 分位数使用 SciPy 分布分位数；样本方差为零时不确认总体非零；翻符号和方向频率
只是满足相应设计条件时的诊断。均值推断为条件性或渐近推断，不是任意重尾、小样本分布
下的有限样本定理。历史协议与输出保留，重新分析写入新路径并明确数据用途。
