# 统计层校准：等价轴、区间覆盖与偏斜（评价计划工作项 D / M1，2026-10-06）

## 1. 新增：两个轴分开输出

每条固定方向的规则在原有「是否非零」判定之外，报告「是否在 ±δ 内」（`analysis.equivalence`，传入
`assess_units(..., equivalence_rel=…)` 时生效）：

- 非零轴（原判定，冻结不变）：端点保守的双侧 1 − α 区间 [E[l] 的下界, E[h] 的上界] 不含 0。
- 等价轴：μ 只知在 [E[l], E[h]] 内，所以两个单侧检验（TOST）各用承载它的端点：E[l] 的单侧 1 − α 下界 > −δ，
  且 E[h] 的单侧上界 < δ。两个轴可以同时成立（「小而确定」的作用）。等价只是相对声明的 δ 排除了足够大的作用，
  不证明 μ = 0。
- δ 的尺度：每坐标 δ_rel·q_R，q_R 为坐标集上参照中点的 RMS，在开发单元上估计后冻结；投影到单位方向上为
  δ_rel·q_R·√n。学习方向（交叉拟合）不给等价结论。δ_rel 的取值见评价计划第 5 节（待确认）。

## 2. 校准结果（`scripts/calibrate_equivalence.py`，每格 4000 次，α = 0.05，δ = 0.5 个单位噪声标准差）

| 噪声 | 单位形式 | 区间覆盖率（名义 0.95） | |μ| = δ 时错误宣布等价（须 ≤ 0.05） |
|---|---|---|---|
| 正态 | 点 | 0.945–0.952 | 0.038–0.047 |
| t₃（重尾） | 点 | 0.952–0.961 | 0.042–0.051 |
| 对数正态（偏度约 3.3） | 点 | **0.895–0.936** | **0.090–0.141**（偏向长尾的一侧） |
| 三种 | 区间（宽度 U(0, 0.4)·sd） | 0.981–1.000 | ≤ 0.028 |

偏度与样本量的关系（点单位，每格 3000 次）：偏度 ≤ 0.6 时各项都在名义水平附近；偏度约 1.1–1.75 时 n = 32–128
的错误等价率 0.06–0.08，n = 16 时非零检验的误报率 0.06–0.07；偏度 3.3、n = 16 时覆盖率 0.898、错误等价率 0.140。

**bootstrap-t（1999 次重抽、固定种子）**：偏度 1.1–1.75、n = 32–64 时错误等价率 0.043–0.060、覆盖率 0.940–0.950；
偏度 3.3 时 n = 16 为 0.095 / 0.921，n = 64 为 0.068 / 0.941。比 t 区间好约一半，强偏斜、小样本时仍不到名义水平。

## 3. 真实数据里有多常见

对仓库中全部工具报告（`results/tool_spec/**`、盲测结果）中至少 16 个确认单位的规则计算单位投影的偏度：39,694 条
规则中 **17.8%** 的 |偏度| ≥ 1；8,579 个检出中 6.5% 的 |偏度| ≥ 1（例如 Liger 部分旋转 RoPE、Triton 教程注意力、
vLLM d = 80 的注意力）。所以 t 近似的局限在真实数据上确实出现，不能只在附录里提一句。

## 4. 报告规则（在 M2 的任何数据之前写定）

1. 每条规则与等价结论附 `unit_skewness` 与 `t_approximation`（|偏度| ≥ 1 为 suspect），冻结的判定字段不变。
2. |偏度| < 1：按 t 判定报告。
3. |偏度| ≥ 1：同时报告 bootstrap-t 伴随区间（`robust`）；评价表中的结论以伴随区间为准。
4. |偏度| ≥ 2 且确认单位少于 64：记为「判不了（偏斜）」，或在声明中增加种子后重跑，不用 t 结论。
5. 盲测 v1、v2 的成绩按当时冻结的协议计分，不追溯改判；本规则只用于之后的评价。
