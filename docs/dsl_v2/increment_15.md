# DSL v2 第十五个增量：登记（2026-10-09）

分支 `dsl-v2`，工具 4.0（开发中）。对应 rc3 正式版 04 的 W2 / W5（核心语义的剩余缺口）。本登记写于实现之前。

## 1. 依据：增量 14 之后的广泛捕获（状态运行）

增量 14 之后用当前求值器把增量 6 的官方测试集合全部复跑（`results/dsl_v2/main_capture/inc14_broad*.jsonl`，状态运行，不是登记的评价）：
12,766 次启动，完整 12,246、完整（集合目标）260（合计 98.0%），部分 126，中止 5，求值器错误 0（增量 6 的 1 次错误已不再出现）。
剩下的类别逐一查过原因：

| 类别（启动数） | 原因 | 本增量 |
| --- | --- | --- |
| 浮点 max / min 位型下降中的整数集合 + select（60）、同址混用原子种类（20） | 返回值集合含 ±inf 初值，区间表示不了 | 不处理（固有） |
| 超出捕获大小（22）、读环境的 inline asm（2）、执行竞争（7）、捕获之外的地址（1）、float64 越界（1） | 固有或前提 | 不处理 |
| argmax / argmin 带 NaN 时 warp 内各 lane 结果不一致（14） | 消费者读哪个 lane 没有模型 | 不处理 |
| 同一 program 两次原子返回值的大小关系（4）、原子返回值作为 `cf.cond_br` 条件（1） | 需要集合之间的关系或 CFG 分支合并 | 不处理 |
| bessel_y0 / y1 负数输入（4） | 类别 D 的既定规则：定义域外记未建立 | 不处理（改成 NaN 是语义改动，需审阅方决定） |
| `remf` 定义域（8） | 除数是 int64 转换来的区间，现规则只接受点值 | **B** |
| `__nv_rint`（double）、`__nv_clz`、`__nv_popc` 中止（3） | 没有声明语义；`math.ctlz / ctpop / cttz` 也一直是拒绝 | **C** |
| int8 `%` 的 1 次部分参照没有原因 | INT_MIN % −1 是未定义行为，记未建立正确，但没写原因 | **A** |

检查 A 时发现一个更重要的缺陷：求值器里整数值按 2^宽度 取模保存，从无符号存储（uint8 / uint16 / uint32）读出的值是无符号表示，
而 `arith.cmpi`（eq / ne 与有符号谓词）、`divsi / remsi / ceildivsi / floordivsi`、`shrsi`、`maxsi / minsi`、`extsi`、`absi` 直接用原值计算。
例如 uint8 元素 200 与常数 `-56 : i8`（MLIR 对 200 的打印）比较相等会得到「不等」，有符号除法会按 +200 而不是 −56 计算。

## 2. 做法

| 项 | 内容 |
| --- | --- |
| A | 缺陷修复：上述有符号操作与比较先把操作数换成该宽度的有符号表示（`extsi` 按输入宽度）；`tt.load` 读出的整数值同样换成有符号表示（写回 uint8 / bool 存储时仍按字节）。除零、INT_MIN / −1、移位量越界的 lane 写明原因 |
| B | `remf`：除了点值以外，若 x 区间的最大绝对值小于 y 区间的最小绝对值（y 不含 0），则 fmod(x, y) = x 精确成立，结果为 x 的区间。y 含 0 仍按类别 D 记未建立 |
| C | 位计数：`math.ctlz`、`math.cttz`、`math.ctpop`（MLIR 语义：输入为 0 时 ctlz / cttz 返回位宽），libdevice `__nv_clz` / `__nv_clzll`、`__nv_popc` / `__nv_popcll` 按同一规则；`__nv_rint`、`__nv_nearbyint`（double）按 `roundeven`（与已有的 float 版本相同）。只对已建立的点值求值 |

## 3. 评价设计（实现前写定）

- 复跑官方测试中与这些项相关的测试（`test_bin_op` 的 `%`、`test_libdevice_rint`、`test_clz`、`test_popc`，及 test_core 中所有用到
  uint8 / uint16 / uint32 的测试），与状态运行逐启动比较。
- 逐签名测试：A 用 uint8 / uint16 / uint32 存储构造比较、除法、移位、扩展，与按有符号语义独立计算的值比较；B、C 三类齐全；W1 中
  `math.ctlz / cttz / ctpop` 与新的 libdevice 条目各有三类测试与触发证据。
- 回归不变。
