读法（不扩大解释）：
- 误报：零效应下两类的拒绝率在 0.020–0.057 之间（1000 次重复的标准误约 0.007）；状态相关与稀疏两类的固定均值类为 0.057、0.051，与名义 0.05 的差在一个标准误内。
- 功效：坐标均值平移在效应 0.02 时 R1 约 0.57–0.61、0.005 时与误报率相当（检测不到）；R5（开发集学到的方向）只在 0.25 时检出；对齐类对状态相关作用在 0.02 时约 0.62。
- 组内抵消（坐标均值为零的固定向量作用）：R1 不检出（与误报率相当，符合设计），R5 在 0.25 时检出。
- 稀有大尾部：R5 在所有效应量下约 57–60% 的重复判「无法判断」（方向学习在近乎全零的开发集上退化，返回无法判断而不是误报）；有界路线零误报，但在所有效应量下功效为零（Hoeffding 的界过宽）。
- 这些是 256 维、64 个确认单位、上述分布下的数字；「未确认」不写成「没有 bias」。
