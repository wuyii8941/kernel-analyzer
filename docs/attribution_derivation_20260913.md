# 补偿归因：数学可以证明到哪里

这份推导解释实现路径，不把恒等式本身称为非零统计bias或loss退化的证明。
同路径训练协议在 `results/property/result_analysis_v1/same_path_training/protocol.json`。
旧源码保持不变，新实验仅切换残差读回的乘数0/1。

## 1. Moment误差怎样进入下一步

先固定同一条梯度序列，讨论一阶moment；二阶moment用g²替代g，推导相同。
令参考moment为m_t，实际供下一步读取的moment为h_t。数学上的递推为

    m_t = β m_(t-1) + (1−β) g_t。

令x_t为当前实现量化前计算出的浮点moment。用ν_t明确表示它与参考计算之间的
浮点求值余项，则

    x_t − m_t = β (h_(t-1) − m_(t-1)) + ν_t。

这里ν_t不能擅自设成零；scalar、编译和求值方式都可能影响它。

默认量化保存h_t=Q(x_t)，定义ε_t=Q(x_t)−x_t，得到精确关系

    e_t = β e_(t-1) + ν_t + ε_t，  e_t=h_t−m_t。

因此每步保存误差会按递推系数进入后续读取。展开后，它是历史误差的加权和。
在相应期望存在时，均值满足相同关系；但只有进一步证明或测量误差均值不为零，
才能宣布统计bias。不对称的实现选择可能产生bias，量化本身不自动证明它。

## 2. 补偿改变的是哪一项

代码保存c_t=BF16(x_t−Q(x_t))，下一步读取fl(Q(x_t)+c_t)。定义实际重构误差

    ζ_t = fl(Q(x_t)+c_t) − x_t。

则补偿后的关系变成

    e_t = β e_(t-1) + ν_t + ζ_t。

它把完整量化残差ε_t换成残差保存与重构误差ζ_t，不是把全部误差变为零。
ν_t仍存在，训练时g_t也会随参数变化，所以固定梯度推导不能直接当作完整训练
loss的公式。当前TorchAO与补偿代码都用量化前的moment计算本步更新；量化残差
主要通过下一步的读取进入该递推路径。

## 3. 已被对照隔离的实现差异

- 原补偿关闭版与默认非编译版的moment一致，但实际参数写入不完全一致。
- 将lr和step的标量表示对齐到TorchAO的CPU FP32 tensor后，32步实际写入全部一致。
- 开启补偿与旧补偿实现的32步写入和moment均逐位一致。
- 默认编译与非编译仍有数值求值差异，不能在机制文字中将其删掉。

同路径训练沿用原补偿的标量方式，并使关闭/开启条件都保留残差存储，只有读回
乘数不同。原默认编译结果作为历史比较，不能当成该同路径的关闭条件。

## 4. 训练结果应该怎样分解

对每条相同数据流的最终评估loss，记D为旧默认编译结果，F为同路径关闭补偿，
T为同路径开启补偿，则

    L_D − L_T = (L_D − L_F) + (L_F − L_T)。

这只是三种训练结果的差值恒等式，不证明两种作用在线性系统中相互独立。
第二项是同路径补偿改变的训练结果；第一项包含实现求值等其他差异。
必须先检查T是否复现旧补偿训练，才能把这个分解用于解释旧训练改善。

新实验保存最终模型，重新加载并计算同一评估集的loss；旧默认只具有原记录证据，
不是新实验独立重训。每条流复用已见数据，因此这是归因重放，不是新的跨模型或
未见数据泛化验证。中途loss不能改变冻结的1024步终点或0.01工程门槛。

## 5. 其他案例的归因范围

31项新signature的能量与对齐关系可以直接复算，但它们均为参考图端点替换。
不能仅由这类结果宣称单kernel的舍入根因已经证明。保持“区域实现差异”结论
就是这些记录当前完整且正确的归因结论，不为填满根因表强行追加解释。

负对齐系数β_aligned也不自动代表更新总幅度缩小；总能量恒等式
C/R=1+Q+2β_aligned已经由原坐标量核查。整体方向转变和固定平均bias仍是不同问题。

## 6. 不能由这些对照额外推出的内容

在Q和更新幅度比已知时，对齐系数由上述恒等式确定。因此它不是独立于这两个量的
另一份证据。全空间平均方向需要跨状态内积或相应向量信息，不能由单状态能量恢复。

补偿可能同时改变误差均值与波动。即使同路径loss改善成立，也只证明当前残差
反馈修改的作用，不能单独证明“收益只来自消除均值bias，而非改变波动”。要证明
后者需要专门分离均值和能量的干预，本轮没有进行，也不以更改措辞冒充已完成。

同样，量化递推恒等式证明误差的传播路径，不证明每条轨迹单调恶化、不证明崩溃，
也不证明参考优化器代表唯一正确的训练轨迹。这些限制不依赖本轮最终loss的正负。
