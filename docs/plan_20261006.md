## 0. 定位与收束

主线固定为：**自动参照 + 陌生组合上的系统性作用检测 + 可核验诊断。** 其余工作都服务于证明这条主线可靠、
省事、能帮助用户做决定，不另起项目：

- benchmark 是工具的独立评价与可复用交付；
- 两条有条件的机制规律（第 5 节）是解释与预测层；
- 真实问题（`bugs/`）是使用价值的证据。

目标主张：以前需要专家为每个 kernel 准备参照、猜方向、追内部实现；现在同一套工具能在新的组合上完成这些关键分析，
并告诉用户哪里真的不对、哪里只是数值不同、哪些作用值得继续追到训练。不追求"控制所有训练的普适定律"，不以找到
训练崩溃为唯一成功标准；但凡主张"改善训练质量"，必须有对应的训练对照。

## 2. 一套工具，两种模式

- **模式 A（无外部规格）**：输入为 kernel 调用、合法输入来源、版本与运行配置；工具自动构造 K_R，测
  e_num = K − K_R，回答"当前实现相对声明数值语义有什么平均偏差或对齐作用"。报告写明"任务语义未检验"。
- **模式 B（有规格 f）**：在模式 A 之上同时报告 e_sem = K_R − f 与 e_total = K − f，三者一起给，不只给其中一项
  （Rprop 例子）。

两种模式共用捕获、参照、区间、判定（`assess_units`）、报告。不再为每类问题新增独立分析脚本。

需要固定成文、随版本发布的契约（不是新的 DSL）：

1. 哪些操作按实数解释，哪些舍入或量化本身是任务的一部分（接口舍入、编译期常数单列）。
2. 参照如何沿控制流、内存与状态组合；哪里降为条件局部参照或参照未建立；按参照值判定分支的含义。
3. 输入分布、测量点、开发/确认划分与统计规则。
4. 两类保证分开写：K_R 是区间包围（有独立审阅支持的范围）；f 分两级——筛查级（float64 eager + 声明预算，
   "区间证实"以预算成立为条件）与确认级（严格包围或独立实现），登记问题一律用确认级复核。

## 5. 两条有条件的机制研究

### 5.1 状态写入的舍入停滞

局部判据：对正的可表示状态 x、一次就近舍入，若 (1 − β)·x < (x − prev(x))/2（prev 为前一个可表示数），则
RN(β·x) = x。研究内容是预测**哪一次更新会被吞掉**：

- 区分实现组织：RN(RN(β·x) + (1 − β)·y) 与 RN(x + (1 − β)·(y − x))（lerp）在实数上相同、被舍入的中间量不同；
  分步物化与融合计算分开；
- 变量：精度、β、输入序列（大小、符号、分布）、库实现（PyTorch foreach / fused / compiled、torchao 等）；
- 只用局部判据预测局部事件；长期比值（如 `bf16_adam_beta2_prediction.md` 的"< 1.02"）是实验预测，不是该不等式的
  推论。新颖性限于自动识别执行路径、预测失效边界、核实不同实现的差异（低精度 EMA 的失真本身已发表，Collage 等）。

### 5.2 局部扰动在 Adam 中的状态相关传播

固定旧 moment，只扰动当前梯度、忽略 ε，ψ = m/√v，δg = c·g 时

δψ/ψ ≈ c·[(1 − β₁)·g/m − (1 − β₂)·g²/v]。

在每个状态上先预测，再与理想更新和实际写入分别比较；报告预测何时准确，何时因 ε、跨符号、分支或写回舍入失效。
"只扰动当前一步"与"整段梯度历史同比例缩放"是两个实验（后者在零初始 moment、实数运算、忽略 ε 时归一化更新不变）。
blind_test_v2 阶段 3 理想响应与实际写入检出数不同、实际写入有 11 / 14 个程序参照未建立，正好用来研究"哪个环节
消除或遮蔽了作用"，不能用来给更新层的小作用下统一保证。

阴性结果只在能给出有效上界的投影上报告"平均作用不超过 X"（写明是哪个量、分母与同时置信度），给不出的保留未确认。

## 7. 新增的纠正（并入阶段总结第 10 节）

| 说法 | 为什么错或过强 | 替代表述 |
|---|---|---|
| 成熟 kernel 在默认与常用配置上基本无偏 / 经得起检查 | 只覆盖测过的用例、输入、测量点 | "在这些用例与测量点上未检出" |
| 发现了严重语义错误，所以均值 bias 检测比普通差分更有用 | 有正确规格时普通差分也可能抓到 | 用同输入的直接差分基线说明新增价值（WP3） |
| Adam 把缩放 bias 统一压到约 1 − β₁（或 0.1 倍） | 传递系数依赖状态：(1 − β₁)·g/m − (1 − β₂)·g²/v | 状态相关传递系数；只在 m ≈ g、v ≈ g² 等条件下近似常数 |
| 每条近似指令有一个可复用的 bias 系数 | 平均误差依赖操作数分布与下游敏感度（E[J·e] 含协方差项） | 条件误差模型，写明分布与测量点 |
| bias 只在不对称非线性之后出现 | 纯加法、输入分布不对称、定向舍入都能形成平均偏差 | 不作为规律使用 |
| 随机舍入把任何 bias 的累计从 T 变成 √T | 单次舍入无偏不保证经过非线性与状态反馈后的更新无偏（ε 经 ε² 后均值为正） | 写明具体舍入方案及其已证明的性质 |
| 局部衰减未被吞掉，所以长期 v 比值 < 1.02 | 局部判据推不出长期比值 | 长期比值是实验预测，单独验证 |
| OpInfo 筛查中的"区间证实"是无条件证明 | f 只带声明的 2⁻⁴⁰ 预算 | 筛查级证实；登记前用确认级 f 复核 |
| 未检出即"95% 保证作用很小" | 只对给出有效上界的投影成立 | 能给上界的单独报告，其余为未确认 |
