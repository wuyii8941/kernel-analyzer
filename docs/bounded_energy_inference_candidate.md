# 总体能量检验：有已知范围时的候选修正

这是新增候选方法，不替换历史协议，也没有宣称真实训练已具备所需条件。
实现为 `src/kernel_analyzer/bounded_energy_inference.py`。

对独立同分布训练单位，必须事前从外部论证
`0 ≤ X ≤ x_max`、`0 ≤ B ≤ b_max` 以及 `E[B] > 0`。
观测最大值、几个随机摘要的最大值、仅提供一段说明文字，都不能证明这些条件。
当前接口记录来源，但不自动核验其证明。

令 `D = X − δ² B`，则 D 的取值范围宽度为 `w = x_max + δ² b_max`。
独立有界变量的指数矩界给出
`P(E[D] − mean(D) ≥ t) ≤ exp(−2 n t² / w²)`。
取 `t = w sqrt(log(1/α)/(2n))`，得到单侧上界 `U = mean(D) + t`。
由于 `Q < δ²` 等价于 `E[D] < 0`，只有 U < 0 才判断等价。
在不等价零假设下，错误通过概率不超过 α，不需要能量服从高斯分布。
下界可对称构造；上下界各为单侧保证，并非合在一起仍有 1−α 覆盖率。
多个位置的超范围判断仍需另行处理多重比较。

测试包含此前稀有事件反例、二项分布边界的精确概率枚举、足够样本下的
小效应，以及违反声明范围时拒绝计算。这些不是完整生产流程校准。

尚缺的关键步骤：从真实参数写入及训练约束推导可用而非极端宽松的能量范围；
验证独立单位生成；加入数值计算误差处理；再通过原坐标采集到结论的完整路径
评估功效。若范围太宽，结论会长期不确定，不能缩小范围来追求通过。
因此当前解决的是附加条件下的数学路线，不是统计主线已经完成。
