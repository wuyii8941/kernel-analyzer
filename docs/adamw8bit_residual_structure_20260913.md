# AdamW8bit 残差结构干预：固定重放与训练结果

日期：2026-09-13

本页区分固定梯度历史重放与在已见数据流上的训练干预。后者用于根因消去，
不是未见数据确认；数值失败不被填成有限 loss。

## 已完成：固定梯度历史重放

在 8 条固定梯度历史上，仅改变一阶 moment 量化残差的使用方式。二阶 moment 继续使用正确补偿，避免人为置换产生非法的负二阶状态。

| 条件 | 平均参数写入 RMS（相对 FP32） |
|---|---:|
| 不使用残差 | 4.2259% |
| 正确使用残差 | 0.00721% |
| 在量化块内循环移动残差坐标 | 7.2045% |
| 倒序使用同一条历史中的残差 | 4.6872% |

正确使用残差在 8/8 条历史中均优于坐标移动和时间倒序。它说明残差与参数坐标、训练步骤的对应关系会改变 optimizer response，不能把补偿效果仅解释为“保存了更多相同总量的信息”。该实验是固定梯度历史上的反事实重放，不是自然训练崩溃或训练质量结论。

原始结果中的 `all_energy_checks_exact=false` 来自检查程序对循环移动逆变换的错误假设，以及约 `2.28e-16` 的浮点求和顺序差异。独立复算保留原始文件并将结果标记为 `VERIFIED`，没有改写原始布尔字段。

## 已完成：1024 步训练干预

协议预先声明 8 条数据流和四种条件：只补偿关键参数、只补偿其余参数、移动残差坐标、额外延迟一步使用残差。历史上的不补偿和完整补偿作为相同训练设置的对照。

全部冻结任务已有终态：

| 条件 | 完整有限轨迹 | 训练数值失败 |
|---|---:|---:|
| 只补偿关键参数 | 7 | 1（第 936 步） |
| 只补偿其余参数 | 8 | 0 |
| 移动残差坐标 | 0 | 8（第 206–330 步） |
| 额外延迟一步 | 8 | 0 |
| 历史完整补偿对照 | 8 | 0 |
| 历史不补偿对照 | 8 | 0 |

坐标移动的 8 条数据流全部出现非有限 loss，说明在这组刻意干预中，残差与参数坐标的
正确对应是训练稳定性的必要条件。该失败端点是在首个失败出现后补充定义的，因此当前
只作这组冻结任务的描述事实，不能称为事前控制错误率的失败率推断，也不能称为自然
AdamW8bit 崩溃。

只补偿关键参数的前 7 条有限轨迹相对完整补偿的平均 loss 差为 `+0.00133`，98.75%
区间为 `[-0.01408,+0.01674]`；第 8 条在第 936 步失败，所以全体最终-loss差值没有定义。
这否定了“所选关键参数组已经足以替代全补偿”的简单结论，不能只汇总幸存的 7 条。

只补偿其余参数相对不补偿的 8 条差值均值为 `+0.00736`，98.75% 区间
`[-0.00723,+0.02195]`；预声明等价没有建立。额外延迟一步相对正确补偿的均值为
`-0.00139`，98.75% 区间 `[-0.01361,+0.01083]`；预声明的 material worsening 也没有
建立。因此训练结果明确支持坐标对应的重要性，但没有确认一阶残差只延迟一步就会恶化
loss，也没有证明少数参数或其余参数单独足够。

这些训练流参与过修改选择，是结果感知的同数据机制实验。区间是小样本、带正态假设的
配对 t 近似；它们不升级为新训练流总体结论。
