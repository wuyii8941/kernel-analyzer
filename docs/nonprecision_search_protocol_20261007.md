# 非精度定向搜索协议（阶段 C 补充轮，2026-10-07，运行前写定）

**动机。** 阶段 C 按「状态存成什么精度」选搜索位置，阶段 B 的尺子也全是精度改动，所以只看到精度问题。工具测的是更新层的平均作用，
不限于精度。本轮检验它能否抓到**非精度的系统性偏差**——语义上差一点、单步能过容差、却在更新层有方向的作用；从一个公开修复过的
已知阳性开始。本文在任何本轮测量之前提交；改动只追加到第 7 节。

## 1. 候选

| 编号 | 候选 | 对照（正确实现） | 设置 | 依据 |
|---|---|---|---|---|
| N1（已知阳性） | 梯度累加时每个微批的 loss 按**本微批**的有效 token 数取平均，再除以累加步数 k（HF Trainer 4.46 之前的做法） | 按**全部微批**的有效 token 总数归一化（4.46 的修复：`num_items_in_batch`），等价于不累加的大批 | D：可变长段落（wikitext 段落，截断到 256，padding 处 label = −100），批 32、k = 4 | HF 与 Unsloth 2024 年公开修复 |
| N3 | fp16 AMP 中先裁剪再 `unscale_`（裁剪作用在放大后的梯度上） | 先 `scaler.unscale_` 再裁剪（PyTorch AMP 文档的写法） | F：fp16 autocast + GradScaler（初始放大 2¹⁶），块数据 | PyTorch AMP 文档明确要求的次序 |
| N4 | 权重衰减作用到全部参数（含 RMSNorm 权重与词嵌入） | 只作用于二维的线性层权重（R 的分组） | R | 训练程序常见的分组细节 |
| N5 | 学习率调度提前一步（相当于先 `scheduler.step()` 再 `optimizer.step()`） | 按步取学习率 | R | PyTorch 对这一次序会给出警告 |

不纳入：激活重算的不一致（本模型没有随机性，重算逐位相同，测不出）；多卡各卡批大小不均（与 N1 是同一个归一化问题，单卡上
即 N1 的结构）。

## 2. 测量：影子状态

这些候选改变的是梯度的组成（N1、N3）或优化器的设置（N4、N5），而优化器状态会积累被改变的梯度，所以用阶段 C 的影子状态测量：
对照正常训练；候选持有自己的优化器状态，每步得到**由同一批数据**按候选的方式得到的梯度（N1：同一组微批的逐微批梯度和，按两种
方式归一；N3：同一份放大后的梯度，按两种次序裁剪与还原，放大系数与跳步由对照的 GradScaler 决定），参数每步重置为对照的 θ_t。
单位：第 100、120、…、1980 步（95 个），开发单位为序号 ≡ 0 (mod 3) 的 32 个；种子 0 与 1；两遍运行（ν̂ 交叉拟合）。作用量 γ̂、b̂ 与
规则 R1、R2、R3、R5（端点保守 t），同阶段 C。

## 3. 判定（事先写定）

- **检出**（回答「能不能抓到」）：两颗种子上，本轮全部规则检验（4 个候选 × 4 条规则 × 2 颗种子）经 Holm 校正后，该候选至少有一条
  规则确认平均作用非零，且两颗种子的符号一致。
- **相对尺子**：按阶段 B 冻结的 δ = 0.05 分类（超过 / 在尺子之内 / 判不了，规则同阶段 C 第 3 节）。δ 是在设置 R 中标定的，D、F 两种
  设置下只作参照，不作结论。
- **训练层面**：候选作为真实训练程序，种子 0–3 与对照配对，ΔL 的 95% 区间；与对照设置自己的种子波动比较（D 用 8 个种子估计 σ_D；
  F 用 4 个种子；N4、N5 用阶段 B 的 σ_seed = 0.0145）。

## 4. 事先登记的预期

- N1：检出（已知阳性；若检不出，记为工具的漏检并分析原因）。不预测相对 δ 的类别。
- N3：检出；不预测大小（Adam 对梯度尺度近似不变，但裁剪每步都生效，相当于每步把梯度归一，改变了步与步之间的相对权重）。
- N4：检出，缩放型 γ̂ < 0（多出的衰减把范数权重与词嵌入往 0 拉）。
- N5：检出，γ̂ < 0（余弦下降段提前一步，学习率略小），且在尺子之内（预计约 10⁻³ 量级）。

## 6. 不做

## 7. 偏离记录

以下 1–4 在任何本轮测量之前补写（实现时发现或需要写明的细节）：

1. **N4 的对照写得不准。** R 按维度分组：二维参数都在衰减组，其中包括与输出层共享的词嵌入。所以 N4 与 R 的差别只在一维参数，
   即 9 个 RMSNorm 权重向量（共 2,304 个参数），词嵌入在两边都有衰减。候选本身（衰减作用到全部参数）不变；第 4 节预期中
   「把词嵌入往 0 拉」这半句不适用，预期「检出、γ̂ < 0」照原样保留，按原样检验。
2. **检出判据的读法。** 第 3 节取严格读法：存在同一条规则，在两颗种子上都经 Holm 校正后拒绝，且两颗种子的平均投影同号。
   宽松读法（两颗种子各有一条规则拒绝、符号一致，可以是不同规则）同时报告，不作为判据。
3. **实现细节。** D 与 R 一样用 fp32（第 1 节没写精度）；F 是 fp32 主权重加 fp16 autocast。N1 的影子梯度由对照逐微批的梯度
   G_i（对 Σ loss / N 求导）按 Σ_i G_i · N / (k N_i) 得到，与「微批均值 / k」的程序只差 fp32 舍入；N1、N3 的候选各自裁剪自己的
   梯度（裁剪是候选训练程序的一部分），N4、N5 得到对照裁剪后的梯度（同阶段 C）。
4. **F 中的跳步。** 对照的 GradScaler 在某个测量步跳过时，该步的 r = 0，不构成单位，从单位中剔除并报告个数。

5. **N3 的归因（探索性，在第 1 节的影子测量之后、本测量之前补写）。** N3 两颗种子都检出，γ̂ ≈ −0.92。候选的梯度先被裁剪到
   范数 1（放大后的梯度范数是 s‖g‖ ≫ 1），再除以 s = 2¹⁶，所以每步梯度的范数恒为 1/s ≈ 1.5·10⁻⁵，每个元素约 4·10⁻⁹，低于 Adam 的
   eps = 10⁻⁸。两个可能的来源：(a) 梯度被缩小后 eps 占主导；(b) 每步梯度都被归一到同一范数，改变了步与步之间的相对权重。
   测量：在 F 中加一个候选 N3e = N3 且 eps 改为 10⁻⁸ / 2¹⁶（只去掉 (a)；本轮所有测量步的放大系数都是 2¹⁶，见结果），与 N3 在同一次
   运行中测（种子 0）。**预测**：|γ̂(N3e)| < 0.1·|γ̂(N3)|，即作用主要来自 (a)。只作归因，不进入第 3 节的判定。

6. **N4 的归因（探索性，事后补写：在看到 N4 种子 0–2 的训练层面结果之后、本测量之前）。** N4 的单步作用 b̂ ≈ 0.005（δ 的十分之一），
   按阶段 B 的剂量反应（随机方向，b = 0.003 / 0.01 时 ΔL +0.0003 / +0.0018）应在 10⁻³ 量级，但配对训练的 ΔL 约 +0.015（约 1σ_seed）。
   假设：剂量反应用的是遍布全部参数的随机方向，而 N4 的固定方向全部落在 9 个 RMSNorm 增益上，其中最后一个（与输出层共享的
   词嵌入之前）直接决定 logits 的温度，对 loss 远比随机方向敏感。测量：以 2,000 步检查点重跑 R 与 N4 的种子 0（逐位可重复，验证
   loss 应与已有运行相同），比较各 RMSNorm 增益的均值；在 R 的最终模型中 (i) 把最后一个增益换成 N4 的、(ii) 把全部 9 个增益换成
   N4 的，看验证 loss 的变化占 ΔL 的多少。**预测**：(i) 就能解释 ΔL 的一半以上。不进入第 3 节的判定。
