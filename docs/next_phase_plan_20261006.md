## 第一部分 实现目的

kernel 开发者和训练工程师面对的是同一个决定：这个 kernel 能不能放进我的训练。

**同行与业界怎样判断重要。** 没有一种按算子误差的大小来判断：

1. 和训练本身的随机波动比。DeepSeek-V3 验证 FP8 训练时，在 16B 与 230B 两个规模上与 BF16 训练对照，相对误差保持在
   0.25% 以下，按「落在训练随机性可以接受的范围内」决定采用。
2. 和已经被接受的做法比。Golden 等人分析 Flash Attention：单次前向的数值偏差比基准注意力约高一个数量级，但按训练中
   权重差异给出的上界，其影响比低精度训练小 2–5 倍，与随机初始化造成的差异相当或更小；结论是算子层偏差大十倍仍不重要。
3. 训练失败。Qiu & Yao 研究的低精度 Flash Attention 造成 loss 爆炸，不需要阈值就是重要的。
4. 算子层容差。torch.testing 按数据类型设定的容差只判断实现对不对，不判断重不重要。

共同点：重要性在训练结果上判断，参照有两把尺子——训练本身的随机波动，以及大家已经接受的做法造成的差异。

**对把 kernel 放进训练的人。** 要回答的问题：换上这个 kernel，对训练的影响会不会超过我已经容忍的那些差异（换随机种子的
波动；已经采用的精度选择，如 BF16 代替 FP32、0.25% 一级的 FP8 方案）。由此给 δ 一个不武断的定义：以一个被接受的做法在
更新层产生的平均作用作为尺子。

1. 用工具测一个公认可接受的改动在更新层的作用大小，得到 γ_accept；
2. 用剂量反应实验确认这把尺子对应到 loss 上的大小，并与种子间波动比较，检验两把尺子是否一致；
3. 每个检出报告成一个倍数：「这个 kernel 的作用是可接受改动的 1/k」。

**现有结果怎么读。** Unsloth 的 bf16 作用在 HF eager 实现里同样存在，按定义不重要；RMSNorm 与外部语料的 9 个条件要和
γ_accept 比才能下结论；AdamW8bit（独立 run 上测到 loss 差）与 bf16 AdamW（有效步长压到 0.52）都是重要的。

**价值主张。** 业界判断一个数值改动能不能用靠完整训练对照；我们提供的是在训练开始之前、用单步重放回答「这个 kernel 的
作用相当于多少倍的可接受改动」，附置信区间与定位。

门槛。

### 2 可以进一步创新的方向

**2.1 以可接受做法为尺子的重要性度量。** 对候选替换 X，在声明的总体 Π 上测更新层平均作用 μ_X（方向与归一化按比较声明
固定）；选公认可接受的改动 A（如矩阵乘累加 FP32 → BF16、eager → 编译、已发表的 FP8 方案），在同一 Π、同一方向规则下测
μ_A；报告 ρ_X = μ_X / μ_A 及其区间（由两个均值的联合区间给出，不能把两个区间直接相除）。

**2.2 单步测量对训练结果的预测效度。** 设候选的更新沿参照更新方向多出比例 γ：u = γ r，θ⁺ = θ + (1 + γ) r；对 SGD 等价于
学习率乘以 1 + γ。固定方向上的作用随步数积累，不能只看一步。两类都用剂量反应实验标定：小模型训练中注入已知大小的更新层
作用（u = γ·r 与 u = b·ν），逐级加大，测 loss 差，找出首次超出种子间波动的大小；再对一组真实替换检验单步 ρ 能否正确排出
训练层面的差异。

**2.3 步数尺度（辅助量）。** u_t = μ + w_t，S_T = Tμ + Σw_t，E‖S_T‖² = T²‖μ‖² + E‖Σw_t‖² ≈ T²‖μ‖² + T·C(0)·τ；两项相等时
T* ≈ C(0)τ / ‖μ‖²。只在平稳窗口内有意义，只作辅助描述。

**2.4 在作用不被抑制的位置上定向搜索。** 梯度 kernel 上的缩放型作用经 Adam 后大多被压低；写进优化器状态的作用不经过这层
抑制。候选位置：低精度保存的优化器状态（bf16 状态的 foreach / fused AdamW，8 位与 4 位优化器，因子化二阶矩）；低精度的
滑动平均（权重 EMA）；跨步累加的缓冲区（bf16 梯度累加、bf16 all-reduce，后者只能黑箱）；迭代型计算（bf16 中的
Newton–Schulz 正交化）。按 ρ 排序，只对超过尺子的做深案例；不预先写阈值。

### 3 四个阶段

**A 发布收尾（约 1–2 周）。** (1) 等价判定零方差保护与 CPU 回归（64 个全零样本返回未建立）；(2) 偏度诊断进报告，校准
结论写成「完成校准并给出失效范围」；(3) RQ2 拆两栏；(4) 核验分两栏；(5) 逐层表标明设备、优化器路径与状态来源，用同一批
梯度与状态在 CUDA 的 foreach 与 fused 路径上重放；(6) 口径修正（9 个条件按 e_num 与 e_total 拆开；Unsloth 写 31/32 及
排除原因；同等预算比较写成「指定预算与参数下的观察」）；(7) 外部接入试验，找不到人写进局限；(8) 打 tag，台账中每个数字
指向文件。验收：审计列出的每一项已关闭或写入局限；表中每个数字可追溯。

**B 重要性标定（约 3 周）。** (1) 2–3 个可接受改动的 μ_A；(2) 参照设置下约 8 个种子的验证 loss 波动；(3) 剂量反应：
u = γ·r（γ 从 10⁻⁴ 到 10⁻¹）与 u = b·ν，每档多个种子；(4) 预测效度：8–10 个真实替换，训练前算 ρ 并登记预测，再做短程
配对训练；(5) 由尺子定 δ，写明来源，在 C 之前冻结；(6) T* 作辅助量。产出：标定图、全部发现的 ρ 表、有依据的 δ。

**C 定向搜索（约 3 周，在 B 之后）。** 按 2.4 列候选，在真实训练状态下捕获，算 ρ 及区间并排序；对超过尺子的前 1–2 个做
深案例（机制推导、预注册干预、独立配对训练；提交前按症状、测试文件、近期 PR 检索上游并在 nightly 上复现）；低于尺子的报告
上界。

**D 写作（从 A 结束起并行）。** 方法章节用现有草稿；评价章节用 A 的修正表；B 写成「从作用到重要性」；C 作为案例；局限
收齐所有范围限定。

### 4 阶段性成果与三种可能的结果

| 阶段结束时 | 可以说 | 还不能说 |
|---|---|---|
| A | 自动参照在他人构造的语料上可靠，两类独立交叉核验均无超出余量的差异；规格差异与平均作用分两轴报告；按预声明门槛，活动的植入缺陷全部识别、控制组与未触发条件无候选；容差判定在 15–20% 的控制条件上误报；9 个通过容差但有平均作用的条件，定位到近似指令 | 这些作用是否重要；kernel 可以安全替换；未经重放的 CUDA 写入路径上的结论；外部用户能复用（若试验未做） |
| B | 单步测量能否预测训练层面的差异；现有每个发现相当于可接受改动的多少倍；δ 的来源 | 超出所测模型规模、优化器与训练长度的普遍结论 |
| C | 在作用不被抑制的位置上，哪些实现超过尺子、哪些在尺子之内（附上界） | 未测过的优化器实现都安全 |

三种结果各自的写法：预测效度好且 C 找到超过尺子的实现（工具 + 训练前的重要性度量 + 独立复现的发现）；预测效度好而 C 没有
找到（训练前的认证：主流实现都在可接受做法之内，附上界）；预测效度差（如实报告，主张收回到「存在、归因与两轴判定」）。
B 的结论不预设方向，只预先登记。

### 5 不做的事与风险

不做：重构规格或方法章节；重跑全部 699 个外部条件；为凑数找新 bug；新一轮盲测；随机算术基线；按库的全量普查；把新的长程
训练设为完成门槛。

| 风险 | 表现 | 应对 |
|---|---|---|
| 可接受改动的作用测不准 | μ_A 区间太宽 | 选作用较大的可接受改动；必要时增加状态数；仍不够则只报种子波动这把尺子 |
| 剂量反应噪声大 | 需要大量种子 | 小模型、短训练、固定数据顺序；先粗扫再细扫；种子数在登记时写明 |
| 单步不能预测训练结果 | 预测效度差 | 按第三种结果处理，如实报告 |
| 小模型的标定不能外推 | 审稿质疑 | 结论限定在所测规模；在两个规模上各测一次可接受改动的 ρ |
| 找不到外部接入的人 | RQ5 无证据 | 写进局限，不用作者代替 |
| 上游已有同类报告 | 像 B016 那样撤回 | 提交前按症状、测试文件、近期 PR 与 nightly 四项检索 |
