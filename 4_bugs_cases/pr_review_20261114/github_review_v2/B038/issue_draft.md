# Varlen attention backward retains the dropped outer probability factor

[PR #8969](https://github.com/flagos-ai/FlagGems/pull/8969) fixes the dense Q/K derivative but leaves varlen unchanged. On its fixed head `69caccc0f8ca58c58a213be4fc8b0193333c87b8`, the varlen loops still apply dropout to the outer P in the softmax derivative. The correct score derivative is `P * (R * U - sum(P * R * U))`.

The [varlen-only patch](https://github.com/wuyii8941/kernel-analyzer/blob/3a4cbf1a0128dc615dbd6134768955d4aec58716/4_bugs_cases/pr_review_20261114/review_evidence_20261115/pr8969/varlen_followup.patch) and [16 same-mask NVIDIA tests](https://github.com/wuyii8941/kernel-analyzer/blob/3a4cbf1a0128dc615dbd6134768955d4aec58716/4_bugs_cases/pr_review_20261114/review_evidence_20261115/pr8969/test_flash_attention_dropout_derivative.py) distinguish the remaining issue: [original PR head 4 failures](https://github.com/wuyii8941/kernel-analyzer/blob/3a4cbf1a0128dc615dbd6134768955d4aec58716/4_bugs_cases/pr_review_20261114/review_evidence_20261115/B038_8969_before_nonzero_v2/junit.xml), [patched 16 passes](https://github.com/wuyii8941/kernel-analyzer/blob/3a4cbf1a0128dc615dbd6134768955d4aec58716/4_bugs_cases/pr_review_20261114/review_evidence_20261115/B038_8969_after_nonzero_v2/junit.xml). A [DKV-only rollback](https://github.com/wuyii8941/kernel-analyzer/blob/3a4cbf1a0128dc615dbd6134768955d4aec58716/4_bugs_cases/pr_review_20261114/review_evidence_20261115/B038_8969_dkv_reverted_v2/junit.xml) fails the two new nonzero-Q/K/V varlen cases at dK while old Q=0 controls pass.

dQ/dK compare with independent FP64 autograd; dV includes the declared [probability-cast error allowance](https://github.com/wuyii8941/kernel-analyzer/blob/3a4cbf1a0128dc615dbd6134768955d4aec58716/4_bugs_cases/pr_review_20261114/review_evidence_20261115/pr8969/nonzero_regression_protocol_v2.json). dBias and forward/backward RNG integration are not established. This should be coordinated on #8969 before creating a separate overlapping issue or choosing a submission base; [#8748](https://github.com/flagos-ai/FlagGems/issues/8748) remains Related.
