## 早期阶段可主张什么

| 主张 | 直接依据与范围 | 不能推得什么 |
|---|---|---|
| 审核接入后，可复用同一数值分析流程 | 系统入口（`pre-reorg-20261009:docs/system.md`）：调用、输入、参考或性质契约均显式提供 | 任意源码零配置、自动生成正确 reference、自动定位所有根因 |
| 实现选择能造成可定位的数值差异 | [案例总表](root_cause_closure_current.md)：同输入干预，逐项注明归因到区域、算术边界或分量 | 来源问题组数等于独立 bias 数；一个 backend 名称就是成因 |
| 能在声明条件下判断能量或方向 | 统计方法（`pre-reorg-20261009:docs/method.md`）、总体合同（`pre-reorg-20261009:docs/population_inference_contract.md`） | 所有高维 bias 指标都已有有限样本保证；固定集合等价能保证未来训练 |
| 训练状态会改变同一数值差异的作用 | [RoPE 状态对照](fused_rotary_position_scaling_audit.md)及总表中的分子/分母复算 | reset 同时改变 moments 和 step counter 时，把全部变化唯一归因于 moments |
| 残差传播诊断能指导有效干预 | AdamW8bit 的 history 重构、同路径开关与独立训练确认（`pre-reorg-20261009:results/property/result_analysis_v4/iid_training_confirmation/verification.json`） | 普适的新优化算法、生产成本优势、平均 bias 是 loss 改善的唯一原因 |
| 数值更接近不保证训练修改成功 | block64、FP32-first-moment、局部补偿和完整补偿各自的既有结果 | 不同采样批次的结果可直接排名；较小 RMS 一定无价值 |
| 参数距离不代表质量持续恶化 | [Liger 长程记录](liger_single_boundary_collapse_experiment.md)保留 loss 差异反转 | loss 反转证明没有 bias 或任意未来训练安全 |

## 必须分开的五种证据

1. **覆盖与执行。** 有效位置、编译 signature、目录族是不同分母。超时、缺参考、
   路径不匹配和非有限值不是阴性，不能从覆盖汇总中静默删除。
2. **数值差异。** 原坐标 Q/RMS 不遗漏未投影的能量，但不证明均值非零。CountSketch、
   单方向投影和旧几何摘要不能冒充全空间上界；公式 proposed update 不是实际写入。
3. **bias。** 冻结方向均值、符号频率、逐状态 aligned 比例均值及 ratio of expectations
   是不同对象。高正号比例不推出正均值；未确认不等于无 bias。`check_bias` 的
   statewise-gain 端点不能改名为总体向量均值证明或 ratio-of-sums 的总体区间。
4. **来源。** 同输入、声明变量的干预能建立该边界内的归因；最终受影响参数不一定是
   来源位置。AOT 端点替换可能包含上游差异，不能当作隔离的单 kernel 对照。
5. **训练后果。** 配对运行才是训练重复单位。历史重放不算新确认；验证窗口和 step
   数不增加 n。收益的范围取决于 checkpoint、数据流、评估集、预算与推断假设。

## 机制解释的限制

- source/response 奇偶分解是恒等式，不是对物理成因的穷尽分类。原坐标重构若含
  实测浮点余项，应区分“恒等式核对”与“只凭残差预测”；较新的残差预测结果不能
  改写旧实验所做的事。
- local 未显著、gradient 显著不自动证明下游从零生成 bias；要比较效应和不确定性，
  或做保持其他条件相同的干预。冷启动效应不能无条件推广 warm 状态。
- saved-P 行和缺陷说明一项一致性关系破坏，不等于完整概率误差，更不等于自然总体
  更新均值或稳定 loss 损害。
- 关键参数贡献大部分差异能量，不证明只修这些参数就足够。局部补偿失败仍有竞争
  解释；参数组耦合是待检验假设，不是从失败直接读出的成因。
- 残差坐标打乱是人为干预。它导致数值失败不等于自然实现必崩，也不能在 OFF 仍稳定
  时声称“正确残差读回是稳定性的必要条件”。

## 统计和训练报告的约束

固定集合直接计算与随机总体推断分开。已有有界均值检验需要观察前有效上界；精确
二项合同针对超界概率，不针对 Q 或 M。t 区间在小样本、重尾或数据选择后没有无条件
精确保证，样本方差为零也不证明总体方差为零。轻量入口的边界校准尚需按
实施计划（`pre-reorg-20261009:docs/system.md`）补齐，不能写“统计理论全部完成”。

IUT 只处理一个声明证书的必要条件合取，不免除跨案例、跨变体和探索后选择问题。
总体 M 的加强保证未建立时保留诊断，不借 Q 或投影签发。历史 t/正态区间不能因为
后续方法改进而自动变成新协议的有限样本证书。

完整有限终点、数值失败、执行失败和未完成分别汇总。非有限 loss 不填大数后算均值，
只分析两边完成的子集时明确条件化。结构干预的事后失败率分析不改名为预注册主端点。
同路径 OFF/ON 归因重放与独立流确认的用途分开，详见
统计与实验设计对齐（`pre-reorg-20261009:docs/statistics_experiment_alignment.md`）。

## 相对已有测试方法的定位

目前支持的是可复用测量、额外诊断信息和代表性训练干预，不是已证明全面优于现有
testing 方法。以 update RMS 定义受控真值的九场景比较是校准，不是完整方法相对 RMS
的独立优势证据。已有 allclose 通过的微小效应也不能包装成“漏过严重训练错误”。

如需更强效用主张，应冻结任务、候选、共同输入和预算，用源码语义或独立干预定义
定位答案，再比较局部误差、多状态 RMS 与完整分析；记录额外执行成本。没有记录的
人工时间不能补造。RENDER/TTrace 只有忠实运行后才能报告其结果，不用自制阈值冒名，
不把对方任务范围外的案例算 false negative。同行关系见创新边界（`pre-reorg-20261009:docs/novelty_positioning.md`）。

当前对外简述：**面向实际训练实现的数值差分分析与偏差诊断，提供声明范围内的判断，
并以来源干预和训练实验验证代表性发现。** 不称通用 bug Oracle、崩溃预测器或任意
kernel 的完整正确性证明。
