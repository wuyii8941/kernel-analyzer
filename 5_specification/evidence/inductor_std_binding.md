# PyTorch Inductor corrected standard deviation 与输入 VJP 绑定

调用边界是 PyTorch 2.10.0 的公开 `torch.std`：连续有限 float32 `[16,128]` 输入，固定
`dim=1`、`correction=1`、`keepdim=False`，返回完整 `[16]` 标准差；再以显式 float32 `[16]`
upstream 求完整 `[16,128]` 输入 VJP。声明的正态输入使每个归约切片的标准差严格为正；两个输入都是
任务前态并保持不变。

任务规格使用已准入的 REDUCE `real` profile。保留的 PyTorch 2.10 文档将标准差定义为 corrected
variance 的非负平方根；保留的同版本 schema 固定这里使用的 `std.correction` 公开重载。合同用独立
`Fraction` 与100位平方根计算复算前向和完整梯度，并将 VJP 限于正标准差，避免把多元素常量切片上的
框架零梯度约定当成唯一实数导数。ground truth 只依赖收到的 float32 输入和这份任务定义，不使用
eager 或已编译输出。

`compiled_formula_observed_20261019.json` 确认实际编译生成一个融合 Triton reduction kernel，同时
写出16个标准差和2,048个输入梯度，输入未改变。前向使用 `tl.sqrt_rn`；反向保留标准差等于零时写零的
分支，并将 `2/127` 生成为十进制常量 `0.015748031496062992`。该常量进入 float32 运算后的值为
`0.015748031437397003`，与精确 `2/127` 相差 `-1/17045651456`。编译结果与 eager 的最大差分别约为
`2.38e-7` 和 `1.12e-8`；这组 eager 比较只核对调用边界。

正式报告 `.cache/spec_trial_20261019_std/production_report_20261019.json` 使用8个开发输入和16个确认
输入。前向384个坐标、VJP 49,152个坐标的程序参照完整率和分辨率均为1；没有语义缺失、绑定、
特殊值、预算、前提或包围失败，完整公开输出均参与比较，重复执行逐位一致。

前向 `Gπ-f` 没有坐标的严格区间排除零；设备到程序的平均绝对差约 `5.32e-8`，最大约
`2.49e-7`，R1、R2、R3 均检出正向平均作用，Holm 校正后 p 值约 `0.0129`。VJP 的程序公式保留
上述 float32 系数选择，49,152个 `Gπ-f` 坐标全部严格排除零，平均绝对差约 `1.82e-11`、最大约
`2.44e-10`；固定方向 R5 检出负向平均作用，对齐方向 R2、R3 检出正向平均作用。设备到程序的梯度
平均绝对差约 `2.81e-10`、最大约 `9.08e-9`，现有规则未确认稳定平均作用；完整设备到任务梯度比较
也未确认。结果表明设备执行差异会遮住更小的程序公式作用。这里没有把通常容差内的实现称为错误，
只报告相对于声明精确任务可分辨的方向和量级。

绑定不扩展到其他 shape、dtype、维度、correction、`keepdim=True`、零标准差切片、空归约、特殊值、
非连续布局、`var_mean`、旧 unbiased 重载、out 重载或任意同名 kernel。
