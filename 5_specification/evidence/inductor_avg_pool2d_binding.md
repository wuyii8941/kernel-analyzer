# Inductor 二维平均池化完整前后向绑定

本次本地源码和公式复核对应 PyTorch 2.10.0+cu128 的公开 `F.avg_pool2d` 及其输入 VJP。
调用文件是 `corpus/calls/inductor_avg_pool2d.py`：连续 CUDA float32 输入 `[1,1,4,4]`，
upstream `[1,1,2,2]`，有限值范围 `[-2,2]`；kernel=(3,3)、stride=(2,2)、padding=(0,0)、
ceil_mode=true、count_include_pad=true、divisor_override=None。返回完整 y 和 dx；两份输入不改值。
这不是第三方审核，也不认证其他尺寸、选项、版本或同名 kernel。

数学任务选择已核验的 `POOL.finite_avg2d_autograd`，明确计入显式 padding、排除 ceil 越界部分。
本调用没有显式 padding，四个真实窗口大小为9、6、6、4；前向是各窗口平均，梯度是同一线性映射
的转置乘收到的 upstream。来源与参照独立核验见 [POOL 实现复核](pool_implementation.md)。
绑定计划逐项映射全部两个物理输入及固定参数，返回 out→y、grad→dx，并声明完整只读前态。
不能因为候选梯度错误而拒绝这份任务对应；错误值应留在被比较的结果中。

实际捕获到两个 Triton kernel。通过存储身份核对，前向 in_ptr0 是原始 x、out_ptr0 是返回 y；
反向 in_ptr0 是原始 upstream、out_ptr0 是返回 dx。全部参数均有对应，没有额外浮点输入。
生成 TTIR 对4个前向和16个梯度坐标完整写入，两个程序只读取对应的原始输入；无原子操作或
跨 kernel 的浮点临时量。A6000 sm_86 的 PTX 与 TTIR 均保留，模式 A 诊断的所有坐标具有完整
程序参照，无未证明前提、外部重入、输出遗漏或结果写完后的改动。

这里的额外 dispatch 跟踪会改变 torch.compile 的执行路径：带跟踪调用没有相同 Triton 启动。
最初把该跟踪用于开发观察的记录被拒绝并保留；修正后的主观察使用正常捕获，跟踪单独留作诊断。
工具本身也将它标为 not aligned，没有使用它提供来源证据。由于两个 kernel 都直接读取原始输入，
完整程序参照不依赖该跟踪补充任何中间值。

程序公式复核：前向 TTIR 累加窗口输入后除以对应整数9、6、6、4；反向 TTIR 的所有浮点除法都除以
精确常量9。分支、索引和 mask 只依赖固定坐标，没有输入值相关的分支；浮点计算是线性加法与常数
除法。因此，可以按每个输入基向量核对该固定形状的完整线性映射。`verify_linear_map.py` 独立枚举
窗口，不调用 POOL 适配器，核对16个 x 基向量和4个 upstream 基向量上的40份完整输出参照。
严格区间与预先给定的系数一致；这是对源码线性推导的核对，非“区间包含便证明等式”。

独立推导的反向系数差：第一个窗口为0；第二、第三窗口每个参与输入为 `1/9−1/6=−1/18`；
第四个窗口为 `1/9−1/4=−5/36`。重叠输入累加各自贡献。这个差异在程序按精确实数执行时已经存在，
与设备舍入分开；只对这个显式选择的任务和实际生成程序成立。

完成上述源码、语义、参数、存储及完整输出复核后，绑定计划和调用文件独立留存于 `validated/`。
开发检查没有自动复制或升级状态。测量声明事先固定8个开发输入、16个确认输入，x 和 upstream
均独立取自 float32 uniform[-1,1]，seed_offset=168。它是已知问题的定向实验，不是盲测泛化材料。

## 正式测量结果

24次调用的绑定全部为 reviewed，前向96个坐标和梯度384个坐标都有完整调用级程序参照和任务参照，
达到声明分辨率；重复执行逐位相同。未出现绑定、语义参照、预算、区间宽度或未证明前提失败。
每次仍按 POOL 合同检查输入域，未支持的输入不因调用文件经过审核而自动得到参照。

前向程序与任务公式相同，96个 Gπ−f 区间均不排除零，设备到程序平均绝对差约9.82e-9。
梯度中288/384个 Gπ−f 区间严格排除零，正好对应每个输入中受尾部窗口影响的12个坐标。
全部24次完整观察上的梯度平均绝对差为：Gπ−f 约0.0395159122，K−Gπ 约1.7559e-9，
K−f 约0.0395159117。没有把这些逐点平均绝对差当成总体有符号均值。

使用8个开发输入确定方向后，16个确认输入上的 R2/R3 对齐规则确认了梯度的程序到任务、设备到任务
非零平均作用；固定方向 R1/R5 未确认。设备到程序的较小梯度舍入作用也被对齐规则确认。
报告中的正负号按各规则校准后的投影定义，不直接表示每个梯度坐标都增大或减小。没有推断模型训练
影响，也没有声称所有其他池化调用具有相同统计结论。

完整必需检查通过，含932项 unittest 和外部调用检查；合同模式 GPU 集成及本绑定拒绝检查通过
71项测试、4个 subtest。最初两条新测试误用了已有接口的状态名称，修正预期名称后的结果与失败日志
一起保留，没有改变生产判定逻辑。

证据在 `inductor_avg_pool2d/`：`measurement_v1.json.gz` 保留完整正式报告、声明、当前已审核调用、
计划与参照源码；`linear_map_v1.json.gz` 保留系数复核；`development_observation_v3.json.gz` 保留
原始输入、输出、参数对应和 TTIR/PTX；前两次开发观察与导致零启动的诊断同样保留；
`validation_v1.json.gz` 保存检查与执行日志。复现入口为 `corpus/measure_cases/inductor_avg_pool2d.json`，
