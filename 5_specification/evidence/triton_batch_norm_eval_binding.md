# Direct Triton BatchNorm evaluation binding review — 2026-10-19

This review covers `corpus/calls/triton_batch_norm_eval.py` and `corpus/call_bindings/triton_batch_norm_eval.json`. It applies only to one contiguous physical finite float32 NCHW input of shape `[2, 8, 8, 8]`, four contiguous channel vectors, evaluation mode, eps 0.125, and the complete values output of the input shape.

The wrapper checks every declared input, shape, dtype, device, layout, finite range and the nonnegative running-variance range. One launch uses four Triton programs. Each program maps every output coordinate to its channel, loads the input, running mean, running variance, weight and bias, evaluates `(x-mean)*rsqrt(variance+0.125)*weight+bias`, and writes the output once. The plan binds all five input pre-states, every task parameter, the full returned tensor and all unchanged states to the reviewed BN `finite_eval_values` profile. The kernel name is not used as evidence.

A GPU 3 comparison with PyTorch 2.10 functional BatchNorm had maximum absolute difference about `2.38e-7`, consistent with differing floating execution of reciprocal square root and operation order. The formal baseline used 8 development and 16 confirmation inputs. All 24 bindings were reviewed and usable, all 24,576 task references reached the declared resolution, and repeated launches were bitwise identical. No program-to-task coordinate excluded zero; its mean absolute residual was about `4.93e-17`, reflecting interval midpoint display rather than a task contradiction. Device-to-program mean absolute residual was about `3.46e-8`, maximum about `1.33e-6`. The report is `.cache/spec_trial_20261019_bn/triton_batch_norm_eval/baseline_report.json`.

A temporary controlled candidate added 0.25 after the same BatchNorm expression. All 24,576 program-to-task coordinates excluded zero, with mean absolute residual 0.25. Complete device-to-task mean absolute residual was about 0.25, and the fixed-mean rules detected a nonzero average effect. Device-to-program error remained at ordinary float32 scale, with mean absolute residual about `4.22e-8`. The temporary candidate and binding were removed after the run. Its report is `.cache/spec_trial_20261019_bn/triton_batch_norm_eval/controlled_plus_quarter_report.json`.

This binding does not cover training, running-statistic updates, saved statistics, gradients, native multi-output forms, other shapes, dtypes or layouts, special values, fused surrounding computation, or another Triton kernel with a similar name.
