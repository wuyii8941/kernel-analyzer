# 规格 v2.5（2026-10-16）

在 v2.4 之上，按「参照身份 × kernel 种类 × 决定维度」补齐 15 个陌生库清点中需要定义的规格。设计依据见包根目录的 SPEC_V2_5_PLAN.md。

## 组成

| 路径 | 内容 |
|---|---|
| specs/ | 可执行参照：spec_quant（OFP8、MX、NVFP4、缩放 FP8、整数量化、4 位打包、延迟缩放）、spec_paged_attention、spec_linear_attention、spec_moe_routing、spec_sparse_attention、spec_collectives、spec_random。精确有理数加 v2 的 rigorous_mp 区间模块，没有新增区间实现 |
| contracts/ | 14 份合同。每份含来源及其身份、D1–D12 维度检查单、条款与保证标签、读法、手算例子、误读 |
| adapters/ | 合同到参照的绑定；误读按其文字描述独立实现，不调用规格代码 |
| check_v25.py | 合同检查：每例只有成立、矛盾、未建立三种结果；每条误读必须被拒绝；没有例子的条款记为未建立；按来源身份给出结论能说到哪一步 |
| tests_v25.py | 与独立计算的性质核对：v2 舍入 oracle、numpy 与 IEEE 转换、分块与逐步递推的精确相等、伴随梯度、split-KV 合并、打包往返、MX 误差界、对齐总数 |
| coverage.py | 把清点中需要定义的 344 个分族按关键词映射到合同，生成 COVERAGE_v25.md（逐分族表供人工复核） |
| survey_9bb8abe/ | 清点原件 |

## 十二个决定维度

D1 公式与参数化，D2 标量约定，D3 布局与索引，D4 并列与次序，D5 数值格式，D6 掩码与对齐，D7 状态语义，D8 近似的参照目标，D9 随机性，D10 非语义部分的排除，D11 合法域与尾部，D12 反向约定。合同对每个维度写「已定 / 不适用 / 未定」；未定的维度就是工具报告「未建立」的理由。

## 来源身份与结论

来源身份分 standard、paper、torch_doc、model_impl、engine_ref、math。条款的依据只有 model_impl 或 engine_ref 时，检查器只给「与参照程序一致」，共有的错误看不见；其余给「符合任务定义」。

## 当前结果

- 合同：14 份，54 条条款全部成立，76 个例子，47 条误读全部被拒绝；读法例子 8 个全部成立。
- 性质核对：28,507 项全部通过（FP8 舍入与 v2 oracle 一致 12,000 项；fp16 与 numpy、fp32 与 IEEE 转换各 3,000 项；分块与递推精确相等 720 项；伴随梯度 120 项；split-KV 合并 40 项；打包往返 1,000 项；MX 误差界与饱和 8,427 项；对齐总数 200 项）。
- 清点覆盖：需要定义的 329 个分族加随机类 15 个，共 344 个；按关键词映射，219 个（64%）落到 v2.5 合同，125 个未定，理由见 COVERAGE_v25.md。加上原本已有参照程序的 453 个，797 个分族中有 672 个（84%）有定义。这批库是用来设计 v2.5 的，所以这些数说明 v2.5 在它上面的位置，不是首次接触的命中率；首次接触时是 453/797（57%）。

## 检查中纠正过的两处

- 一处手算期望值写错（F7 的 fp32 缩放读法），检查器报矛盾，按 IEEE float32 转换改正。
- 一处参照路径出错（线性注意力默认缩放），检查器报错，已修。

## 仍然未定

13 个维度未定（见 CHECK_REPORT_v25.md 末尾），以及清点中 125 个分族：RWKV、HGRN、ABC 等 A1 之外的递推变体 27 个，KV 字节布局 16 个，布局与元数据格式 16 个，压缩 KV 与环形缓冲 10 个，投机解码、哈希与水印 10 个，其余见 COVERAGE_v25.md。
