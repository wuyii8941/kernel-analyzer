# 独立实现复核保留文件

运行时只在这里存在与当前文件完全相同的 `contracts/<ID>.yaml` 和
`adapters/<ID>.py` 时，承认该合同记录的实现复核仍适用于当前版本。公开调用的绑定计划同理保留为
`bindings/<ID>.json`，审阅时使用的可执行调用文件保留为 `calls/<ID>.py`。

这些文件由独立复核的结果产生。开发检查器不会写入本目录，例子、误读或单元测试通过也不会自动复制文件。合同、适配器、绑定计划或调用文件修改后，当前文件会与这里保留的复核版本不同，运行时会拒绝使用，直到重新复核并保留新的完整文件。

这里直接保留可阅读的原文件，不使用内容哈希。合同内容审阅、参照实现复核和真实 kernel 绑定仍分别判断。
