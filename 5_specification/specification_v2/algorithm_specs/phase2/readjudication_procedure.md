# 2b 结论复审程序（第 2 行的完成标准）

1. 在 docs/ 与 results/ 的所有结论性文字（报告、summary 的 verdict 字段、台账）中检索以下模式，列出每一处：
   `误差界内` `在 .* 误差界` `条件数` `eager 也一样` `与 eager 一致.*因此` `正确舍入本身` `不是实现问题` `可以忽略` `很小`
2. 每一处填一行复审表：原文、它替代了哪一类判断（误差多大 / 平均作用 / 是否违反）、改写后的表述、依据（精度不变性比值、统计判定编号、契约条款）。
3. 改写规则：
   - 大小的描述保留，但不得作为结论；
   - 语义归类用 numeric_contract_v3 第 2 节的比值，已有 float32/float64 双精度数据的直接算，没有的记「未判定」；
   - 平均作用由统计层回答，样本不足记「无法判断」，不写「不是问题」；
   - 「不是缺陷」只能来自契约条款（例如 G7 的 GELU：真实数值作用、契约未禁止），并保留为研究对象。
4. 复审表入库；原文不改历史记录，只在新版本报告中替换。
5. 完成标准：模式 1 的检索结果每一处都在复审表里有一行，且没有一行的「改写后」仍含上述模式。
